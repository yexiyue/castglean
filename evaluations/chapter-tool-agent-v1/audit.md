## 逐例核对

### 1. holdout-tide-post

**结论：可用；给定范围及公开标注约定，未发现实质语义不确定或身份不足。**

- u2 `[69,96)`：递钥匙并“说”的主语是祁雨，对应唯一的 `c-qiyu`。
- u4 `[126,159)`：“莫舟没有伸手，反问”明确支持 `c-mozhou`。
- u6 `[175,205)`：“祁雨笑了：”承接关于蟹和邮票的直接回应，支持 `c-qiyu`；没有其他发话线索竞争。
- reviewGold 恰好纠正 u2/u4 的对调；u6 和其余叙述作为负例成立。换行在 u5 叙述中，外层引号均在对应 speech 内。

此处没有从人物名之外推断隐含身份；characters 中名字与规范 ID 一一对应。

### 2. holdout-dark-stair

**结论：可用；陌生人规范身份不足是文本明确设定，unknown 合理，没有强行裁定已知 ID。**

- u2 `[102,129)` 来自“身份不明的陌生人”，不能绑定到唯一登记人物叶槿。
- u4 `[153,183)` 的“叶槿朝门外答道”直接支持 `c-yejin`。
- u6 `[204,228)` 的“门外那人又说”可识别为前述陌生人的再次发话，但不提供其姓名或登记 ID；末句再次明确未见脸、不知姓名。因此两个 unknown 自洽。
- reviewGold 恰好纠正 u2 的错误人物和 u6 的错误叙述类别。后续换行归 u7 叙述。

unknown 不表示两次声音必定来自不同人，也不能作为完整的未知人物共指能力测试。本例能检查的是“不强配已知人物”，而非未知人物稳定 ID 的恢复。

### 3. holdout-two-lu

**结论：可用；同名规范 ID 绑定充分，未发现身份不足。**

characters 不仅给出两个“陆青”，还分别提供“北街木匠，佩木制名牌”与“南街医师，佩白瓷名牌”。这些描述与源文一致，是绑定依据，不需要猜测 ID 的英文含义或依靠数组顺序。

- u2 `[93,117)` 前明确为“佩木制名牌的木匠先开口”，对应 `c-lu-carpenter`。
- u4 `[162,192)` 前明确为“佩白瓷名牌的医师放下药箱，说”，对应 `c-lu-medic`。
- u6 `[243,282)` 前再次明确为“木匠陆青指着自己的木名牌补了一句”，对应 `c-lu-carpenter`。
- reviewGold 恰好纠正 u2/u4 的人物对调；u6 是可支持的负例。“他名下”的所指不影响发话人绑定。

结论以提供的完整 characters（含 description）为前提；未检查实际 adapter 是否保留 description，不能认证运行时输入完整性。

### 4. holdout-title-in-quote

**结论：可用；嵌套引号和称号不构成发话人歧义。**

- u2 `[93,174)` 前明确“宁舒对他说”，故是 `c-ningshu`。“守钟人”即使是冯伯的登记别名，也只是宁舒话中的称呼，不会把发话人变成冯伯。
- u4 `[198,267)` 前明确“冯伯听完才回答”，故是 `c-laofeng`；内层“补星星的人”是所讨论称号，没有独立发话行为。
- u6 `[294,339)` 前明确“宁舒指着表盘接话”，故是 `c-ningshu`；内层“星星”同样不切换发话人。
- gold 保留外层完整话语，内层单引号未导致错误拆分；reviewGold 恰好纠正 u2 的人物和 u4 的类别。u7 的换行属于叙述。

不需要为未列为 alias 的“补星星的人”补建角色，也不能把被称呼者当作当前说话者。

### 5. holdout-unspoken-seed

**结论：可用；内心与有声话语区分明确，未发现强行裁定。**

- u2 `[54,102)` 前有程栗“心想”，后又明确“这句话她没有说出口”“闻禾并不知道她的念头”，支持 thought / `c-chengli`。

- u8 `[303,345)` 紧接“闻禾把种子放进土里，暗自想道”，支持 thought / `c-wenhe`。主语明确，不需要猜测前文代词或作者意图。
- reviewGold 恰好纠正 u2 的 speech→thought 和 u8 的人物。换行位于 u9 叙述，边界与标注约定一致。

### 6. holdout-glass-unicode

**结论：固定范围语义可用；analysis 的完整分段存在非唯一性，需限制评测结论；无人物身份不足。**

- u1 `[0,123)` 的告示、电子屏文字与月相被明确描述为印刷/静默显示；u2 `[123,221)` 的组合字符及汉字又有“这些都是文字，没有广播”。speech 或 unknown 都没有支持，narration / narrator 合理。
- u4 `[251,291)` 前明确“赵柠低声念给自己听”，是有声 speech / `c-zhaoning`；自言自语不会因此变成 thought。
- u5 的“她没有念出告示”与前述发声不冲突：u4 的话语并不是“请勿触摸”。屏幕变换数字仍未发声，继续归叙述。
- u7 `[386,419)` 前明确“赵柠心里想”，支持 thought / `c-zhaoning`。
- reviewGold 恰好纠正 u1/u2 的非人声展示文字和 u7 的内心类别。
- u1 末尾 CRLF、u2 末尾制表符、u5 开头换行、u8 开头及结尾换行均在 narration 范围内。引号保留在所属话语或展示文本所在叙述中，未把引号一概当作 speech。
- UTF-8 切分没有截断 `🌘`、`🧭`、`𠮷` 或组合序列 `é`；未正规化、替换或裁剪原文。全角 `１` 与 ASCII `0` 按原样保留。

分段问题具体见前述报告：u1/u2/u3 可以合并为 `[0,251)`，u5/u6 可以合并为 `[291,386)`，而不改变语义标签或空白归属。这仅是非唯一性的证据，不是修改答案或建议事后筛样。
