# 整章多角色消费夹具

原创人工标注，允许随项目公开分发。不是模型预测或真实音频验收。

包含第一人称旁白、同名不同 ID 的 A/B/A 发言、未知与歧义发言、心理活动、引述文本，以及 emoji、组合字符、全角空格和制表符。所有片段依序组成唯一完整分区，空白也保留。保存正文是 LF；import_sha256 对应把 LF 替换为 CRLF 的原始输入。

运行：`cargo run -p castglean-core --example consume_chapter`。示例中的 Casting 是宿主显式策略，核心不保存具体音色；它只打印安排，不生成音频。未知/歧义依旧保留在原标注中，同名身份不会合并。

消费契约与修订失效见 [整章交接](../../docs/chapter-consumption.md)。
