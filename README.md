# CastGlean

章节交互简化（2026-11-13）：已接当前章右侧角色归属与声音设置，AI 校验结果直接可用，下拉修改立即保存，失败可重试并沿用宿主撤销；音色搜索/模型筛选、共享资源订阅、停顿失焦或回车保存和底部单一主要播放器已接入。导入改为先选 TXT、文件名预填名称、同屏编码预览后提交。原文、稳定身份、人工保护及历史音频保持；来源范围变化的重分析仍保留独立候选。自动化和原生验证边界见 `openspec/changes/simplify-chapter-workflow/validation.md`。

面向个人的桌面有声书制作应用：从本地小说原文完成章节分析、角色与音色绑定、顺序生成和试听。模型提出建议，宿主验证结果，用户保留制作决定权。

当前已实现本地工程与来源管理、分章和章节归属分析、声音绑定、整章顺序生成、片段起播与连续播放，以及日志和诊断导出。原文保持不变；章节任务冻结模型与文本语义身份，相同输入和版本才可续跑。

Kokoro 使用 g2pW 中文多音字预测和英文神经未知词后备。已完成自动化检查、本机真实模型样本及中文原生的导入→分析→整章生成→停顿 WAV 导出样本；**完整原生界面矩阵、人工听感和其他平台验证仍待完成**。角色分段正文、底部片段轨道、独立停顿与 WAV 导出已实现并通过自动化验证；修改声音后的局部重做与候选采用仍在规划中。

## 技术栈


- 桌面框架：Tauri 2（系统 WebView + Rust 宿主），选型依据见 [docs/desktop-studio/technology-choice.md](docs/desktop-studio/technology-choice.md)
- 前端：React 19 + TypeScript + Vite，TanStack Router 文件路由；UI 采用 shadcn/ui 源码组件与 Base UI 原语，包管理器 pnpm
- Rust 宿主：`src-tauri`，负责工程持久化与后台任务；选角、声音映射、候选与导出随产品功能落地
- 音色试听播放器采用 WaveSurfer.js 8，UI 参考 waves-cn 并适配现有 shadcn/Base UI；宿主后台提取并缓存波形摘要，音频仍通过受控本地协议播放。章节播放会话独立于浏览章，切章或切换页面继续播放；桌面底部控制条标明播放工程与章节并可返回当前片段。合成路由、浏览器真实 PCM 和 macOS 隔离实例跨章播放检查通过；人工听感与其他平台待验。

## 开发

```bash
pnpm install        # 安装前端依赖
pnpm desktop:dev    # 桌面开发模式，启用仅本机的 MCP 调试桥
pnpm build          # 前端类型检查与构建
cd src-tauri && cargo check   # 校验 Rust 宿主
```

## 界面预览

开发服务器提供以下可交互的前端设计预览，沿用 `docs/design.pen` 的页面层级：

- `/`：独立工程首页；应用级侧栏显示文字导航（新建、最近工程、音色中心、模型中心），底部提供快速上手和设置。工程以列表展示，示例工程独立放置，不混入用户最近工程。顶栏显示模型状态，点击直接进入模型中心；浏览器显示“浏览器预览”。
- `/start`：快速上手引导页。按导入章节、准备声音模型、确认存储位置提供操作入口；无需先配置模型即可导入与阅读原文。存储位置需在开始下载前确认，设置分区用 `?settings=` 深链直达。
- `/new`：导入 TXT，选择整本自动分章或每文件一章，检查编码预览并确认；追加来源时保留已成功项和失败文件，返回稳定的工程章节地址。
- `/project/sample`：复用真实章节工作台的只读示例，可浏览两章；分析、角色编辑、声音与导出需使用真实工程。
- `/project/:id`：单一章节工作台，原有三个图标工程侧栏、虚拟目录/正文、分章结构编辑与归属检查共用布局。工程角色入口为角色中心页面（非弹窗，master-detail）：左列旁白/角色列表（保留 AI 来源）（绑定状态摘要、待审建议标记与搜索），右列所选目标详情集中承载角色身份操作（重命名/别名/复用）、声音绑定（旁白与角色到库音色或预置音色，试听走真实音频链路）、声音画像（人工编辑不被建议覆盖）、选角建议按目标对照（当前绑定与建议并排，逐项采用；显式忽略待补）与音色设计（可预填画像，候选在本目标详情内预选绑定回填）；表单与统计就近渲染，不再有页面级游离表单。AI 选角从工程会话输入栏发起（可携带自定义要求，要求随触发消息冻结并转发给选角子 Agent），结果卡「审阅选角建议」直达首个待审目标。只有一个工程 AI 助手；检查分章、分析本章、选角和自然语言工具请求共用会话、模型、用量及草稿，切章不换会话。每次运行固定目标，迟到结果可定位回原章；会话历史只显示工程助手会话。结构候选和归属重分析继续显式审阅，角色与人工保护、采用/撤回保持；顶栏「生成本章音频」可对已分析、已绑定声音的章节发起整章生成，有效分析后按角色列分段；底部制作区显示生成前阻塞、全章音频占位、真实单元进度、片段试听、停顿编辑和 WAV 导出（自动化通过，原生待验）。范围及本轮验证见[融合验收](docs/desktop-studio/project-assistant-validation.md)，此前归属原生公开样本见[归属验证](docs/desktop-studio/chapter-analysis-validation.md)。
- `/models`：独立模型中心，展示当前构建实际编译的本地模型与离线盘点状态（未下载/部分就绪/已就绪/下载中/失败），支持准备计划确认、分阶段进度、取消/重试及加载验证；各模型通过固定清单直接盘点和读取共享 Hugging Face 缓存。共享缓存可能被其他应用引用，本次不提供模型文件删除。
- `/voices`：我的音色从 Rust 宿主读取真实资产，支持一次选择多个 `.voice` 包、完整校验、逐项选择与冲突决定、批量导入，以及多个音色导出到一个包；进度和结果可在切页后从任务快照恢复。音色存于应用数据目录 `voices-v2/`，不依赖模型下载或服务连接。预置音色来自实际模型目录，不可作为参考资产导出；真实资产已接重命名、确认删除、原始参考与指定模型试听；播放、推理及传输占用时删除返回忙状态。
- 音色详情以真实绑定数据展示工程引用（工程名与旁白/角色目标，可定位到对应工程的角色中心），无引用时如实显示为空。入库要求描述：设计路径自动带出、导入无描述项须逐项补填否则不发布；描述可修改，身份与引用它的绑定不变。删除被工程引用的音色会被拒绝并列出引用清单。
- `/voices/new`：文字设计与参考录音两种创建方式分别使用真实设计引擎和用户 WAV；参考录音与准确转写可在不加载模型时保存。支持会话草稿、旧候选保留及常驻试听播放器；现已接入真实设计引擎、WAV 候选、试听和确认入库（描述必填）；候选切页保留，未保存候选不承诺跨重启恢复。
- 设置浮层（顶栏齿轮打开，不再有独立设置页面）：保留当前页面上下文，双栏布局——左侧可搜索的分类导航（通用、服务连接、存储位置、语言、快捷键、关于），右侧为分组设置项；“关于”展示品牌标志、版本和吉祥物；分类切换写回会话状态，从任意页面都能直达某个分区。主题与语言只在这一处调整。服务连接分区提供文本模型的真实地址和凭据配置，远程语音服务明确标为尚未接入，模型资源统一在模型中心管理。地址栏带 `?settings=<分区>` 时直接打开对应分区（如 `/models?settings=storage`），关闭浮层会清掉该参数，浏览器后退同样关闭浮层；未知分区回落到“通用”，不显示空白面板。
- 全站视觉体系：主题 token 集中在 `src/index.css`，亮暗主题使用静阅青语义色，并包含 success/warning/info 及弱底变体；组件统一和真实页面验收仍在进行。组件与状态的视觉验收在真实页面进行，不维护独立展示页（原 `/design-system` 已移除）：空白、无匹配、服务未就绪和错误反馈覆盖首次使用、搜索/分类为空、角色与制作结果为空、404、路由加载失败、文件操作失败、章节导入问题及录音播放失败，并提供清除筛选、重新选择、重试或返回入口；服务未接入不伪装为连接错误。浏览器打开时各页显示统一引导（能力说明 + 示例工程入口 + 桌面端指引）。

所有业务页面共用顶部工程标签栏，一个标签对应一本小说的制作工程；模型状态只报告本机真实资源盘点，不隐含文本模型的默认选择。真实工程在统一外壳内采用可收放的目录、章内原文和正文/工程助手三栏，角色由稳定入口管理；真实工程已支持声音绑定，章节音频第一阶段已实现但原生窗口验收未完成；独立示例不作为真实制作结果。关闭标签只收起视图，标签和阅读位置是界面会话状态；工程、分析、角色、人工修正与 AI 历史由宿主持久化，重开可恢复。

示例页面使用隔离的只读数据，不写入真实工程。整书导入与辅助分章已完成本机验收：桌面宿主冻结 TXT 来源、确认 UTF-8/GB18030/GBK 编码、本地 regex 检测并支持人工标题/起点/分卷调整；不依赖 LLM 或 TTS 准备。浏览器仅提供示例预览；真实工程的打开、校验、读取和保存均由桌面宿主处理。旧版 v1 不再支持，原文件保持不变。

服务连接设置已加入多连接/多模型、系统凭据、默认与任务模型选择、分项能力探测，本地服务也可显式获取模型列表。 新建或编辑时可使用当前地址与凭据获取模型列表，无需先保存；部分服务返回的容量显示在列表中，输出能力上限不会自动设为请求参数。 OpenAI 兼容网关返回的可编码思考档位随模型记录，重新获取会更新已有模型；ultra 暂不支持。分章诊断通过 Rig 工具循环提出规则和行补丁，graph-flow 管理外层检查点，正式采用须点击确认。宿主测试、bindings、前端构建、真实桌面主链、故障恢复及 128 MiB／10000 章容量往返已通过；指定 Magpie 网关的 OpenAI、Anthropic、Gemini 三协议均完成列表、文本、工具、Schema 与流式验证。**其他平台、原生厂商端点和发布包性能仍需分别验收，尚未发布**，见[分章验证记录](docs/desktop-studio/chapter-splitting-validation.md)。

本地工程在 SQLite 中保存目录与编辑状态，原始字节和精确 UTF-8 正文单独按摘要保存。提交成功后自动保存，工程通过本地 id 打开；不读取或迁移旧 `.castglean` 文件及恢复目录。来源范围与限额见[数据格式](docs/data-format.md#本地工程与来源)。音色设计、原始参考与模型试听已接宿主，独立验收边界见音色验证记录。章节音频第一阶段（整章生成与播放）已接宿主、待原生窗口验收；局部重做/候选采用、远程语音服务和系统通知仍待接入。底部轨道、角色分段及停顿导出进展见 [章节音频工作台](openspec/changes/chapter-audio-workbench/tasks.md)。
