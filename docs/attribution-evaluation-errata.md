# 评测元数据勘误：attribution-v2

发现时间：v1 两端实测后复核阶段。v1 的正文、语义金标和已有报告均保持冻结；v2 没有真实模型运行报告，也不使用 v1 产物回算“更高分”。

确认的问题：

- 生成器对同一金标证据片段中的提及字符串使用首次匹配，漏掉后续同身份提及。例如 `same_name-02` 中两处“老师周宁”；模型引用后一处有原文依据，却无法与选定的第一处范围对齐。
- `anonymous-04` 原文明确出现“递水的女孩”，与“女孩”是同一身份，允许称呼却只收录后者。完整描述有原文依据，应纳入。

v2 在人工复核的这些原创场景中，补全每个身份已选提及字符串在该身份金标证据片段内的重复出现，涉及 `same_name-02`、`alias-01`、`alias-02`、`alias-03`、`alias-04`、`anonymous-01`、`anonymous-03`。另为 `anonymous-04` 增加上述完整描述及提及范围。不根据任意模型命称扩展表，也不接受“小田（第一人）”等无原文后缀。

40 个正文、表达类型、归属状态、身份数量、开发/留出划分保持相同。修正只涉及称呼和提及元数据，不把对齐缺陷改称模型归属错误。新版本通过 Schema、应用和离线评分测试，并保存独立冻结清单。

本次正式数值报告仍是 v1 的 160 次运行，严格得分和对齐诊断原样保留。下一批对照应显式选择 `--suite evaluations/attribution-v2`，在模型调用前核对 v2 冻结摘要；本次不追加或回退模型调用，也不宣称 v2 已实测。
