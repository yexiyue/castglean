# 单一工程助手融合验收

日期：2026-11-08。规格：[unify-project-assistant](../../openspec/changes/archive/2026-11-08-unify-project-assistant/)。状态：实现及自动化已完成，隔离原生工程与真实模型只读工具已验证；最终包重开复核见下文。

## 已交付

真实工程只有一套目录、虚拟正文和工程级 AI 助手，移除分章/归属模式栏。分章、分卷、标题规则、跳行、结构候选及归属检查器在同一工作台可达。当前章节、会话、草稿与运行目标分别管理；操作固定自己的章及来源，切章不会改写任务目标或重放模型请求。回复常驻显示本次上下文，可点击回到对应章，旧消息翻页和重开保留运行上下文。

首次分析、重分析差异、人工保护、采用/放弃/撤回与稳定角色身份继续由原领域宿主管理。混合待检查默认全书，支持结构/归属、本章/全书与文字/行号搜索；读取失败不会显示为已检查完成。旧分章与章节会话保留在只读历史中，不拼接成新会话，不提供旧作用域的发送入口。

SQLite schema v3 从 v1/v2 事务升级，只增加可空运行上下文；原始来源、编辑与消息保留。`HistoryPage.contexts` 只查询本页涉及的同一会话运行，流式和向前翻页合并上下文，不把旧结果标成当前阅读章。

## 原生与真实模型

macOS **26.6.2 / arm64**，独立标识 `com.yexiyue.castglean.acceptance` 的调试包；原始应用配置未更改。沿用此前的“公开短章 · 原生归属验收”两章工程与匿名本机 OpenAI 兼容网关，模型为 **GLM 5.3 Flash**。

原生界面实际观察到单一工作台/助手、完整原文和旧归属标注。输入未发送草稿，切到第二章再回第一章，点击台词打开检查器再返回，草稿保持。历史中可打开旧“分析本章”会话，显示只读说明及原消息/结果，不含可编辑输入框。

真实请求明确要求只调用 `read_analysis` 读取既有归属，不重新分析或修改。发送后立即切到第二章，运行目标仍为第一章；实际工具完成并给出第一页 5 段的状态说明。该次执行约 19 秒（数据库首尾时间），**2 次模型请求、1 次只读工具**；最后一次模型请求报告 input 3045、output 181、cached input 0。这是最后一次请求的用量，不能当作两次请求总 token 或已知金额。

宿主读回：运行结束等待输入、活动任务 0，旧 5 次执行保留，新增 1 次工程助手执行；没有该次运行发布的分析版本，既有分析 revision 7 / humanRevision 6 保留；354 字节来源文件的 SHA-256 与保存摘要一致。原生控制首次按路径连接超时，随后按 bundle identifier 成功；失败尝试没有计为验收通过。

最终调试包重新打开后，会话、既有归属及“上下文 · 第一章 灯下”标记恢复。切到第二章后标记仍指向第一章，点击可返回并选中第一章。重开后的只读数据库复核仍为 6 次执行、活动任务 0，分析 revision 7 / humanRevision 6 未变，354 字节来源摘要一致，没有自动重放模型请求。

## 验证边界

本轮真实模型样本验证了统一助手的只读工具与切章上下文；自然语言调用完整归属分析的跨阶段发布由真实 Worker/可控服务验证。本轮没有再次用真实模型完成“自然语言启动分析→候选采用→撤回”的整条链；原归属引擎此前的原生/模型闭环见[原验收](chapter-analysis-validation.md)，不能把两者合称本轮新流程的完整真实模型验收。

本轮原生为中文浅色；中英亮暗和小窗口的矩阵属于浏览器自动化。其他操作系统、其他模型、长书语义质量、复杂歧义和实际费用未新增实测。声音映射、演绎和音频制作不在本次交付范围。未发布应用；完成规格已于 2026-11-08 同步并归档，Git 交付以提交记录为准。
