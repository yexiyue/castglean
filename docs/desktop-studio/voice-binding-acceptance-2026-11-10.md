## 本轮验收修复

- 用服务商模型标识查推理目录，避免内部配置 ID 导致档位入口消失；异步历史快照首次到达时恢复冻结档位。
- 修复思考菜单标题缺少 Base UI 分组上下文导致的路由异常；模型和档位的单选操作显式关闭菜单，避免遮罩阻挡下一次点击。
- 用户明确选择模型/档位即确认该配置；隐式配置漂移仍须确认。确认入口移至各工程页面都可达的助手区；不支持原档位时明确提示回落。
- 选角历史/运行目标显示选角语义，不标成全书分章结构。
- 通用候选卡增加独立操作区，设计绑定不再被包进“用模型试声”弹窗；目标键按字段构造，不依赖对象属性顺序。
- 修复真实资产存在时的并行目录读取竞争：底层 inventory 使用非等待文件锁，宿主将同进程读取排队，并在 blocking worker 中执行。新增八线程并发读取回归；最终包携真实资产重启后角色中心读取通过。
- 角色列表和详情通过目录解析库音色名称，不把资产 UUID 当作正常显示名。

最终自动化：336 项宿主库测试、2 项集成测试通过，7+2 项外部条件测试按配置跳过；Clippy 全目标与 rustdoc 均 `-D warnings` 通过。47 项 Node 测试通过（其中播放/试听/候选卡 11 项），前端生产构建、Biome、配置确认及推理档位浏览器回归通过。此前 29 项 Python 评测脚本测试通过，本轮未改评测实现。两个活动变更和声音绑定主规格另经严格校验。原生最终包已包含名称显示修复；没有提交、推送或发布。

新增档位浏览器回归覆盖中文/英文、浅色/深色及 1024×680 窗口：目录用服务商模型 ID、打开菜单、发送 high、切到不支持模型后提示回落。配置确认回归覆盖角色中心可达、显式选择与草稿保持；候选卡回归确保绑定操作不用打开试听设置。
