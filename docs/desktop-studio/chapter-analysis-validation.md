## 真实模型公开短章

显式模型：`zcode/GLM-5.3-Flash`；本地 OpenAI 兼容网关 `127.0.0.1:3425`。使用测试专属连接与配置修订，不修改用户连接、不访问私人小说；输入为六行公开合成“灯下”短章，两个人物、一段内心独白和无法辨认的第三个声音。

首次诊断记录：HTTP 200、finish_reason=stop，但网关未执行输出 Schema；模型还混淆绝对字节与标量位置，产出自定义字段并误判缺失正文。严格解析拒绝，未发布版本。旧 120 秒探测期限也不适用于后台分析，现分离为探测 120 秒/后台 600 秒。不是放宽输出长度或自动修复重试。

修正后手动执行 opt-in 测试：**通过**。用时 **50.278 秒**，服务商报告输入 **2052 tokens**、输出 **3115 tokens**、缓存输入 **0**。未提供价格，因此不推算金额。10 个片段覆盖全部原文字节，均未审阅：

- 标题、动作引导及末句为旁白。
- “小舟，雨停了。”归阿岚；“我听见了。”归小舟。
- “也许我们能赶上末班车。”为阿岚内心独白。
- “等等我！”保留未知，不创建假定角色或回退为旁白。

结构/范围/来源校验由宿主执行；以上类型和归属由本次公开短章人工抽样核对。不能据此声称长书、同名角色、复杂歧义或其他模型语义质量通过。

复现（会调用选定真实服务，正常测试不自动运行）：

```sh
CASTGLEAN_REAL_ANALYSIS_ENDPOINT=http://127.0.0.1:3425 \
CASTGLEAN_REAL_ANALYSIS_MODEL=zcode/GLM-5.3-Flash \
cargo test --manifest-path src-tauri/Cargo.toml --lib selected_real_model_public_chapter_acceptance -- --ignored --nocapture
```

## 原生桌面验收

**通过**：macOS 26.6.2 / arm64，真实 Tauri/WKWebView 打包应用，中文亮色窗口。使用相同源码、独立 identifier `com.yexiyue.castglean.acceptance` 和独立数据目录，不操作既有小说工程。只复制本地匿名 GLM 模型条目，清空 probe 历史，不复制凭据。最初按显示名命中旧包，已重新构建并用具体 bundle 路径连接当前包；全局控制枚举超时不能代替应用级连接验证。

实际窗口闭环：真实文件选择器导入两章公开 TXT→UTF-8 确认/自动分章→首章分析→分析期间切章再返回→明确继续后保存整章初稿→角色确认/同名候选本章复用→人工修改说话人并确认→原文证据及版本历史查看→退出/重开并检查人工结果→重分析候选→人工冲突默认不选→明确选择并采用→模型归属显示为未审阅→撤回为原来的人工确认→最终包再次人工修改/撤回→再退出/重开并核对。原生文本域草稿在检查器/助手切换后保持，上下文窗口未知时显示未知，不伪造用量比例；请求未附加输出 token 上限。

原生发现并修复：

- 模型把已确认角色 UUID 重复列入新人物声明。捕获的公开响应原文覆盖和归属引用合法，但新人物声明违反宿主契约；未放宽校验，给生成 Schema 补上 `^new:`，明确没有新人物时 `characters:[]`，窗口记录推进至 4。修正后真实请求携带新约束并成功生成候选，差异仅为“台词 · 未知 → 台词 · 阿岚”，人工冲突默认不勾选。
- 撤回数据正确但检查器暂留旧片段。成功回读后清理选中/证据，并阻止已切章的保存回读覆盖当前章；浏览器覆盖“选中已采用片段后撤回”和“迟到保存时切章”，最终原生包也验证撤回立即显示选择提示，再选择原文即为恢复的“未知 / 人工已确认”。
- 角色复用推进修订后，旧检查器的保存被乐观锁拒绝，草稿保留，明确重新读取后保存成功。确认角色没有自动确认片段。同名“小舟”由模型提出两个候选，未自动合并，经显式本章复用；这是模型身份抽取质量问题，不能声称身份语义完美。
