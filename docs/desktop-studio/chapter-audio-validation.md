# 章节音频验证

章节生成按冻结计划顺序执行，每个单元音频落盘后更新状态；完成后拼接整章。片段可就近起播，播放中跟随当前单元；模型资源或文本算法版本变化时不混合续跑。

自动化检查覆盖生成前阻塞、单元切分、失败与取消、续跑身份、音频落盘及播放时间轴。TaleChime 的 Kokoro g2pW 与英文神经后备已在 macOS CPU 上生成公开中英混排样本并验证有效 PCM；这不证明整章听感。

系统化原生窗口验收尚未完成：需验证生成、进度、逐段及整章播放、暂停与切换章节、取消、重启恢复、互斥，以及小窗口和中英文亮暗主题。人工听感、其他平台和不同模型各自验证。

显式真实模型测试默认跳过，需预先准备模型资源：

```bash
CASTGLEAN_MODEL_ROOT="$HOME/.cache/huggingface/hub/castglean" \
  cargo test --lib real_kokoro_generates -- --ignored --nocapture
```

可通过 `CASTGLEAN_AUDIO_OUTPUT` 指定新 WAV 输出路径。
