# 章节音频验证

章节生成按冻结计划顺序执行，每个单元音频落盘后更新状态；完成后拼接整章。片段可就近起播，播放中跟随当前单元；模型资源或文本算法版本变化时不混合续跑。

自动化检查覆盖生成前阻塞、单元切分、失败与取消、续跑身份、音频落盘及播放时间轴。TaleChime 的 Kokoro g2pW 与英文神经后备已在 macOS CPU 上生成公开中英混排样本并验证有效 PCM；这不证明整章听感。

系统化原生窗口验收尚未完成：需验证生成、进度、逐段及整章播放、暂停与切换章节、取消、重启恢复、互斥，以及小窗口和中英文亮暗主题。人工听感、其他平台和不同模型各自验证。

显式真实模型测试默认跳过，需预先准备模型资源：

```bash
CASTGLEAN_HUB_CACHE="$HOME/.cache/huggingface/hub" \
  cargo test --manifest-path src-tauri/Cargo.toml --lib real_kokoro_generates -- --ignored --nocapture
```

可通过 `CASTGLEAN_AUDIO_OUTPUT` 指定新 WAV 输出路径。 该路径必须是尚不存在的绝对路径；测试使用临时应用数据与缓存，只读取指定的 Hub 缓存。

2026-11-14：macOS arm64、Kokoro 1.1-zh-g2pw CPU、已就绪共享缓存，公开自撰样文生成 13 个单元、约 82.1 秒；加载约 4 秒，合成约 118 秒。逐单元检查顺序、覆盖范围、24 kHz 单声道 PCM 和非静音峰值，并核对整章时长。这是宿主合成测试，预先构造计划，不覆盖真实导入、分析、绑定、原生切章或导出，也不代表人工听感。

同日扩展并重跑该测试：在临时数据库中构造分析和绑定记录，将真实生成的音频经宿主停顿编辑加入 0.75 秒，经播放计划和 WAV 写入函数导出；检查停顿条目、导出时长和 24 kHz 格式。13 个单元约 82.1 秒，加载 3.96 秒、合成 117.39 秒；仅使用已有模型缓存。此为宿主函数级集成，分析与绑定记录仍为夹具，未经过真实导入、分析服务、原生播放、文件选择器或人工听感。

另以自撰公开文本和独立临时工程执行同一宿主链路：实际文件冻结与导入、本机模拟服务驱动的分析、真实绑定事务、已就绪模型目录预检、Kokoro CPU 合成、停顿播放计划及 WAV 写入，确认输出非静音且原文不变。分析服务响应和绑定目录为夹具；未测试真实远程分析服务、原生文件选择器、跨章播放或人工听感。

## 2026-11-13：角色正文、音频轨道与停顿编排

`chapter-audio-workbench` 已接入宿主与真实工程路由：有效分析后采用固定角色列的归属片段布局，未分析继续紧凑/原样阅读；底部按计划显示音频块与占位，提供真实执行位置、取消/继续及正文双向定位。未知时长阶段只按顺序布局，完整后才有真实时间刻度。音频片段顺序固定，缺口停止，不跳过丢失产物。

停顿是边界上的额外静音：拖入、移动、拖边调时、数值输入、键盘移动/调时、删除与最近修改撤销共用宿主命令。默认 0.5 秒、0–10 秒、10ms 步长；0 表示删除。停顿在正文边界及轨道同时显示，右侧统一编辑；拖动结束提交，Escape 放弃预览。声音或分析已变化时旧音频保留，但编排不可直接继续编辑/导出；续跑条件变化需要明确生成新版本。播放与导出冻结各自编排修订。

自动化证据入口：

- `chapter_audio::store::tests` / `database::tests`：执行位置与单调修订、schema v7→v8 保留数据与迁移回滚、停顿回执、并发修订、跨工程拒绝、撤销重开、声音变更失效、缺口及摘要限额。
- `chapter_audio::playback::tests` / `chapter_audio::export`：真实 PCM 静音、采样帧取整、音频/静音/音频顺序、总时长、损坏与格式冲突、磁盘满写入错误、不可写父路径、目标被其他进程修改、取消不发布半成品。
- `tests/source-selection-browser.mjs`：实际角色布局及同一原文行的多角色、跨行逻辑块、原始 Unicode/CRLF、角色与停顿标记排除、选区书签恢复；连续阅读和章界测试继续独立执行。
- `tests/chapter-audio-state-browser.mjs`：实际生成 hook 的迟到查询、旧事件、终态和切章期间迟到启动响应；`tests/chapter-player-browser.mjs`：真实 hook 的连续区间冻结、跨文件/静音定位及互斥。
- `tests/chapter-real-media-browser.mjs`：浏览器播放真实 PCM WAV 和静音，验证静音内部 seek、暂停、后台保持与恢复进入下一单元。声音是公开合成正弦夹具，不证明模型听感。
- `tests/chapter-audio-workbench-browser.mjs`：实际路由合成 IPC 的生成占位、逐单元进度、停顿插入/拖边/键盘/撤销/失败保留输入、导出入口、中英×亮暗×宽窄八组截图、一万单元轨道虚拟化及手动浏览暂停跟随。截图在 ignored `src-tauri/target/workbench-acceptance/audio-track/`，只含公开合成文本。

原生边界：本轮桌面控制接口连续两次初始化超时，未取得真实原生窗口可操作证据，不推断其原因或会话是否锁屏。系统化原生生成→试听→停顿→导出闭环、真实模型听感和其他平台保持未验收；不能凭上述浏览器/PCM/宿主证据勾选任务 6.1 或 6.2。未发布应用或 SDK。

轨道摘要仅对可见窗口读取最多 128 个前缀、每项最多 80 字符，按已发布不可变来源的摘要路径与字节范围 seek，不为滚动重新读取整本正文；摘要不能作为修改或合成授权。执行入口仍完整校验来源摘要。UTF-8 截断、非法范围和输出限额有宿主测试，正文阅读器的原有整体验证策略保持。

## 2026-11-13：清库后真实小说原生流程（部分完成）

用户明确授权重置主应用及五份验收数据库。关闭宿主、取得运行锁后，先通过 SQLite backup API 生成六份完整备份并逐份检查 `integrity_check = ok`，再清理对应数据库及 sidecar；共享权重、来源文件、音色和连接配置保留。

原生调试包实际导入本地 UTF-8 小说，生成一份来源、500 个章节与一个前置目录项。导入后的原始来源摘要与用户文件一致。第一章通过已有连接完成真实归属分析，耗时 201 秒、两次模型请求；结果包含七个候选身份与一处预审疑点。章节界面已观察到固定角色列与逐段正文；旁白预置音色绑定持久化，重启后工程、分析及绑定保留。生成前检查列出五个未绑定的对话角色，未错误启动合成；已确认其中一个角色身份。

模型目录原生读取为 11 个模型、6 个就绪；盘点性能修复与观测耗时见[开发构建哈希记录](../knowledge/lessons/dev-model-inventory-hashing.md)。角色中心保存身份、绑定和画像后只刷新工程数据，首次进入、手动重试及音色入库后继续读取资源目录，避免每次工程修改重新校验全部权重。

用户解锁后继续完成五个发声角色的身份确认与预置声音绑定，旁白加角色共六个绑定，覆盖四个 Kokoro 预置音色。保存后未再等待完整模型盘点。原生生成计划包含 166 个单元（149 个有声、17 个空白）；取消后保留四个已完成单元，片段可起播/暂停；续跑保留同一任务身份并继续推进。生成中可从轨道边界打开停顿编辑，保存 0.75 秒后正文与轨道同步更新，支持最近修改撤销。

真实失败边界：任务在第 23 个单元失败并保留前 22 个单元，原因为 Kokoro 不支持全角百分号 `％`。这是引擎显式支持边界（TaleChime 的 `crates/kokoro/tests/mixed_oracle.rs` 有拒绝用例），不修改原文、不跳过失败单元，也不把部分产物当作整章完成。首章失败事实保留；另选不含该符号的章节继续制作闭环。

期间另观察到 AI 队列停止心跳：应用派发器继续提交 Pending jobs，但 run 的 generation 保持 0、没有发出模型请求。重启后同一 queued run 被领取为 running、generation 变为 1，并开始首次模型请求，旧重复派发的 jobs 被安全消费。停止心跳的根因尚未确定，不把重启恢复写成已经修复；后续需覆盖长期运行与睡眠恢复时的 worker 存活和错误可观测。

第二章成功完成 100 个单元（81 个有声、19 个空白），完成后的轨道显示 81/81；整章可起播、暂停和片段导航。生成中切到首章可看到另章仍在后台生成，首章失败与 0.75 秒停顿不被覆盖，切回后进度和第二章的 1.25 秒停顿保留。

原生保存对话框导出成功，WAV 为 24kHz/单声道/16 位 PCM，总长 542.245 秒。逐采样比较原始 `chapter.wav` 与导出文件：指定首单元边界新增 30,000 帧全零静音（恰好 1.25 秒），其余 PCM 字节完全一致。产物及数值检查记录仅放在 ignored `src-tauri/target/workbench-acceptance/native-20261113/`。

原生片段连续播放到队列末尾后回到“播放”和整章就绪状态。用户随后反馈“现在是整章可以生成了，刚刚试听了感觉也还行”；记录为本次样本的用户听感反馈，不外推到全书、全部音色或其他模型。

本轮补充门禁：397 项库测试、2 项集成测试通过，10 项外部条件测试忽略；fmt、全目标 Clippy、前端类型/构建、修改组件的 Biome 及 diff 检查通过。一次增量构建出现 rustc SIGBUS，关闭增量编译后原生打包成功，不能据此断言编译器崩溃根因已修复。

边界：本轮原生证据为中文、1360×900 窗口的上述制作流程；原生指针拖动、中英亮暗及小窗口完整矩阵、人工听感和其他平台仍分别待验，不据此全部勾选 `chapter-audio-workbench` 的 6.1/6.2。私有正文、数据库、凭据和音频产物不入 Git。
