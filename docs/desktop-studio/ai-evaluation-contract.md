# 正式章节分析评测契约

唯一入口为 `scripts/ai_eval/run_production_agent.py`。Rust测试桥直接执行正式C7纯核心、提示词、工具和原生Rig Agent，随后运行独立只读预审；不调用旧JSON/ECS、不写工程数据库。窗口规划、阶段恢复和事务发布由宿主自动化回归验证，不能把本入口称为桌面端到端验收。

输入是JSONL：`caseId`、`source:{text,sha256}`、`characters:[{id,name,description?,...}]`、可选 `aliases` 和 `gold:[{start,end,kind,speakers}]`。坐标是半开UTF-8字节区间。角色上下文原样传给核心，不按显示名匹配身份。发送前全量检查重复用例、来源摘要、角色身份、gold连续覆盖与合法UTF-8范围；gold不传给模型。公开用例在 `evaluations/`，AI标注不是人工真值，私人用例不得进Git。

分析与预审都完成才算交付。评分再次检查片段完整覆盖、合法身份和类型；失败或结构无效时交付字节正确数为零，失败不移出分母。没有gold则语义质量为 `unmeasured`。AI预审只是待核对建议，不自动采用，也不能作为自己的准确率答案。

运行前冻结程序、驱动、用例、配置包装和真实连接配置的SHA256；每例前后检查身份，不一致停止。输出含实现/输入/配置身份、真实分析/预审trace、工具audit、耗时与评分。用量缺失保持未知，缓存是输入子集，不重复相加。身份门禁只证明冻结文件未变化，不证明供应商实际执行了请求的思考强度或语义正确。

凭据只由Rust从系统凭据库读取。驱动只接连接配置路径与模型选择，不覆盖地址、凭据、思考或输出策略。默认思考由供应商能力决定最低档，用户可在前端修改。没有整章时间/累计token配额；正式传输保护和工具防空转约束仍生效。

输出必须位于Git忽略目录，默认诊断不复制正文或凭据。显式评测job/result含授权正文或角色上下文，属于本地私人产物，不能提交或分享原文件。报告区分自动回归、真实服务商冒烟、桌面交互与人工语义验收。
