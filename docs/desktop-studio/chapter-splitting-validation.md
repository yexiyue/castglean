# 整书分章验证记录

日期：2026-11-06。变更 `add-assisted-chapter-splitting` 的桌面主链已验证，仍有故障、容量与平台验收未完成；未发布应用，未归档变更。

## 当前结构

- `llm` 私有模块负责配置、凭据、配置租约、受限 HTTP 和三协议适配。Rig 0.46.0 提供模型单次调用、结构化输出与有界工具循环；应用 DTO 不依赖 Rig 消息类型。
- `novel_import` 负责受控文件选择、严格解码、不可变来源、本地 regex、人工修正及恢复事务。规则重检测与具体行补丁分开：行补丁基于当前目录操作，便携工程重开后改标题不会重新推测全书目录。
- `novel_import::diagnostics` 负责外层 graph-flow 图、预算、工具、候选与显式采用。graph-flow 0.8.1 关闭默认特性与 Rig 消息桥，无 SQLx/PostgreSQL 或另一套 runtime。
- React 使用 AI SDK UI 自定义 Tauri transport。宿主保存事实，前端只显示快照；无额外 Node/HTTP 服务。切页释放订阅，显式“停止”才取消宿主任务。

## 真实 macOS 桌面证据

使用当前源代码构建的临时 Review 应用与独立 Vite 工作副本，未替换正式安装包。用户指定 OpenAI Chat Completions 兼容服务 `http://127.0.0.1:3425/v1`，模型 `zcode/GLM-5.3-Flash`，连接显示名“本地验收”。密钥通过 UI 存入 macOS Keychain；检查非密钥配置未包含密钥明文。独立原生凭据测试验证了唯一测试条目的新建、替换、读取、删除，不触碰用户其他条目。

三个独立探测均在真实桌面通过：文本连接、本地随机 token 工具往返、JSON Schema 输出。探测输出上限为 2048；早期 256 上限曾导致工具探测失败，没有隐式重试。Anthropic/Gemini 只有可控端点证据，无真实凭据，不记为真实服务通过。

本轮只发送公开合成夹具。正文含 BOM、CRLF、CR、LF、中文、emoji 与组合字符，296 UTF-8 字节，SHA-256：

```text
8e2078dc37a1cafbb846025d62cf0e8cb816f580e71362a2a42cc66efb360078
```

桌面主链实际结果：

1. 本地默认检测得到 5 章，`【三】海边` 未识别。
2. Rig 调用目录、上下文、规则测试与候选提交，建议三条规则，产生 6 章。聊天发送“可以”仍不改变 5 章目录；显式点击“采用方案”后才变为 6 章。
3. 独立诊断通过 `patch_boundaries` 建议将显示第 9 行正文设为“清晨抵达”，4 次模型请求、4 次工具调用，生成 7 章候选；显式采用后主目录变更。
4. 保存 `/tmp/整书分章验收.castglean` 并通过原生文件对话框重新打开，7 章、1 卷、1 项人工修正及标题保留。对保存文件检查：解码来源逐字节等于输入；按章节范围拼接逐字节等于完整来源。
5. 诊断中切换“目录与原文”再返回，保持同一请求运行；显式停止后页面显示“已停止”，会话消耗保留为 3/64。
6. 等待输入时退出并重启，重新打开原工程可读到相同 7 章与已采用方案，原诊断仍为 4/64，没有自动发起请求。
7. 已查看中文浅色与英文深色真实界面；临时宿主按 1024×680 初始窗口重建后，检查目录、原文、诊断与恢复入口。IME 组合输入未实测。

部分后续请求曾返回不可用结果，错误记录与现有目录保留；新诊断可成功完成边界补丁。不能据此宣称该模型所有续聊场景均可靠。

## 工具与恢复约定

工具只接受当前来源身份和零基行号，UI 显示行号加 1；不接收路径、代码或可信字节偏移。目录每组 5 条，标题检索每页 10 条，支持到第 2000 页；上下文至多 30 行并按实际 JSON 大小缩减。单工具最多 8 KiB；无法装入的单行显式报超限。`test_rules` 测试完整规则集，`patch_boundaries` 只修改当前目录的具体行，二者均校验完整覆盖；`submit_proposal` 只暂存。没有采用工具。

每轮至多 8 次模型请求、24 次工具调用、600 秒；单请求 120 秒、4096 输出 token，输入 128 KiB、响应 256 KiB；累计序列化输入 512 KiB，工具返回 64 KiB，会话总请求 64 次。请求前记账，错误、重复读取及分页计数；缺失 usage 显示未知。换模型、重启、取消与失败不重置会话总预算。新诊断才建立新预算，旧记录保留。

恢复记录位于应用私有目录，不进入工程与 Git。正文存放在 `sources/<sha256>.txt`；当前文档和单步撤销引用同一不可变 blob。恢复 JSON、图位置、候选、预算和采用回执在同一事务内发布。先发布来源再发布恢复记录；摘要损坏时拒绝覆盖。采用核对来源、基础修订和人工状态，以 session/proposal/命令身份回读回执。规则不进入便携工程；正式工程保存 v2 来源、目录、卷与人工状态，重新打开后的具体行修改保留已保存划分。
