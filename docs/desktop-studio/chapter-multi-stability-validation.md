日期：2026-11-09。状态：来源、边界及无金标评测预检完成，真实执行待运行。用户认可token节省并授权更多《吞噬星空》章节；本次只测隔离实验CLI，不修改应用工程。前一轮工具/上下文优化及全部诊断见[方案C报告](chapter-tool-agent-validation.md)。

## 方法与证据边界

固定使用上一轮C7二进制（代码9c468dd、SHA-256 `8fbfde8bb2d325f45f448c14d2c80b2372d21b9347a9fcd9ae2b7c588484e4f9`），不重新构建或调语义提示/工具。原生helper和模型连接同前轮，模型选择为zcode/GLM-5.3-Flash，实际HTTP须确认low、无token或执行时间上限；16模型/32工具/3次失败校验保护保留，不声称远端网关永不超时。原文只来自与既有授权sourceHash匹配的本地不可变来源，SQLite仅只读提取边界。

在任何模型调用前选定现有ordinal 2、10、50，排除此前反复实验的ordinal 1，不按模型输出选择章节。逐章冻结来源/范围、完整JSON预处理、source-only抽样与所有程序身份。三个全新章节分别3088/3509/3356个Unicode标量、8642/10027/9640字节，保留原始空白；每章使用空人物输入独立发现身份，不测试跨章角色合并或生产恢复。

| 章节ordinal | 三路串行执行顺序 |
| --- | --- |
| 2 | JSON → 当前Agent → ECS |
| 10 | 当前Agent → ECS → JSON |
| 50 | ECS → JSON → 当前Agent |

9个主槽位全部计入计划分母，失败不重跑、不只统计成功耗时。报告min/median/max用于描述三个不同章节的观测，不计算样本不足的P95或宣称重复运行成功概率。JSON无生成预审，Agent含独立预审，分别记录初稿及完整流程；缓存是输入子集，不重复相加。部分用量保留已知字段，未知字段/槽位明确计数，不能伪造零成本。

没有新章节人工gold，不生成语义准确率。主流程质量门槛是宿主UTF8/引用/完整覆盖和合法完成，只能证明结构。每章另做一次匿名独立AI抽查：在原文位置切片中等距固定8个不重复anchor（含首尾），上下文各扩180个Unicode标量；抽样不读取模型输出。只把三路在相同focus范围的标签交叠传入匿名A/B/C，映射按章轮换，原文保持精确UTF8范围。AI可报告kind/speaker疑点或insufficient_context及high/low；名字变体不自动当错，不强求找问题。抽查与生成使用同型号但独立会话，存在同源偏差；疑点不是人工真值，24个focus也不是整章语义覆盖。

抽查最多额外3次请求，调用、用量、耗时单列，不计入主流程提速；若某路线没有完整初稿则该章抽查明确跳过，不补假结果。结构门禁、无gold的语义信号与人工验收分开。全部正文、请求、理由和结果只在忽略的`plan-c/multichapter-c7-v1/`，Git仅保留脚本、测试、方法和脱敏汇总。

## 可复现入口

`scripts/ai_eval/run_chapter_stability.py`复用既有JSON调用、原生校验、工具进程回收和逐章证据门禁；`chapter_quality_audit.py`负责source-only抽样、匿名输入、引用校验及无理由文本汇总。runner在第一个付费调用前预检全部三章并冻结所有快照/样本、二进制/helper/实际连接/协议/driver/审阅器，之后每槽位前后重新核对。与旧单章入口分开，不用伪造gold兼容旧评测。

实际运行需要显式提供target中的授权manifest、C7 frozen binary/config、原JSON协议和新输出目录。每槽位立即保存结果；中断保留计划分母和未知成本，文件漂移或门禁失败停止后续执行并拒比。主统计汇总与独立抽查结果分别保存在summary.json和audit-results.json，后者不是准确率报告。
