## 实现与复现

推荐路线保留 Rig 0.46＋Tokio 宿主：精确预切片和引语上下文 → 冻结人物快照 → 最多两路标注 → 结构校验 → 只读 AI 预审 → 统一发布。新运行使用紧凑协议；旧冻结运行恢复沿用锚点协议。人工保护、来源绑定和租约仍由宿主控制。步骤 journal 保存完成结果与失败请求历史；明确继续复用合法步骤，不在同次运行隐式重发。

阶段诊断记录请求身份、父运行、模型/配置/提示词/协议/来源摘要、实际耗时及服务商用量。默认诊断不含正文、姓名或响应。宿主提供 `chapter_analysis_run_diagnostics` 与 `chapter_analysis_ai_review`；尚无专门前端诊断面板。AI 预审报告不会自动修改标注或人工确认状态。

公共原创固定集为开发 7 例、留出 3 例；规范人物 ID 已提供，角色发现质量不在此评分内。分析与植错预审分进程，均不接收 gold。完整交付、固定单元/逐字节类型＋身份准确率、预审检错/误报、延迟、并发和 token 分开统计；失败保留在计划分母。详见[契约](ai-evaluation-contract.md)和[复现命令](ai-evaluation-usage.md)。数据量很小，答案尚未独立人工复核，不证明泛化。
