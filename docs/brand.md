# CastGlean · 拾角：品牌与资产

版本：1。日期：2026-10-06。

## 名称与定位

英文展示名 **CastGlean**，中文名 **拾角**，仓库与拟议 CLI 名 **castglean**。英文由 Cast（故事人物）与 Glean（拾取线索）组成。正文中使用 CastGlean，路径和命令使用小写 castglean。

定位：有证据的小说角色与台词分析。品牌表达安静、细致、可核对的档案员形象。

中文标语：**从原文拾取线索，让人物与台词有据可循。**

英文标语：**Every character. Every line. Evidence attached.**

标语描述设计方向，不代表当前算法准确率或已交付能力；面向用户的页面必须保留实际项目状态。

## 视觉概念

主标志将展开的书页与猫头鹰合成一个轮廓。两只眼睛采用引号形状，喙采用朱红菱形；折叠页面呼应阅读、角色档案和可引用的文本。

吉祥物名为 **拾拾 / Shishi**。纸页组成身体与羽翼，手持证据卡；个性温和、专注，允许疑惑和查证，不表现成无所不知。吉祥物用于文档封面、空状态和后续教程，主标志用于头像与小尺寸识别。

## 色彩与排版

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink` | `#123D39` | 标题、主轮廓与高对比文字 |
| `paper` | `#F4EBDD` | 品牌底色、纸页与温暖留白 |
| `vermilion` | `#C65A43` | 喙、书签、证据索引等少量强调 |

这些色值是后续实现的目标 token；生成图片带轻微纸质纹理和色差，不用于反向采样定义 token。

展示标题采用有文学气质的衬线风格；正文使用易读的系统中文字体；代码用等宽字体。当前封面文字已栅格化，不附带或要求安装商业字体。不要在小字号正文使用过多装饰字形。

## 文件与使用

| 文件 | 背景 | 建议用途 |
| --- | --- | --- |
| [logo.png](../assets/brand/logo.png) | 透明 | 项目标志、头像与应用图标的基础稿 |
| [mascot.png](../assets/brand/mascot.png) | 透明 | 文档插图、教程、后续产品空状态 |

| [manifest.json](../assets/brand/manifest.json) | JSON | 原始尺寸、透明状态、文件摘要与生成来源 |

标志周围保留至少约四分之一标志高度的留白，避免裁掉书页尖端。保持长宽比，不横向拉伸。照片和复杂纹理上优先增加纯色承托区，不叠加发光或渐变。

小尺寸优先使用主标志，不使用完整吉祥物及证据卡。当前提供 PNG 原稿，尚未提供手工矢量重绘、字体文件或多尺寸 favicon；未来按实际载体制作并验收。

封面适合横向展示，但不是已上传的 GitHub social preview。若后续设置仓库 social preview，应另按平台尺寸与文件限制制作，避免自动裁切遮住名称。

## 文案规则

使用“角色分析”“台词归属”“原文证据”“人工修正”。结果不确定时明确表达未知或候选，避免“百分之百识别”“零幻觉”等未经验证的宣传。界面能力与研究路线均以实际交付状态为准。
