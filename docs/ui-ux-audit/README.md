# 桌面界面与交互问题清单

记录日期：2026-11-13。本文汇总当前已发现的问题，供后续讨论和排期；不是功能规格，也不表示已修复。详细操作和组件盘点见[组件与交互审计](../desktop-studio/component-interaction-audit.md)，候选方向见[制作体验设计](../desktop-studio/production-experience-design.md)。

后续设计采用用户已选的[静阅青设计系统方案](../desktop-studio/design-system-proposal.md)，其中将下列问题映射为组件与交互验收条件；[Tailwind 约束调研](../research/tailwind-design-system-governance.md)记录样式纪律与 Typeset 接入边界。方向选择不表示本清单的问题已修复。

证据主要来自 macOS Tauri 开发窗口、当前工作区源码及隔离工程。隔离工程使用自造文本、本机合成分析响应和已安装的 Kokoro 模型；真实生成不代表全书听感或分析质量。临时截图和音频可能包含本地数据，不纳入仓库。以下优先级是建议，修复前须核对当时的代码和运行状态。

## 待验证，不作为已确认缺陷

- 模型详情与音色列表往返、嵌套确认层及鼠标关闭后的焦点：自动化路径出现过差异，需原生输入和读屏复测。
- 语言切换时曾观察到当前章变化，但后续重复切换保持原章，期间开发页面发生重载；原因未确定。
- 动效减少偏好、真实 WebView 性能、包体和跨平台表现；Motion 及其他候选库尚未在本项目集成验证。
- 音频多单元拖动、生成取消、失败恢复、导出失败；声音绑定冲突；模型下载、磁盘不足和多音色包部分结果。
- 全页面的中英文、亮暗、最小窗口、真实键盘和读屏矩阵。当前证据不能代表这些组合全部通过。

## 已验证的边界

隔离工程在无文本模型时可以导入并阅读；部分导入重试没有重复写入已成功的来源。目录已验证大列表的 Home/End、分组展开收起、过滤回退和无结果清除的部分路径。旁白绑定在切章后保持；隔离合成样本完成过单单元和双单元生成、WAV 导出及停顿键盘微调。这些只是对应路径的证据，不覆盖真实模型归属质量、所有错误或人工听感。

组件调研以现有 shadcn/Base UI 为基线，Motion、React Aria、TanStack Virtual 和 `react-resizable-panels` 均为候选；能力、取舍与官方来源见[组件调研](../desktop-studio/component-interaction-audit.md#候选组件能力与取舍)。
