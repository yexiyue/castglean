# 桌面界面与交互问题清单

记录日期：2026-11-13。本文汇总当前已发现的问题，供后续讨论和排期；不是功能规格，也不表示已修复。详细操作和组件盘点见[组件与交互审计](../desktop-studio/component-interaction-audit.md)，候选方向见[制作体验设计](../desktop-studio/production-experience-design.md)。

后续设计采用用户已选的[静阅青设计系统方案](../desktop-studio/design-system-proposal.md)，其中将下列问题映射为组件与交互验收条件；[Tailwind 约束调研](../research/tailwind-design-system-governance.md)记录样式纪律与 Typeset 接入边界。方向选择不表示本清单的问题已修复。

证据主要来自 macOS Tauri 开发窗口、当前工作区源码及隔离工程。隔离工程使用自造文本、本机合成分析响应和已安装的 Kokoro 模型；真实生成不代表全书听感或分析质量。临时截图和音频可能包含本地数据，不纳入仓库。以下优先级是建议，修复前须核对当时的代码和运行状态。

## 优先处理：制作流程受阻或状态误导

| 编号 | 问题与证据 | 用户影响及处理方向 |
| --- | --- | --- |
| P1-01 | **章节模型配置入口失效。** 未配置文本模型时，选择模型菜单中的“服务连接”经点击和键盘激活均只关闭菜单；右上角设置正常。当前菜单项使用 `onSelect`，Base UI 1.9 文档使用 `onClick`，但尚未以修复实验确认因果。 | 用户在分析阻塞处无法直达配置；修复入口并验证返回章节与焦点。源码：[model-picker.tsx](../../src/components/ai-elements/model-picker.tsx)。 |
| P1-02 | **切章会停止当前播放。** 隔离样本播放约 4 秒的音频时切章，媒体在约 0.15 秒处暂停，第二章也没有原播放会话的控制入口。 | 浏览和播放上下文相互干扰；需先确定切章后的播放策略，再清楚呈现播放目标和控制。源码：[use-chapter-player.ts](../../src/hooks/use-chapter-player.ts)。 |
| P1-03 | **分析失败与读取重试混淆。** 隔离服务不可达时，顶部提示“重试读取”，助手另提供“继续分析”；点击前者只移除顶部提示，任务仍未完成，恢复服务后通过后者才成功。 | 用户可能误以为已经重试任务；应分别表达连接失败、读取重试和任务续跑，以及保留结果和可能费用。源码：[imported-workspace.tsx](../../src/components/projects/imported-workspace.tsx)。 |
| P1-04 | **部分导入后返回章节的地址不稳定。** 两个文件成功、第三个重复文件失败；移除失败项并“返回章节”后显示工程，但地址仍为 `/new`，刷新回到空导入页。已提交工程仍可从最近工程打开。 | 工作上下文在刷新后丢失；返回时应有稳定工程地址，同时保留已导入来源。源码：[new.tsx](../../src/routes/new.tsx)。 |
| P1-05 | **制作结果页否认已存在能力。** 真实工程结果页称声音绑定、生成和导出尚未接入，而章节工作台已有这些入口。 | 用户无法判断实际可用功能；应区分章节能力与尚未提供的工程级结果管理。源码：[project-workspace.tsx](../../src/components/projects/project-workspace.tsx)。 |
| P1-06 | **静态示例与真实工作台分叉。** 示例使用独立组件与静态状态，部分确认操作已过时。 | 示例不能可靠反映真实流程；后续应明确示例入口、数据隔离和替代路径，再移除独立工作台。源码：[chapter-workspace.tsx](../../src/components/workspace/chapter-workspace.tsx)。 |

## 制作流程与恢复

| 编号 | 问题与证据 | 建议方向 |
| --- | --- | --- |
| P2-01 | 导入预览的首、中、尾样本没有位置标签，短文件样本重叠，看起来像重复正文。 | 标明样本位置和重叠关系，区分编码预览与实际分章。 |
| P2-02 | 多文件编码失败只在顶部显示通用错误；文件编码选择和移除按钮名称相同。部分提交失败时，已完成文件从待处理列表消失，错误合并了版本冲突和重复正文。 | 错误关联文件名；明确成功和待处理项、可用恢复动作，并为每个控件提供可区分名称。 |
| P2-03 | 手动分章确认层没有具体行号或目标上下文，初始焦点位于确认按钮；结构撤销藏在更多菜单，旁边的分析撤销按钮可能处于禁用状态。 | 确认前展示目标与影响，明确取消；区分结构撤销与分析撤销。已有人工记录和音频时的影响尚未实测。 |
| P2-04 | 生成前阻塞会说明“尚未分析”，但阻塞提示本身没有直接前往分析或配置的动作。 | 将缺少条件与对应解决入口放在一起，不自动启动任务。 |
| P2-05 | 正文片段开始播放后，底部显示“暂停”，正文按钮仍显示播放图标和“播放此片段”。 | 各入口应表达当前可执行动作，并使片段可辨认。 |
| P2-06 | 停顿编辑器预填 0.5 秒但未保存，没有常规保存按钮；输入 11 秒后仅提示未保存，未显示范围错误，关闭后无效草稿消失。0.75 秒失焦保存、方向键加 0.01 秒和撤销在隔离样本中通过。 | 明确保存时机、0–10 秒范围、错误与关闭草稿的处理；有效草稿经模拟点击关闭时的丢失尚需原生指针复核。源码：[chapter-pause-editor.tsx](../../src/components/projects/chapter-pause-editor.tsx)。 |

## 待验证，不作为已确认缺陷

- 模型详情与音色列表往返、嵌套确认层及鼠标关闭后的焦点：自动化路径出现过差异，需原生输入和读屏复测。
- 语言切换时曾观察到当前章变化，但后续重复切换保持原章，期间开发页面发生重载；原因未确定。
- 动效减少偏好、真实 WebView 性能、包体和跨平台表现；Motion 及其他候选库尚未在本项目集成验证。
- 音频多单元拖动、生成取消、失败恢复、导出失败；声音绑定冲突；模型下载、磁盘不足和多音色包部分结果。
- 全页面的中英文、亮暗、最小窗口、真实键盘和读屏矩阵。当前证据不能代表这些组合全部通过。

## 已验证的边界

隔离工程在无文本模型时可以导入并阅读；部分导入重试没有重复写入已成功的来源。目录已验证大列表的 Home/End、分组展开收起、过滤回退和无结果清除的部分路径。旁白绑定在切章后保持；隔离合成样本完成过单单元和双单元生成、WAV 导出及停顿键盘微调。这些只是对应路径的证据，不覆盖真实模型归属质量、所有错误或人工听感。

组件调研以现有 shadcn/Base UI 为基线，Motion、React Aria、TanStack Virtual 和 `react-resizable-panels` 均为候选；能力、取舍与官方来源见[组件调研](../desktop-studio/component-interaction-audit.md#候选组件能力与取舍)。
