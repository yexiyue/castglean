# 人物归属标注政策 v1

本政策用于独立评测，版本为 `attribution-v1`。结构通过应用校验只表示格式有效，不保证语义正确。标注只依据本章可见原文，不补写背景、说话习惯或常识剧情。

## 身份与称呼

人物身份是同一个可追踪的人，姓名与别名只是称呼。姓名相同不代表同一个人；明确“又名”“大家叫他”等共指依据才能合并不同称呼。书名、地名、口号、拟人化风声等不建人物。原文中出现且可追踪的人物均列入角色表，包括没有发言的人。

匿名人物有明确人物锚点（如唯一的红衣旅客、柜台后的店员）且后续可持续指向时可以创建身份，显示名采用原文称呼，不能根据一句台词虚构“说话者”“未知人物”等占位。没有人物锚点的楼外喊声不创建人物。允许称呼来自原文姓名、明确别名或完整描述；不容许为提高匹配率加入泛化的新名称。

身份提及记录原文 UTF-8 字节区间，区间指向姓名、可靠指代或人物描述；解释其指向的理由。明确群体提及可作为每个成员的锚点，但可能产生等价身份匹配，此时报告上下界。称呼不承担身份区分的全部责任。

## 表达类型与边界

`narration` 是叙述、动作、人物提示语等。`speech` 是向外说出的语言，包括来源未知的对白；来源未知不能改成叙述。`thought` 是明确标识的内心语言，不能把一切情绪叙述当作思想台词。`quoted_text` 是书名、牌匾、纸条、术语等非发言引文，不能仅凭引号识别对白。

本基线引号及其内部标点归入表达，发言提示语和引号外标点归叙述。无引号的连续发言若原文明示仍在发言，则整个发言句归入 speech。全文连续覆盖，无空洞或重叠，边界须为 UTF-8 字符边界。评分允许不同分段，但按字节交叠评估类型，表达单元所有交叠部分必须一致正确。

## 归属状态

| 状态 | 必要条件 | 禁止推断 |
|---|---|---|
| resolved | 表达唯一指向一个有原文锚点的身份；可靠的唯一指代或明示持续发言均可 | 最近姓名、轮流对话、某人在场本身不够 |
| ambiguous | 原文明示来源范围，能限定至少两个具体身份，候选必须完整 | 从在场名单猜候选；遗漏明确候选 |
| unknown | 原文无法限定具体来源，或没有可靠的人物锚点 | 虚构人物以强行确定归属 |

同一句表达不能因为模型置信度高而确定归属。原文明示“只可能是甲乙之一”标 ambiguous；只说远处有人喊而没有具体身份限定则 unknown。匿名身份唯一可追踪时允许 resolved。未能区分的同名人物可 ambiguous，不能按提及先后随意指定。

每个 resolved/ambiguous 表达须有原文证据片段引用；人物证据须覆盖身份提及。评测元数据说明理由，不进入生产提示词。非表达叙述与非对白引文不带归属。

## 冻结与复核

四十例为原创公开短场景，十类各四例，开发及留出各二十例，叙事结构不同。先核对规则和摘要再调用模型。冻结文件记录正文、角色表、标注、元数据及本政策摘要。发现缺陷升级评测版本并公开说明，不能追着结果改答案。原六例和历史报告保留为独立历史组，不并入本基线。
