# TaleChime 独立联调原型退役记录

日期：2026-10-31。状态：历史记录，不是可运行产品或当前集成入口。

## 整理决定

项目转为桌面应用优先：先完成正文、试听、修改、候选和导出的制作闭环，再按具体缺口补齐 CastGlean 与 TaleChime。原独立 `integrations/talechime` library + CLI 不再作为并行交付维护。

原型当时尚未提交。本次整理先将源码、锁文件、样例、测试、布局补丁、专用输入脚本及其测试、对应 OpenSpec 变更迁至仓库外的本机备份，并核对迁移文件 SHA-256；备份位置随本次工作交付。当前仓库不依赖该本机备份，其他机器也不能据本文直接构建旧原型。

移除专用跨仓库 CI、忽略规则和补丁行尾规则。保留根 workspace 的分析库、CLI、通用评测脚本、交接契约与测试。没有修改相邻 TaleChime checkout、模型权重、私人小说或既有音频输出。

原 `talechime-audiobook-integration` 变更随原型迁出，不同步为仍在提供的主规格；这次不是将退役能力归档为现行支持契约。后续桌面变更根据真实需求重新定义宿主能力。

## 保留的证据

[2026-10-10 首章联调记录](verification.md)保留输入摘要、环境、导出指标、失败实验与验收限制。其中路径、命令、CI 和“已通过”均属于当时状态，不是本次重新运行的结果。

## 值得带入桌面实现的经验

- 已保存的分析快照可以独立用于音频实验，调试声音不必重复调用文本模型。
- 角色 ID 与声音绑定分开，未知、歧义和未绑定情况使用显式回退。
- 合成单元不能任意硬切；标点独立成段、上下文过短和指令差异都可能影响生成。
- 只有分析、语音完成和文件 finalize 都成功后才能发布正式结果；候选失败应保留旧版本。
- 取消测试不能证明 GPU 原生调用可以立即中断；部分失败与资源释放需要可观测。
- 完整 WAV、有效样本和覆盖正确不证明归属语义或听感正确；真实增量整章、听感与恢复仍需重新验收。

这些是迁移参考，不承诺原实现可以直接用于桌面工程。当前产品入口见[桌面企划](../../desktop-studio/README.md)。
