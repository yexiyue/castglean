# 阶段 B 模型分析基线

日期：2026-10-06。本报告记录一次小样本工程基线，不是一般小说准确率承诺。

以下记录此前普通文本 JSON 及 low 思考对照；后来增加的 JSON mode、Schema、单工具传输实验另见 [结构化输出验证](structured-output.md)，不混入历史统计。

## 配置与口径

实际调用模型为 `bigmodel::glm-5.3-flash`，来自用户授权迁移的 comfy-agent 本地配置；默认示例仍沿用其代码默认 `glm-4.6`。使用 BigModel Coding Plan 端点、genai =0.7.0-rc.1，普通文本 JSON，无工具调用或自动重试。

公开样例使用提示词版本 1、切片版本 1、默认预算：160 字符片段、3000 字符目标窗口、两侧各 3 片段、最多 32 请求、每请求 8192 输出 token 和 120 秒超时。已有测试替身证明流程边界，下面的数字来自真实远端调用。

人工标注中的 speech/thought 为计数单元。输出分区可不同，按 UTF-8 范围重叠对齐，要求覆盖该单元的输出类型与归属全部符合人工样例。跨独立运行 ID 不相同，样例按显示名和候选名的多重集合对照；这个简化口径不能证明通用身份匹配正确性。同名歧义仍要求保留两个独立候选。

表达类型另按全部正文的 UTF-8 字节加权，检查混入叙述的宽泛 thought 范围。这里只对照固定人工样例，证据正确性尚无独立人工金标准。

## 公开样例结果

| --- | --- | --- | --- | --- | --- | --- |

合计：归属及表达联合正确 3/4（75%）；已确定结果正确 2/2（100%）；unknown 比例 2/4（50%）、ambiguous 0/4。总请求 3，输入 2007、输出 3918 token，三次各自耗时之和 70.140 秒。模型在同名样例中未建立两位独立角色，把应为 ambiguous 的第一句降为 unknown；第二句符合样例 unknown。这个结果说明保守未知可以有效避免错认，但仍需提高角色发现和候选保留能力。

三份产物全部通过完整离线 validate，原文快照字节一致，表达类型字节加权正确 157/157。小样本结果不能外推到真实长章节；未知与歧义不能被当作已确定角色归属。

## 迭代中发现的问题

首次调用已揭示未引号心理活动与前面的叙述混片，以及“我”没有成为已知人物的问题。当前版本在冒号处分段、保留紧邻句末的闭引号，并明确第一人称人物与虚构旁白角色的区别；随后重新运行上述全部公开样例。首次结果未混入最终统计。公开样例均少于 24 片段，后来增加的默认窗口片段数上限不改变其请求内容。

隐式心理活动、复杂嵌套引语和跨窗口身份传播仍需要更多样例。当前只有本次公开样例与真实小说章节的结构测试，不具备已标注大型评测集。

## 用户提供的真实小说

应用户要求，使用其本地小说文件提取开篇第一个正文章节测试。整本文件约 24 MB；本次只取第一章正文，不包含下载页说明及章节标题。输入和所有运行产物均位于被 Git 忽略的本地 runs 目录，不分发正文或模型响应。

该章包含 3552 个原始字符、9944 个 UTF-8 字节，规范化换行后为 3374 字符、9766 字节，确定性切片得到 342 片段。第一轮使用 1000 字符窗口、最多 8 请求、8192 输出 token 和 180 秒单请求超时，发生输出截断；程序拒绝结果且未发布最终目录。随后以 16384 token 和 240 秒超时重跑成功，其他预算不变。未经人工逐句标注，不给出归属准确率。

实际小说测试推动加入默认每窗口最多 24 目标片段的限制，避免大量短段落使 JSON 输出膨胀；可以通过 `--window-segments` 显式调整。成功的第二轮沿用增加该限制之前的窗口划分：999/1000/988/387 字符，102/101/97/42 片段。该轮配置在当前 CLI 中用 `--window-segments 128` 可复现。

## 显式 low 思考等级对照

用户提出高思考等级可能造成开销，批准显式 low、补统计并使用相同章节对照。旧代码只设置 max_tokens，没有设置 reasoning_effort；GLM-5.3-Flash 的官方说明称省略等级默认 max，但旧响应未保存服务端实际等级或推理明细，不能事后证明具体推理占比。[官方说明](https://github.com/zai-org/GLM-5#note)

本次保持原文、书章 ID、提示词版本 1、切片版本 1、1000 字符窗口、128 目标片段上限、两侧 3 片段、16384 输出 token、240 秒超时和最多 8 请求。两次均为 4 个窗口，规范化正文和全部 342 个片段 ID、坐标逐项一致。仅显式修改请求思考等级；模型采样及后续已发现角色的差异仍会改变上下文，不能把全部性能变化归为思考参数的因果效应。
