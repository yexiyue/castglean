# 章节制作后续规划

更新：2026-11-13。状态：整章生成、停顿与 WAV 导出已有中文原生样本，用户试听反馈可用；完整原生矩阵和全模型质量仍待验，见[验收记录](../../desktop-studio/chapter-audio-validation.md)。产品决定见[整章生成优先](../decisions/chapter-generation-first.md)，本页记录依赖和剩余工作，不代替 OpenSpec 或验收。

后续简化已依据本轮操作整理为[真实章节制作后的流程简化建议](chapter-workflow-simplification.md)，其中直接操作减负优先，助手工具卡复用现有能力。下文 2026-11-11 第一阶段条目为历史范围，当前实现以最新验收与该建议为准。

## 当前基础

- 导入、分章、来源不变性、工程自动保存和单一工程助手已实现。
- 章节归属分析、稳定角色、证据与人工修正已实现，见[归属验收](../../desktop-studio/chapter-analysis-validation.md)和[融合验收](../../desktop-studio/project-assistant-validation.md)。
- 声音绑定、画像、选角和设计入库绑定主链已完成 macOS 原生及真实模型验收；采用撤回和显式忽略仍有缺口，见[声音验收](../../desktop-studio/voice-binding-acceptance-2026-11-10.md)。
- 已有语音后端、模型资源与音色短试听，不等于已接入整章音频。
- 整章音频第一阶段代码已落地：宿主构建合成单元并做生成前检查，在引擎线程顺序合成，任务与单元持久化，全部成功后拼接整章 WAV；工作台有“生成本章音频”入口、状态条与播放条。首期只支持同一模型的预置音色（已用 Kokoro `1.1-zh` 验证宿主层）。2026-11-11 按用户真实失败补齐：执行文本规范化（Kokoro 前端拒绝单元内换行与集合外符号）、失败详情落库（`error_detail`，应用日志系统仍缺）、同指纹断点续跑（失败后再点生成不再从头）。界面与命令层未经系统化真实窗口验证。

## 第一阶段剩余

- 真实原生窗口验收：生成 → 进度 → 连续播放、取消、生成中退出后重启、切章不改任务、与试听/资源准备互斥。隔离工程已备好。
- 试听产出音频，评估音质、角色区分度与单元间衔接（当前不插入静音）。
- 未覆盖的测试：命令层并发启动与阻塞不落库、互斥守卫、`analysis_invalid` 阻塞、单元收集上限。
- 用真实模型分析产出的章节再跑一次，确认片段形状与种子数据一致。

## 已决定的下一步

先使用已有分析和角色绑定，由宿主确定性地构建合成单元、解析实际声音、按顺序调用后端、保存音频并按章播放。首个模型组合先验证一章，不先做完整助手目标推进或独立演绎规划。完整性、失败与旧结果保护仍需明确契约。

| 顺序 | 范围 | 需要落实的契约和证据 |
| --- | --- | --- |
| 1. 整章生成 | 前置检查、固定分析/声音/配置、顺序合成、真实进度、取消、持久结果、连续播放 | 独立章节音频 OpenSpec；来源覆盖与顺序、后端长度切分/格式、未知/缺声处理、部分完成与重启核验；真实整章合成与听感 |
| 2. 单章收尾闭环 | 自动重试、修正后安全范围重做、候选采用、WAV 导出；应用级日志系统 | 依赖失效与旧候选保留；缺口/过期导出检查；改错后听见变化（用户发起的同指纹续跑已在第一阶段落地） |
| 3. 助手与界面减负 | 工具卡的决定、任务进度、播放及信息；减少跨页操作 | [助手方案](../../../openspec/changes/assistant-guided-production/proposal.md)复用已落地用例；真实操作习惯验证，短试听只做补充回归 |
| 4. 扩展 | 整书队列、角色级批量变化、发音与演绎、多后端 | 独立规格和实际质量/平台验证，不阻塞首章 |

## 当前交互假设

保留直接“生成本章”和结果播放路径；只展示确实阻塞生成的问题，已有分析不强制重新确认每句。缺声/歧义集中解决或明确选择回退，后台生成不阻止浏览正文。生成完成后容易开始听、定位错误、查看实际配置，比先统一所有页面更优先。

以上是待验证的交互假设。用公开样章记录发现入口、处理阻塞、后台切换、开始播放、定位错误与失败恢复的实际操作，再调整按钮、面板和对话卡。旧“声音绑定仍待独立规格”和“先做短试听助手切片”的排序已由本次决定替代。
