# 章节结构写入恢复

2026-11-14，当前 Tauri 宿主将结构编辑的命令回执与修订写入同一数据库事务；同一命令身份和参数可重放已提交回执。前端不能将 IPC 异常直接等同未写入，也不能用重新读取的目录证明原请求是否提交。

实际工作台的章节标题、分卷、规则、撤销、正文边界以及分章方案采用与放弃共用工程会话中的 [StructureOperationRegistry](../../../src/lib/structure-operation.ts)。结果未知时冻结原身份与参数，阻止另一笔结构写入；明确重试原请求。写入已确认而回读失败时只重新读取。用户可读取当前目录后明确停止核对，界面说明原操作可能已完成且停止后不能继续按原身份重试；草稿保留，旧修订不会自动改写成新修订。

浏览器合成 IPC 验证回执丢失后重放、已确认回读失败、切换路由时迟到回执、两种结构入口互斥和模拟窗口关闭提示。宿主事务回执由 `project::edits` 相关测试覆盖；真实原生窗口故障注入和重启后的恢复未验证。该登记只驻留桌面会话，关闭进程后原请求身份丢失。

方案浮层打开时在浮层中恢复；关闭浮层或离开并返回工程后由工作台恢复。实际路由的合成 IPC 测试覆盖采用回执丢失、切路由同身份重放，以及放弃已确认但回读失败后只读。读取当前目录只是供用户核对的快照，不能证明原操作结果或保证此后没有其他写入。
