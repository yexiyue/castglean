# 章节角色与归属闭环

日期：2026-11-08。适用：Tauri 2 宿主、SQLite schema 3（归属存储由 schema 2 引入）、Rig 结构化章节分析。状态：实现、自动化与 macOS 原生公开样本闭环通过；真实模型错误与未覆盖边界见领域验收。

- [OpenSpec](../../../openspec/specs/chapter-attribution-analysis/spec.md) 规定首个有效分析自动保存待审阅初稿，重分析只产生候选。人工字段和边界受保护，连续源区间差异不依赖模型生成的片段 ID。采用、放弃和撤回都有修订校验及幂等回执。
- 角色身份全书稳定；未确认候选不作为其他章的权威上下文，明确确认后才成为共享知识；本章复用只将本章片段重绑到现有身份，不改其他章或自动确认候选。别名必须有原文出处，名称变化不合并身份。分析依赖实际引用的角色修订，不因其他章无关编辑失效。明确继续保留原始角色上下文，仅校验旧快照中的实际依赖；之后新增的无关已确认角色不会扩充重试输入或使已有窗口失效。
- 模型只处理锚点内 Unicode 标量，宿主转换为绝对 UTF-8。兼容网关可能忽略请求 Schema，提示也携带相同 Schema；不能混合字节和标量单位。模型 Schema 必须反映实际宿主校验：新人物列表的 key 只能以 `new:` 开头，已确认角色 UUID 只用于归属引用。原生公开诊断曾发现模型错误地重复声明已确认 UUID，现同步 Schema/prompt 限制，校验没有放宽。公开样本曾因此失败，拒绝输出是正确边界，不放松校验掩盖协议问题。
- 窗口记录只存范围、锚点摘要和合法结果。全部窗口覆盖并汇总校验才发布整章；明确继续复用兼容已完成窗口，普通聊天、订阅和离页不重发分析。
- 真实项目工作台复用分章目录、章内虚拟阅读和单行工具栏。正文→片段检查器无需聊天；复杂边界/角色/版本操作在独立浮层中完成，不挤压正文。助手草稿按会话保存，普通聊天不改变分析。
- 根据用户最新选择，共享输入改用 shadcn Input Group + 原生 textarea，移除 Tiptap；保留 IME、纯文本、多行、明确发送/停止和模型选择。此决定替代前期工作台笔记中的 Tiptap 方案。执行活动用 Trace，业务结果是独立结果引用，不能伪造为工具执行。

- 原生实测的撤回展示修正：成功回读后清理旧选中与证据；保存回读检查章节身份，迟到命令不能把上一章快照放入新章节。浏览器和最终原生包均验证，业务历史与原文不删除。

2026-11-08 审查补充：局部采用和人工替换按区间差集保留未替换的保护，不能因相交就删除整条保护。范围已变化的重分析形成默认不选的整章候选，明确采用后才更新，新旧范围不做静默标注迁移；旧人工版本保持历史可查，不允许撤回成失效范围。编辑、候选采用和角色证据读取先在写事务外验证正文，再在锁内复核来源绑定及预期修订。

验证、复现命令和未验证边界统一见[领域验收](../../desktop-studio/chapter-analysis-validation.md)，不以浏览器夹具代表原生宿主或模型语义质量。

Schema pattern 的语法依据：[Schemars 官方属性说明](https://github.com/gresau/schemars/blob/master/docs/_includes/attributes.md)。
