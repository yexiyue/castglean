# 紧凑校对与原样显示

日期：2026-11-08。状态：用户已确认并实现，经合成 IPC 浏览器验证；原生 WebView 另验。本决定落实并替代[空白呈现调研](../plans/source-whitespace-presentation.md)中未实施的候选状态。外部依据仍见调研记录，不将本应用数值当成通用规范。

## 显示规则与边界

默认紧凑校对：单空行 12px，多空行 24px，后者显示原始行号范围与数量并能选择首行；定位到组内任意行时高亮整组，但分卷等操作仍取真实定位行。多空行仍是可发现的留白，不将其自动认定为无意义内容。正文沿用应用字体并减少逐行上下内边距；诗歌、ASCII、段首缩进和非空内容不重排。

章节头提供稳定“原文显示方式”选择，工程会话保存 compact/original，跨章保留。原样显示恢复逐行原文排版。单空行选中时显示真实行号；两种模式都不提交工程修改，章节边界、来源 hash/UTF-8 范围及原始文本不变。

[空白元数据](../../../src/lib/projects/source-whitespace.ts)仅用 trim 判别整行空白并记录行范围，不 trim 来源文本。支持原始 CRLF、制表符、全角空格、NBSP/BOM；零宽格式字符不当作空行删除。跨宿主读取块的相邻空白范围合并，跨章/来源不会合并；显示范围随真实补读扩展，不虚构未读取行数。

## 虚拟化与选区

[阅读器](../../../src/components/projects/virtual-source-reader.tsx)按显示模式保存独立高度，空白延续块可为零高度，只从正高度块选取普通视口/邻块，避免全空章把全部原始块都当成可见。缓存仍由 [SourceWindow](../../../src/lib/projects/source-window.ts)控制。空白原文节点在相关块挂载时保留但不占显示高度，组标签不属于 source-line，不能混入复制或引用。

选择跨未挂载/已回收的块时临时保留相应范围并补读，完整后才提供询问；清除选区后恢复普通有限窗口。14 项源窗口/空白测试与浏览器测试覆盖该例外，不把活动长选区冒充常规有限节点数。切换显示时按原行/像素偏移恢复锚点，原生选区保存 anchor/focus 行号及 UTF-16 偏移并恢复方向；补读后重新从真实 DOM 选区提取原文。空白处定位优先保持精确目标，避免多个隐藏行共享像素位置时误锚到组首。
