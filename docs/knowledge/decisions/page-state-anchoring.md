# 页面状态锚定与整页状态外壳

日期：2026-11-15。状态：已实现（集合页状态锚定、路由级状态补回应用外壳、候选面板空态）。

## 背景

应用只有一个空状态组件 `src/components/app-state.tsx`，底层是 shadcn 的 `Empty` 基座：`flex-1 flex-col items-center justify-center`。这在整页状态（404、路由加载失败）是对的，但在集合页是错的：

- 集合页上方是工具栏（搜索框、模型筛选、视图切换），用户刚在那里操作，状态却掉到屏幕中部，离上下文很远；模型盘点要 15–40 秒，这期间页面几乎全白。
- 同一状态在不同页面的形态不一致：模型中心的「没有匹配的模型」有放大镜图标，预置音色的「没有匹配的音色」用了 `compact` 变体所以没有图标。
- `PageShell` 才渲染应用级导航栏，`route-states.tsx` 自己渲染 `<main>`，所以未知地址下整条左栏消失。
- 创建音色的候选面板没有候选时只留一行说明文字浮在空面板顶部。

## 决定

- `AppState` 增加「锚定」形态：内容高度自适应，状态紧跟在上一个元素之后（水平居中、垂直贴顶）；整页居中形态保持不变。
- 模型中心、预置音色、我的音色与音色设计引擎列表的空态、搜索无结果态与加载态一律锚定，同类状态形态一致（图标 + 标题 + 清除或重试动作）。
- 页面未找到、路由加载中、路由加载失败保留应用级导航栏，状态仍整页居中。
- 候选面板没有候选时给出图标、标题、说明与下一步，说明里保留「候选需确认保存后才进入音色库」的约束。

## 取舍

- **不直接改 `Empty` 基座**：基座的居中行为在设置浮层分类、卡片网格等场景是正确的，改基座会扩大回归面；因此在 `AppState` 上加形态而不是动基座。
- **加载态贴顶后视觉更弱**：整页居中的转圈更醒目，但集合页的语义是「工具栏 + 列表」，等待状态属于列表区域，贴顶更贴近上下文。
- **404 补回导航栏后内容列变窄**：状态块仍居中，1024×680 与更小窗口需要复核不横向溢出。

## 验证证据

- 真实 macOS 窗口（2026-11-15）：`/voices?library=preset` 搜索无匹配、`/models` 搜索无匹配与读取中、`/missing`、`/voices/new` 候选面板在 1360×859 下形态符合本决定。
- 自动化：`pnpm test`、`pnpm build`、`pnpm lint` 与目标 e2e 通过；新增 `e2e/workspace/page-state-anchoring.spec.mjs`，用间距与高度断言状态锚定在工具栏下方、用导航栏断言 404 保留应用外壳。
