# Hub 缓存与应用数据分离

2026-11-12，实施中。TaleChime 的固定模型清单按仓库、revision、文件名和 SHA-256 解析共享 Hub 缓存，加载器直接消费资源路径；CastGlean 不再组装模型目录。旧 Hub 缓存下的 `castglean/` 不自动读取、迁移或删除。各模型与识别、音色设计入口已接入固定资源，见[活动变更](../../../openspec/changes/use-hf-cache-directly/tasks.md)及相邻 TaleChime 同名变更。

持久应用数据根包含数据库、工程来源、音色库与章节音频；应用缓存根包含设备校准和试听临时资源。设置可分别选择这两个目录及 Hub 缓存，根目录重叠会被拒绝。持久数据与应用缓存更改在重启后作为一个作用域生效，旧数据不移动；Hub 缓存和下载源可在模型任务空闲时切换。用户可清理设备校准与失去租约的旧试听临时文件，该操作不删除共享模型或持久音色。共享缓存的跨程序引用无法由本应用完整获知，本次不提供共享模型文件删除。

隔离缓存、本地 Hub 测试和宿主路径测试已运行；CosyVoice3 macOS CPU 直接缓存加载和合成证据见相邻 TaleChime 的 `docs/records/resources/hf-cache-direct-2026-11-12.md`，不代表人工听感或其他平台验收。

2026-11-12 在 macOS 原生窗口使用独立应用标识、隔离数据和缓存以及不可用的本地下载端点：核对三类生效路径，点击应用缓存清理并收到成功提示；模型中心显示缺失状态，CosyVoice3 准备确认展示实际缓存路径、下载量和可用空间，启动后进入下载状态并在端点失败后允许重试。该检查发现 HTTP 502 被误报内部错误；引擎已修正分类，本地模拟 502 回归通过。修正后原生实例虽正常启动，但辅助功能接口未再发现窗口，因此错误文案尚未在原生窗口复验。删除旧转换字段后的确认窗口在修正网络分类前已复验。中英文、亮暗主题和小窗口的设置与清理交互另由合成宿主浏览器检查，不能视为其他平台原生验收。
