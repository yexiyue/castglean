# 分章Agent规范化

2026-11-09，已实现，自动化门禁与独立复核已完成。复用现有Rig 0.46、Serde/Schemars及graph-flow，不新增依赖、并行Agent或另一套持久化。不改变模型思考能力选择，不删除用户工程、来源、人工修正或历史运行产物。

思考强度属于通用模型配置：分章 Agent、工程助手、章节归属分析和独立预审都通过 `llm::configured_model` 使用冻结的连接租约，由 `llm/providers/defaults` 为每轮请求注入同一设置，包括流式工具后续回合。用户在前端模型设置选择；默认取已知支持的最低档（不固定为low），供应商默认或未知能力不附加参数。新配置用于后续任务，活动运行继续使用受保护的原配置。新增本地原生SSE回归执行真实分章graph与目录工具，分别覆盖GLM最低档low、用户high、供应商默认和未知模型；每组核对两次请求及一次工具调用，不产生付费模型请求。

本次通用思考配置补充验证：11项思考配置测试（含上述四组分章回合）和9项后台运行时测试通过，22项现行主规格严格校验通过。此次不改动生产请求装配逻辑；本地原生HTTP/SSE夹具验证参数传递，不证明服务端实际思考强度或语义质量。

分章六个工具及工程助手额外两个归属工具均使用typed Tool。`tools/arguments`拥有参数与Schema、命令；`tools/adapter`装配库工具和权限范围；`tools`负责领域用例和事务；`tools/read`只投影受控来源的有界结果。固定目录、检索和受理/提交结果使用DTO；分章读取投影上限继续为每次8KiB、原文上下文最多30行；扩展归属检查沿用其独立16KiB边界。

分章与C7复用 `ai/tool_input::Invocation`，保留原始JSON身份与解码Result。错误参数也先核对已受理调用，进入真实工具计数和Failed事实，再返回安全宿主码/预期Schema。成功参数直接交给typed Command，不重复按字符串取字段。C7独有的32工具/3次失败校验不照搬到普通分章会话；分章继续只遵守既有资源、协议和显式配置边界，不新增累计产品配额。

权限由权威会话和冻结上下文共同决定。分章范围即使被直接调用typed归属工具也被拒绝；工程助手可在同工程请求单章分析。提示词按范围提供，不在分章模式宣称具备未提供的归属工具。任何模型工具均没有正式采用、撤回或改写原文权限。

本轮修复两处既有问题：发布层原先只接受chapter_splitting，导致project_assistant的分章候选可能被拒；现在仍校验同工程、同run、来源和修订，但允许正确工程助手作用域。省略可选title/volumeId时，反序列化再编码会补null，与已受理参数不相等；发布候选绑定原始accepted输入，既保留字段语义又保留准确调用身份。候选、工具成功引用、预算和graph边界仍在一个事务发布，用户工程目录不会因生成候选自动修改。

SSE执行与C7复用 `ai/failure`，保留认证/配置、超时、网络和工具错误分类；响应截断与缺失终态仍拒绝，不自动重试。等待下一块流时可取消；宿主仍先取消并等待本地工具退出，再发布终态。关闭Rig正文遥测；共享会话里有界的工具输入/结果仍是恢复模型历史的权威事实，不复制到新日志。未知usage保留未知。

graph-flow仍负责prepare/diagnose/validate/review，原checkpoint协议、版本CAS和完成工具边界保持。不要把恢复称为在途模型请求或内存工具循环的断点续跑。C7实现摘要已纳入共享解码和错误分类源码，后续修改这些代码同样使旧实现摘要失效。

验证覆盖真实native Rig/SSE参数错误→修正→单个待审阅候选，HTTP401/408/429分类及未知usage、下一块流到达前取消、工程助手发布候选/省略可选字段、分章范围越权拒绝，并保留既有恢复、来源损坏、取消、候选事务与人工采用回归。尚未重新进行付费模型分章质量、原生桌面或跨平台验收；编译/夹具通过不代表语义质量或速度改善。

最终验证：274项Rust库测试、2项集成测试、45项Node测试、6项Python评测测试通过；6项库测试及2项原生资源测试按原有外部条件忽略。Specta绑定导出、前端生产构建、rustfmt、全目标Clippy -D warnings、rustdoc -D warnings和28项OpenSpec严格校验通过，文档相对链接无缺失。独立子agent多次只读复核无P1/P2发现。

原生系统消息的content可以是内容块而非字符串；新增夹具断言最初对此假设过窄，修正断言后单例与全目标回归均通过，没有放宽运行时校验或超时。前端仍有既有大chunk/导入方式构建提示，不影响本轮门禁，也不代表本轮进行了原生桌面或真实模型验收。
