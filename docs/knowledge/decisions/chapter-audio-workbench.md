# 角色分段正文与章节音频轨道

日期：2026-11-13。适用：当前 CastGlean Tauri 2 桌面宿主与 React 工作台。状态：已实现、原生待验；自动化证据见[章节音频验证](../../desktop-studio/chapter-audio-validation.md)，原生窗口和人工听感未验收。

用户以 Fish 工作台截图提出：全章生成应逐片段可见、完成即可播、未生成占位，支持拖拽停顿；正文未分析时紧凑阅读，分析后按角色分段。不可变来源约束针对数据，不要求视觉始终按原文行排版。

- 有效分析按归属片段投影固定角色列与正文列，不再将标签穿插文字。同一逻辑片段可以跨有界读取页，展示分行不进入复制或引用；底层范围仍为原始 UTF-8 字节。
- 一个归属片段可对应多个合成单元。底部轨道显示真实单元状态，执行位置来自宿主而非完成数量；未知时长用顺序占位，完整后才使用秒刻度。
- 选中、生成位置和播放位置分离。用户浏览时暂停跟随；播放固定连续区间和编排修订，缺口停止，后续生成不悄悄追加。
- 停顿绑定任务不可变计划中的单元边界，是额外静音。编排独立修订、幂等命令、最近修改可撤销，变更不调用 TTS；来源/分析/声音失效时保留历史，不能自动挂到新计划。
- 播放和 WAV 导出共用宿主的 audio/silence 编排；静音由真实 PCM 提供，支持暂停和 seek，避免靠 UI 定时器累计停顿。导出冻结修订，失败不发布半成品。

本决定替代[紧凑显示决定](source-whitespace-presentation.md)中分析后仍按行内标注的呈现边界；未分析时的紧凑/原样和精确复制继续适用。`attribution-review-and-playback` 的异常驱动待检查规则保留，原生未验收项不由新浏览器回归代为勾选。

负责行为的[规格与设计](../../../openspec/changes/chapter-audio-workbench/)和[任务](../../../openspec/changes/chapter-audio-workbench/tasks.md)为实施依据，不将浏览器合成 IPC 当作真实模型或原生 WebView 验收。
