日期：2026-11-08。状态：历史阶段，双模式/独立助手已由[单一工程助手](unified-project-assistant.md)替代；以下保留当时的设计和验收记录。规格：[unify-chapter-workspace](../../../openspec/specs/chapter-production-workspace/spec.md)。

## 决定与边界

真实工程恢复原有三图标侧栏：章节制作、实际角色管理、制作结果状态。分章检查、归属分析在同一外壳切换；`/project/:id?mode=split|analysis` 与已有来源的 `/new?draft=…` 都使用 [ProjectWorkspace](../../../src/components/projects/project-workspace.tsx)。导入完成默认分章，追加文件仍进入编码确认流程。示例保持独立，真实结果入口明确音频制作尚未接入。

复用两个领域工作台和同一原文阅读组件，首次访问后保留挂载，保持独立会话、输入、受控修改和选择。协调上下文只传临时 UI 状态；隐藏模式使用 inert、不注册快捷键、不发布顶栏 portal、不显示其浮层。模式切换不发送、重试或取消模型任务。角色入口复用真实投影和现有管理器。

切换时捕获来源、章节、精确 UTF-8 行起点、可见行与视口偏移。仅交接/激活时应用，普通章节选择不会恢复旧锚点；章 ID 变化时以来源字节归属重新找章。默认阅读定位在目标行上方留 44px，仅传行号会来回漂移，因此 [VirtualSourceReader](../../../src/components/projects/virtual-source-reader.tsx) 增加目标偏移，分析读取从目标附近开始，继续使用原章范围与有界窗口。

结构编辑/采用前说明可能使相关分析失效，历史与人工记录保留，不自动迁移。成功更新外壳工程快照，每次进入模式也回读工程（拒绝较旧修订覆盖）；读取失败保留内容并提供重读。分析激活及工程修订变化时重读宿主投影。前端不计算或改写分析失效，无数据库、IPC、宿主执行或来源格式变更。

## 验证

外层布局按用户纠正复用原 AppSidebar：固定 64px、三个图标入口与提示，不新增音色/模型工程入口；宽窄窗口均保留同一侧栏。实际路由回归断言恰好三个入口且无常驻文字，12 组矩阵及构建通过。

- [统一实际路由回归](../../../e2e/workspace/unified-workspace.spec.mjs)：真实角色、跨章/长章位置往返、独立草稿、当前模式独占顶栏/快捷键、结果状态、编辑失败保留输入/成功回读、重查宿主失效；延迟分析响应跨模式完成且仅一次启动。12 组中英 × 亮暗 × 1360/1024/800px，两个模式均可用，无页面错误、未声明 IPC 或文档横向溢出。
- 既有实际路由分析交互与 8 组模型/检查器矩阵、8 组顶栏布局、目录/浮层、章界/跨来源回归通过；原文连续窗口和空白浏览器回归通过；19 项分章/AI 与 14 项原文窗口/空白单元测试通过。原生文本域草稿检查改用 inputValue，不沿用 Tiptap 的 innerText。
- 前端构建、lint、翻译和严格规格校验；lint 保留既有 sidebar cookie 警告。未修改 Rust，结构失效与来源校验仍由宿主负责。

浏览器使用公开合成来源与隔离 IPC，不访问用户小说、模型或凭据。历史 macOS/真实模型验收属于上一项分析交付，不作为本轮新布局原生验收。
