# 目录、问题定位与稳定检查器

日期：2026-11-07。适用：React 19 / Base UI 1.9 桌面工作区。状态：已实现，浏览器合成 IPC 验证；原生 WebView 另验。

用户指出诊断与分页在长列表末尾、无法跳页，附加设置展开挤压内容。代码证实目录每 100 项切片、诊断仅展示前 20 项。选择固定“目录／待检查”入口、按来源与卷的虚拟树，基于已有完整宿主快照只渲染视口范围；不用增量 IPC，也不把虚拟化称作服务端滚动加载。标题搜索与章号直达替代翻页。树节点提供明确层级/集合位置与活动节点；宽度统一两行截断，完整标题可访问。

参考 [WAI-ARIA Tree View Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/) 的键盘、层级与焦点约定；[NN/g 桌面 accordion 指南](https://www.nngroup.com/articles/accordions-on-desktop/)强调有条件使用，并非所有展开交互都违规。本应用的阅读定位和主要动作应保持稳定，因此章节/分卷和其他附加编辑/明细采用复用 Dialog，保留 Base UI 焦点返回和嵌套 Escape 语义，不以动画掩盖正文位移。

发现的逻辑修复：分卷原来使用预读页起点 `line`，诊断/行号定位会预读前两行；现在使用 `locatedLine`，浮层显示对应来源与实际位置。保存仍经宿主校验与回读，失败保留输入，不改写原文。长行号宽度按当前页最大位数计算，避免六位行号压到正文。

实现：[目录](../../../src/components/projects/chapter-directory.tsx)、[工作台](../../../src/components/projects/chapter-splitting-workbench.tsx)、[辅助浮层](../../../src/components/auxiliary-dialog.tsx)。[规格](../../../openspec/changes/archive/2026-11-08-streamline-directory-and-inspectors/)替代旧工作台每百章分页及内联展开的交互约定。其他领域的持久化/传输协议不变。

复现：启动 `node tests/helpers/serve-workbench.mjs`，设置 `PLAYWRIGHT_MODULE` 后运行 `tests/directory-inspectors-browser.mjs`。覆盖一万章视口节点上限、卷折叠/方向键/Home-End/直接定位/搜索、全部 50 项本地问题及第 50 项定位、目录与诊断切换滚动保持、编辑失败重试/成功关闭、实际分卷行、浮层背景位置/草稿/焦点、实际导入路由中英亮暗与音色高级选项、音色传输明细/嵌套冲突参考/管理、候选规则只读浮层、诊断历史与候选模型试听的背景位置及焦点，以及实际分章路由 2335 章宽浅色和窄暗色。测试只使用公开合成文字，不复制用户附件正文。

浏览器结果不代表原生 WebView、系统读屏器、真实工程或模型验收；本轮没有 Rust/IPC 或数据格式更改。

集成证据：分章工作台/交互、真实顶栏 8 组布局、连续导入与全应用 128 组页面/主题/语言/运行模式回归通过；17 项 AI/分章和 9 项播放测试通过。TypeScript/Vite 构建、严格 OpenSpec 校验、diff 空白检查通过；英文缺失 0，lint 仅保留原有 sidebar cookie 警告。1440 浅色与 1024 暗色真实路由截图已目视检查，运行截图保存在 ignored `src-tauri/target/workbench-acceptance/directory-*`。

补查：诊断历史不再插入消息上方，候选模型试听不再插入候选保存动作之前；两者均用独立浮层，验证背景位置、Escape/焦点与无隐式任务启动。候选试听使用可保留挂载的 Dialog Portal 能力，关闭保留内部文本草稿；其余浮层继续使用所属受控表单状态。

## 2026-11-08：目录头部与阅读工具栏减负

本节替代前文“独立章号直达表单”的呈现：搜索与序号定位共用一个输入，纯数字匹配目录序号（含前置内容，不等同小说章号），Enter 选择第一个命中，方向下键进入虚拟树。仅输入不触发原文读取；原有树键盘、折叠、固定问题入口保持。目录标题紧邻计数，线型标签取代胶囊分段，编辑入口归到明确命名的目录操作菜单。

正文将原两排工具合成一个 56px 固定栏：当前章节标题优先，来源文件在次级截断文本入口中切换，同时说明目录位置；显示与跳行使用 Popover（32px 操作高度），分卷保留有位置上下文的 Dialog。Ctrl+G 打开并聚焦跳行，非法值在浮层内提示，关闭恢复焦点且背景不移动。英文分卷短标签使用 Volumes，避免窄窗口挤压标题。沿用项目 10/8/12/16px 语义圆角。

依据：[Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) 的命令优先级、分组与减少控件边框，[VS Code Command Palette](https://code.visualstudio.com/docs/editing/getting-started/userinterface#command-palette) 的按需快速定位。Mobbin 因付费限制未取得参考截图，未用作证据。

验证：`tests/reading-toolbar-browser.mjs` 覆盖真实路由 1440/1024 × 中英 × 亮暗共 8 组、输入不读取、目录序号/无匹配/清除、来源语义、显示切换、跳行校验/Ctrl+G、焦点返回、固定几何和无溢出；截图 `src-tauri/target/workbench-acceptance/reading-toolbar-*` 为 ignored 合成夹具产物。目录/检查器、章内阅读边界、空白显示/原样显示/选区复制及交互回归通过。14 项源窗口测试、17 项 AI/分章测试、构建、严格规格与翻译检查通过；lint 仅保留既有 sidebar cookie 警告。原生 WebView、系统剪贴板和读屏仍需独立验收，不表示已覆盖。

### 常驻范围搜索（2026-11-08）

用户指出原搜索框占据主要位置却随标签消失，导致视觉突变。本节替代“问题标签隐藏搜索”的旧行为。依据 [NN/g Tabs Used Right](https://www.nngroup.com/articles/tabs-used-right/) 的相关视图布局一致性与 [Carbon Searching](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines#searching) 的常驻/收起搜索取舍，选择保留可直接输入的常驻搜索，使用共享 quiet 变体弱化边框，焦点样式保持。

同一输入元素按当前视图更新范围；目录查询与问题查询分开，滚动位置各自保留。问题匹配本地类型名称、所属章节、来源文件和显示行号；纯数字精确匹配 1 起始原文行号。章节归属使用按来源的标题行索引二分查找，不增加宿主调用或改写工程。问题徽标保持真实总量；暂无问题与过滤无匹配区分，即使零问题也保留搜索框。

专项 `tests/directory-search-browser.mjs` 验证同一 DOM、固定几何、独立查询/滚动、类型/章节/行号匹配、真实总量、清除/焦点/Enter/方向下键、输入不读取、零问题和真实路由中英亮暗 1440/1024 共 8 组。目录/检查器及阅读工具栏回归、构建、lint（既有 sidebar cookie 警告）、翻译零缺失及严格规格检查均通过。浏览器合成 IPC 不代表真实原生 WebView/读屏验收。
