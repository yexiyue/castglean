# 设计

`ai/tool_input`只处理原JSON与DTO解码Result，不拥有业务错误或执行权限。C7和分章typed Tool都在实际准入后处理解码拒绝，避免丢失真实工具次数或改变参数身份。

`tools/arguments`定义参数、Schema和命令；`tools/adapter`负责Rig注册与安全反馈；`tools`负责权威作用域、领域请求与事务；`tools/read`只读取受控工程并投影有界结果。候选仍由store完成工具事实/回执/graph边界的同一事务。

分章诊断仍使用graph-flow的prepare/diagnose/validate/review；不增加与其重叠的自建检查点。只读工具不能采用候选；工程助手可按冻结作用域请求单章分析，分章作用域不可越权。解析失败、业务失败和未知工具都留真实事实，不额外施加C7专属的32/3限制。

模型正文遥测关闭；共享会话中有界工具参数和结果仍是恢复模型历史的权威事实，不再复制到另一套日志。流式供应商错误与C7采用同一安全归类，语法损坏、截断和缺失终态仍拒绝；取消不等流下一块文本。
