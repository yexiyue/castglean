# 规范化分章Agent

## Why
分章工具虽有同源参数Schema，仍经动态工具与字符串分发重复解码，固定输出为手写JSON，流式错误归类不完整。需要与章节分析的类型边界、审计和执行规范一致。

## What Changes
- 复用统一的可恢复typed参数入口，分章工具使用Rig typed Tool和类型化命令/读取结果。
- 工具能力按权威会话与冻结上下文决定；不能靠隐藏工具阻止越权调用。
- 共享Agent错误归类、关闭正文遥测、及时响应流式取消，保留失败工具事实及未知用量。
- 保留graph-flow阶段检查点、候选原子发布及人工采用，不新增累计产品配额，不迁移或删除工程数据。

## Impact
仅调整宿主实现；分章候选与graph检查点协议保持原意，工具失败返回稳定宿主码。分章/归属共用解码适配基础，不合并两类业务状态机。
