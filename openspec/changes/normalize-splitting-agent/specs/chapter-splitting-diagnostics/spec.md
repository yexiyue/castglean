## ADDED Requirements

### Requirement: 类型化分章Agent边界
系统 SHALL 从同一参数类型生成工具Schema并执行typed命令，工具能力由权威会话及冻结上下文校验。解码失败仍计入真实调用并保存安全失败事实；不因类型化适配新增累计产品配额。后台Agent关闭正文遥测，使用统一供应商错误归类。

#### Scenario: 参数类型错误后修正
- **WHEN** 模型先传入非法类型，再修正参数
- **THEN** 第一次拒绝和第二次尝试均被记录，只有合法命令可以产生候选，不重复或伪造成功结果

#### Scenario: 分章工具越权请求归属
- **WHEN** 分章作用域尝试读取或触发章节归属工具
- **THEN** 宿主拒绝且不创建归属输入或修改工程，不依赖模型自觉遵守工具列表

#### Scenario: 模型流等待期间取消
- **WHEN** 流尚未返回下一块数据而用户取消
- **THEN** 执行及时响应，按既有宿主约定等待本地工具退出后发布取消，不伪报完成

#### Scenario: 工程助手发布分章候选
- **WHEN** 工程助手在同一工程/运行中提交合法规则或边界建议，部分可选字段被省略
- **THEN** 候选绑定原始已受理参数和当前来源修订，并与工具事实原子保存，仍等待显式采用
