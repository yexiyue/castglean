## ADDED Requirements

### Requirement: 选角任务步骤

系统 SHALL 在选角调用旁显示默认收起且可展开的 Todo 列表，通过 AG-UI 的任务、审批、试听计数与结果更新同一列表。

#### Scenario: 等待确认试听

- **WHEN** 选角任务等待用户批准试听
- **THEN** 收起行标注待确认，展开后可核对步骤并提交既有审批表单

#### Scenario: 批准后更新试听

- **WHEN** 宿主提交试听进度或选角建议
- **THEN** 更新原列表的试听计数或完成状态，每次更新不追加列表

#### Scenario: 失败与取消

- **WHEN** 任务失败、取消或部分试听未得到产物
- **THEN** 列表如实反映宿主状态，并保留已处理的试听计数
