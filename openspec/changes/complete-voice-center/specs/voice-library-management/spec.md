# Spec Delta

## Purpose

为已保存的真实音色提供可持久化的名称维护与显式删除，并明确其与活动创建、试听及音色包传输之间的一致性。资产身份和声音内容不随名称变化，删除结果以真实存储提交为准。

## ADDED Requirements

### Requirement: 持久化重命名

应用 SHALL 校验并持久化音色名称，保持资产身份、录音和转写不变；失败保留旧名称，后续列表与新导出反映已提交名称。

#### Scenario: 重启后名称保持
- **WHEN** 用户成功重命名音色并重启应用
- **THEN** 列表显示新名称，相同资产身份和参考内容保持不变

### Requirement: 显式删除与并发保护

应用 SHALL 在删除前显示确切资产并要求用户确认；资产存在活动读取、试听、保存或传输占用时返回忙状态，不静默中断任务。成功删除后从正式列表移除，失败保留可访问资产。

#### Scenario: 导出或试听正在使用资产
- **WHEN** 用户确认删除仍被活动任务占用的资产
- **THEN** 删除返回明确忙状态，活动任务与资产均保持有效

#### Scenario: 确认删除完成
- **WHEN** 无活动占用且删除成功
- **THEN** 重新打开应用后该资产不再出现，删除不会改变其他资产或用户原始输入文件
