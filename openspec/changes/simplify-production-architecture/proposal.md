# 收敛正式实现与评测架构

## Why
合并后的章节域同时携带正式C7和已退役JSON/ECS实验、历史协议分流及一次性脚本，增加依赖和维护成本。用户已授权不考虑旧兼容，不保留旧实现。

## What Changes
- 删除旧JSON/ECS实验实现、专用驱动及历史日志兼容；只保留正式Rig Agent+C7。
- 按执行编排、事务发布、运行观察、纯核心划分职责，移除重复查询与无用适配。
- 评测只调用正式核心与原生运行时，保留公开用例、身份冻结、失败分母和未知用量。
- 更新当前文档，移除退役实验说明、旧库归档及已完成历史变更；保留主规格和未完成验收任务。既有工程、人工修正、来源与本地实验产物不删除。

## Impact
旧分析输入和检查点不再支持继续或读取专用诊断，需要显式新建任务；不迁移、不清空数据库，不重写Git历史。正式模型能力与用户思考设置不变。
