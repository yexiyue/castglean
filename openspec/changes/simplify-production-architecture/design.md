# 设计

以KISS、YAGNI、DRY、SOLID检查实际职责，不新增通用仓储、执行框架或兼容facade。

- agent_core：纯来源校验、原子草稿工具与协议。
- agent_runtime：Rig循环和脱敏请求/工具事件。
- execution：冻结输入校验与分析/讨论派发。
- execution_agent：阶段检查点和领域转换。
- publication：角色/版本/候选/回执的一次事务发布。
- observation：进度、只读预审与脱敏诊断的查询投影。
- evaluation：仅测试编译的无工程写入入口；共享正式核心，不含旧JSON或ECS。

保留当前输入/检查点版本，拒绝旧版本，不做隐式升级。删除历史专用脚本及其测试、旧库归档及已完成变更；历史规格链接改指现行主规格，保留未完成任务、正式评测和公开数据。所有删除仅限Git跟踪的源码和文档，不清理忽略目录中的私人产物。重构前后的自动化回归验证人工保护、完整来源覆盖、阶段恢复、取消和未知用量。真实模型与桌面验收不冒充本轮验证。
