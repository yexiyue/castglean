# 后端类型边界与库能力收敛

## Why
固定业务结构通过Value与字符串字段传播，工具参数和Schema双份定义，增加运行时漂移与恢复维护成本。用户已授权全部优化，不要求旧实现兼容。

## What Changes
- Serde参数为唯一结构来源，使用Schemars与Rig参数Schema工具生成定义，保留运行时身份枚举和跨字段约束。
- 正式章节归属分析优先类型化工具；检查点、阶段更新、预审、诊断和生成配置采用明确DTO。
- 错误使用thiserror稳定枚举；查询采用SeaORM类型化结果，JSON数据库边界保持显式校验。
- 同目录临时文件保存复用tempfile，保留同步、限制、覆盖策略与凭据发布事务。
- 保留正式评测、失败分母、未知用量和来源/人工保护回归。

## Impact
检查点格式升级，旧格式不继续、不迁移、不删除数据；工具wire约束可能因生成Schema变化，需结构和真实Rig夹具回归，不以编译通过宣称AI质量提升。前端思考强度选择和业务采用规则不变。
