## ADDED Requirements

### Requirement: 类型化执行边界
系统 SHALL 以Rust业务类型表达正式工具参数、检查点阶段与预审结果，从参数类型生成工具Schema；动态身份约束可在生成后追加。检查点更新必须校验租约和依赖，不接受任意字段名覆盖执行身份。

#### Scenario: 分析完成后追加预审
- **WHEN** 独立预审结果被持久化
- **THEN** 保留原分析、所有请求trace与未知用量，预审结果只能作为只读建议

#### Scenario: 参数与工具Schema同步修改
- **WHEN** 工具参数结构发生变化
- **THEN** 工具Schema从同一结构生成，非法字段和运行时身份仍由边界与业务校验拒绝

#### Scenario: 参数类型错误仍被计数
- **WHEN** 工具名称合法但字段类型或必填字段错误
- **THEN** 返回脱敏修复反馈并计入真实尝试、失败修复与audit，不将随后修正伪装首次有效，也不绕过限额
