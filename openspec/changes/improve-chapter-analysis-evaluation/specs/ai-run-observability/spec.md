# Spec Delta

## Purpose

为 AI 执行保留可查询的阶段、请求、父子关系、耗时和配置身份，支持排查慢请求、复核提示词变化及比较并行策略，同时保护正文、模型凭据和私有运行材料。

## ADDED Requirements

### Requirement: 阶段与请求身份
系统 SHALL 记录准备、人物发现、标注、校验、预审及发布的实际阶段与终态；子任务包含父运行和独立请求身份，不能用聊天推断执行成功。

#### Scenario: 并行子任务一项失败
- **WHEN** 一项标注失败而另一项已完成
- **THEN** 分别保留各自耗时、错误及有效结果，父运行不伪造整章发布

### Requirement: 真实用量与提示词追溯
系统 MUST 记录来源、配置、提示词、协议和模型身份及服务商实际用量；未知用量保持未知，缓存输入不重复累加。默认诊断不得含正文或凭据。

#### Scenario: 请求超时无用量
- **WHEN** 请求未获得完整响应
- **THEN** 保存超时和持续时间，用量为未知而不是零

#### Scenario: 恢复完成步骤
- **WHEN** 明确继续复用已有有效结果
- **THEN** 可定位原请求证据，不伪造一条耗时为零的新在线请求
