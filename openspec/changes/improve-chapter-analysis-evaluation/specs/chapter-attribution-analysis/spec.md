# Spec Delta

## ADDED Requirements

### Requirement: 宿主预切片与紧凑归属建议
系统 SHALL 由宿主生成保留精确来源的稳定片段及引语层级，模型按连续片段 ID 区间返回类型、归属、真实证据与简短理由；嵌套称号不得因局部引号被强制判为旁白。正文与范围还原只由宿主完成。

#### Scenario: 台词中的嵌套称号
- **WHEN** 外层人物发言包含被内层引号包围的称号
- **THEN** 模型获得外层引语上下文，标注可保持人物发言，不将引号规则当成语义答案

### Requirement: 同一运行内有限并行
系统 SHALL 在冻结本章人物快照后，有界分派互不重叠的目标片段；子任务可读整章上下文，不能各自发布或绕过人工保护。明确继续复用指纹一致的完成步骤，在途未知请求不盲目自动重发。

#### Scenario: 一个子任务失败
- **WHEN** 部分子任务已完成且其他子任务失败
- **THEN** 保留有效步骤供明确继续，当前有效版本保持，不发布半章

### Requirement: AI 预审与人工确认分离
系统 SHALL 在结构完整校验后执行独立提示的 AI 预审，保存带定位及依据的问题建议；预审不得自动改写人工字段或标记人工确认，明确区分疑点、AI 认可与人工决定。

#### Scenario: AI 指出一处归属问题
- **WHEN** 预审返回合法片段引用及建议
- **THEN** 问题可查询且原标注仍未人工确认，不凭模型自评自动采用修改

#### Scenario: 预审失败
- **WHEN** 标注完整但预审超时或返回非法引用
- **THEN** 保存标注步骤及失败诊断，不伪造预审通过，明确继续可复用有效标注
