## Standards

- **历史窗口丢失（审查者标 P2，已修复）**：原 `DesktopAgent.listen` 仅合并显式前置分页缓存和最新窗口，旧最新窗口的第一条消息被挤出后消失；`before=null` 时已无补读入口。违反数据格式中历史保留与工程规范的可丢弃展示边界。现在合并全部已加载消息、records、runs、invocations 和 contexts，按稳定身份采用新事实；连续窗口保留最早分页边界，完全不相交的重连窗口重新开放补读。
- **停止失败覆盖受理成功（P2，已修复）**：原 `accept` 在成功受理后等待 cancel；cancel 失败导致发送 Promise 拒绝且不建立订阅。违反工程规范中成功回执与后续失败分开的规则。现在先确认受理、建立跟随，再独立报告停止失败；没有另建请求或自动重发。
- **可能的 Duplicated Code（判断性建议，已简化）**：多处 `filter(!some(id))` 后追加的合并形状被统一为 `mergeById` 与 `mergeHistory`，删除五份 `older*` 并行缓存。不是工具规则违例。
