# Tasks

本清单按实施与验证证据更新，验证边界见 validation。功能范围以 proposal、两份 delta spec 和 design D7 的所有权表为准。

## 1. 任务展示基础

- [x] 1.1 从现有 AgentPage、runtime 消息和领域引用建立只读展示索引，区分普通回复、专业调用、嵌套预审与尝试；用真实官方 runtime fixture 验证同名不同身份、无父工具快捷任务、挂起继续、重试和分页不会合并或复制，补数据来源文档。
- [x] 1.2 建立共享助手布局和任务区段组件，从 ImportedWorkspace 拆出 agent 展示分支；提供普通对话、排队、运行、等待、失败和候选结果的可运行组件夹具，检查现有主题/共享控件及主结果入口唯一，并记录新交互结构。
- [x] 1.3 为固定目标、任务名称和结果归因补齐确有需要的只读投影；现有字段足够时不增加 IPC，字段不足时只查询现有权威记录、导出 bindings 并通过宿主/tsc 测试，同步字段来源及未知值规则，不新增目标步骤表。

## 2. 状态动作与生命周期

- [x] 2.1 实现 design D3 的状态/动作映射，替换重复运行横幅、通用重试与重复停止入口；组件测试覆盖计算完成但候选待审阅、cancelling 尚未终止、未知阶段/用量和读取失败，更新面向用户的状态说明。
- [x] 2.2 接通停止、显式重试、原请求核对和只读重读，保留未知受理身份与输入；真实 client 及浏览器测试验证停止期间去重、受理丢失不盲发、切页/StrictMode teardown 不取消、旧会话迟到结果不污染新会话，同步恢复操作文档。
- [x] 2.3 把工具、reasoning、用量和旧尝试放入按需详情，保留原解释与失败事实；验证展开不启动模型、不显示原始 JSON/路由字段、无内容回复不生成空行，流更新和前置分页保持用户滚动，补交互文案中英翻译。

## 3. 必要问题与输入模式

- [x] 3.1 实现任务内问题组、文字回答和普通 composer 的单一主要输入模式；按工程/会话/中断保存本次应用会话内草稿，测试切章、切会话、审阅往返、长问题及未知作答形式，证明不再堆叠两块完整输入框并记录临时状态边界。
- [x] 3.2 使用官方中断回答入口一次提交该轮必要答案，复用受理未确认恢复；宿主/真实 runtime 夹具验证多问题、重复/过期/跨会话回答、提交失败和响应丢失，成功后只清理对应回答草稿且恢复普通草稿，不将路由信封显示成用户回复。
- [x] 3.3 完成问题标签、字段错误、提交中状态、键盘与 IME 保护；浏览器验证 Enter/组合输入不误发送、失败保留输入、焦点返回对应问题，补中英回答与未知形式文案，不扩展任意 schema 表单或领域决策工具。

## 4. 审阅与工作台协作

- [x] 4.1 将分章、归属和选角结果统一映射到现有领域查询与审阅入口；测试待审阅/已采用/放弃/失效及查询失败，不复制主操作、不自动采用，不把未实现撤回/忽略显示为可用，更新结果操作说明。
- [x] 4.2 接通任务目标定位、返回助手与原文/属性面板协作；实际路由验证甲章运行切乙章、结果固定目标、返回任务锚点/阅读范围/草稿/焦点，窄窗口开关目录恢复原辅助模式，更新工作台操作文档。
- [x] 4.3 整理下次请求的模型/思考配置和引用上下文入口，保留宿主冻结与确认边界；浏览器验证模型缺失能进入设置、返回保持输入、运行中更改配置不改历史目标，并补已知/未知配置展示说明。
