## 宿主集成

通过 TaleChime 的固定资源接口盘点和下载模型，保留准确的进度、取消和失败状态；移除原生转换准备分支。不得删除共享 Hub 缓存中可能属于其他模型或应用的文件。缓存缺失或损坏时明确报告。

本次不提供共享模型文件删除：无法可靠证明其他应用的引用已经消失。模型状态由实际缓存盘点决定；用户可打开 Hub 缓存目录并使用 Hugging Face 缓存管理工具自行管理。应用清理仅覆盖可确认由 CastGlean 拥有的设备校准和失去租约的旧试听临时文件。

分别配置绝对路径：Hub 缓存、CastGlean 持久应用数据和可再生应用缓存。设置入口可发现；变更路径不自动迁移或删除原数据。清理可再生缓存不得删除持久音色。

持久数据目录属于整个宿主的启动作用域：数据库、工程原文、音色库、后台任务和章节音频必须使用同一份启动时解析的路径。更改该目录时先保存待生效设置，并要求重启应用后切换；重启前继续使用启动时的完整旧作用域，界面明确显示尚未生效，避免同时混用旧数据库和新文件。应用缓存目录同样在重启后统一切换，以保留当前试听候选和媒体租约。Hub 缓存与下载源可以在没有相关任务时即时切换。路径校验应以规范化后的三个完整根目录进行，拒绝相互包含及已有符号链接造成的重叠；保存设置不移动或删除任何旧数据。

引擎接口由 TaleChime 同名变更定义；修改宿主时以实际公开接口为准，保持模型资源身份及恢复语义一致。测试使用隔离缓存；真实桌面验收与自动化结果分别记录。
