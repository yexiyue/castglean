## ADDED Requirements

### Requirement: 宿主使用共享 Hub 资源
宿主 SHALL 通过引擎固定资源接口盘点及准备模型，并准确展示进度、取消和失败，不组装模型目录或执行本地转换。

#### Scenario: 缓存缺失或损坏
- **WHEN** 固定模型资源缺失或损坏
- **THEN** 宿主显示未就绪并提供统一下载，不替换为其他版本

#### Scenario: 清理共享资源
- **WHEN** 用户清理模型或缓存
- **THEN** 系统不得删除其他模型或应用可能引用的共享资源，也不得删除持久音色

### Requirement: 配置独立存储位置
宿主 SHALL 提供可发现的设置入口，分别配置 Hub 缓存、持久应用数据和可再生应用缓存的绝对路径。

#### Scenario: 修改路径
- **WHEN** 用户修改 Hub 缓存路径且相关任务空闲
- **THEN** 后续下载与盘点使用新路径，不自动迁移或删除旧位置的数据

#### Scenario: 修改应用数据或缓存路径
- **WHEN** 用户保存新的应用数据或应用缓存路径
- **THEN** 界面提示重启后生效，当前进程继续使用启动时的完整存储作用域；重启后使用新路径，不自动迁移或删除旧位置的数据
