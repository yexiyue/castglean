# Design

## Context

参见 proposal.md。现有 core 校验器要求提供全部证据章和统一角色修订，model 尚为空，CLI 只有离线 validate。保留三个 crate 和草案持久化 DTO。

## Goals / Non-Goals

**Goals:** 公开泛型异步分析入口、可测试建议协议、GLM 适配及 `.env` CLI，完成真实公开样例基线。

**Non-Goals:** 工具循环、自动身份合并、已标注章重分析、声音画像分析、缓存和持久化恢复。本次只给新章节生成完整候选结果，不实现多文件状态提交。

## Decisions

1. core 的最小 Model trait 接收文本请求、输出文本及用量；异步 future 支持 Send，GLM 在 model 实现。选择泛型而非插件注册框架，Tokio 只负责宿主运行时内的超时和取消。
2. 独立切片函数按换行、引语和句末边界切分，过长片段按 Unicode 字符数细分。ID 包含切片版本、正文摘要及范围；引号不决定表达类型。窗口按字符和目标片段数双上限顺序组装（默认 3000 字符、24 片段），带前后相邻片段；前文已接受角色进入下一请求。片段完整分区，暂不增加嵌套语义层。
3. 建议字段严格解析：新角色临时引用、显示名、别名及证据；目标片段的类型和归属；临时与正式引用用显式标签区分。已有角色只能引用，不修改字段，避免覆盖人工确认。正式 ID 由书章、正文和临时身份生成，同名不自动合并。建议引用只能落在本请求可见片段，确定和歧义判断要求证据。
4. 可选输入已校验书籍，提供完整证据而非减弱 validator。新章不得复用已有章 ID；返回新的已校验候选书籍，角色增加时提高修订并更新候选中旧章的修订引用，原对象和既有内容不变。跨章自动身份识别质量及修正操作仍在 C。
5. 每窗口一次联合调用，无自动重试；预先检查窗口数，限制请求正文与输出大小，传递 max_output_tokens，统计模型实际报告的用量。未知 token 记为缺失，不宣称硬总 token 上限。取消和超时丢弃请求 future，返回前再次检查取消，不存储部分结果。
6. model 显式注入 genai AuthResolver 和 ServiceTargetResolver，不让 SDK 隐式读取环境。沿用 comfy-agent 的 genai 版本和 BigModel 命名、端点。CLI 用 dotenvy 的解析迭代器读取文件而非修改全局环境，进程环境优先；默认当前目录 `.env` 可缺失，显式路径缺失报错。
7. CLI analyze 第一版从空角色表分析单章；支持 book/chapter/source/output/env-file 与预算参数，Ctrl-C 取消。输出先写同父目录临时目录，再发布到不存在的最终目录，失败清理临时目录；这是一次新产物发布，不是阶段 C/D 的状态事务与恢复。库无默认路径和文件写入。

    P --> M[联合模型建议]

## Risks / Trade-offs

用户批准的输出约束补充：建议类型派生 Schema，model 负责选择 JSON mode、JSON Schema 或强制一次 submit_analysis 工具返回；工具参数转成同一建议文本，core 校验规则不变。工具不执行写入，不回填结果或继续循环。工具模式仅接受一个指定名称的调用及工具停止原因；其他模式拒绝工具调用。任何模式失败均不自动降级或重试。JSON 解析错误按 serde 类别区分语法和结构，静态诊断不含正文或字段值。先用冲突指令探测严格约束，再用实际建议协议验证；HTTP 200 不作为约束生效证明，默认方式按验证结果选择。

已完成探测后的选择：默认 json（response_format=json_object）。当前端点接受 json_schema+strict 但冲突响应违反约束；工具小 Schema 探测通过，实际建议协议首次三个样例中两个结构失败，诊断重跑成功仍不能抹去失败。两种模式作为显式可选传输，不宣称服务端严格保证。JSON 语法先用通用值验证，再对原始文本严格解码 DTO，从而保留重复字段检测并避免字段错误掩盖未完成语法。

用户批准的性能诊断补充：思考等级放在 GLM 适配配置中，保持 core 请求厂商无关；默认 low，库可显式选 high/max。CLI 优先级为参数、进程环境、环境文件、默认值。运行统计记录请求等级、可选推理 token 和每次最终建议的 UTF-8 字节数，不保存思考正文。服务端未返回明细时保留 null，历史统计可读取；最终字节数不换算为 token。对照保持正文、提示词、切片和窗口不变，仅改变思考等级，但采样波动和角色上下文差异仍会影响结果，单次对照不能证明因果或语义等价。

- 规则切片不能精确表达所有隐式、嵌套台词 → 公开限制并通过样例记录语义误差，不用模型生成坐标。
- 角色表增长会超过输入预算 → 明确失败，不截掉身份或证据；相关检索后续按评测需要扩展。
- GLM 响应能力和停止原因可能不同 → 文本 JSON 作为最低协议，截断明确拒绝，用本地模拟服务测试适配。
- SDK 原始错误可能含私人响应 → 对外只暴露类别和静态诊断，不透传 Debug。
- 取消无法保证服务端请求停止或不计费 → 丢弃本地结果，不承诺远端请求撤销。

## Migration Plan

添加新 API 和 CLI 命令，不修改草案 Schema。只迁移现有本地 `.env` 中的三项配置，不复制数据库和服务配置；真实配置忽略，示例使用占位值。回退可继续使用离线 validate。

## 后续兼容说明

此变更记录阶段 B 的单次基线；后续 bounded-analysis-repair 增加默认一次候选修复，设置 max_repairs_per_window=0 保留此处单次模式。适配器仍不隐式切换输出方式或重试网络调用；候选修复由 core 的独立窗口流程控制。
