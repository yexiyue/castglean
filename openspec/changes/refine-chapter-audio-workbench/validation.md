# 章节音频工作台验证

## 自动化

- Rust 单测通过 449 项，11 项显式环境测试保持跳过。Clippy 全目标以警告视为错误通过。Specta 导出测试通过，前端使用本次生成的类型绑定。
- 前端构建通过，Vitest 85 项通过。Lint 通过，仓库仍有 Tailwind 样式提示。
- 章节浏览器回归 13 项通过，覆盖角色缺声定位、未分析时选择单音色、跨章与跨页播放、播放时收放轨道、连续阅读、失败恢复、停顿草稿和 WAV 导出。工作台回归检查长章仅渲染视口片段及中英文、亮暗主题、1024×680。
- OpenSpec 严格校验通过。基线 `chapter-audio` 与 `chapter-audio-editing` 同步至主规格后可以归档本次增量。

## macOS 隔离桌面

- Mac Apple Silicon，使用独立应用标识、schema v10 新库及自撰公开正文。未分析章节从工作台选择 Kokoro `1.1-zh-g2pw` CPU 的 `zf_001` 生成，通过真实媒体会话播放，收起轨道后保留播放控件。宿主报告 1/1 单元完成，整章 PCM 时长 4.87 秒。
- 对未分析的第二章分别调用两种预检。单音色返回可生成计划，多角色返回 `no_analysis`，两次预检后该章的音频任务与归属状态均为空。
- 为同章注入已确认归属和两条预置音色绑定，通过真实宿主命令生成多角色结果。3/3 单元完成，使用 `zf_001` 和 `zm_009`，两种结果具有独立任务和媒体。多角色 WAV 经原生保存窗口导出，24 kHz 单声道 PCM、5.72 秒。在首个片段后添加 0.5 秒停顿并再次导出，结果为 6.22 秒。
- 暂停第一章的多角色会话并前往第二章，底栏仍显示第一章及继续播放。第二章导出按钮生成第二章独立的 2.89 秒旁白 WAV。
- 归属数据使用预置测试结果。真实文本模型分析、原生失败定位与断点续跑、其他平台和人工听感仍待验证。
