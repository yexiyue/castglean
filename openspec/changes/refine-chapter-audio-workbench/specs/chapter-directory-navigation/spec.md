# Spec Delta

## MODIFIED Requirements

### Requirement: 内容优先阅读栏
系统 SHALL 在窗口顶栏显示章节标题和正文工具。窗口顶栏按目录、正文和 AI 助手三区布局，短分隔线对齐可见分栏。章节标题下拉提供原文信息、跳行与分卷。按原文行分章或合并从行号菜单与选区浮条发起，编辑边界仍需确认。正文工具提供前后章、紧凑／原样显示及可选的角色标记。正文区域承载原文、选区与阅读标记。

#### Scenario: 阅读命令与小窗口
- **WHEN** 用户切换显示、跳行或分卷，或缩窄窗口
- **THEN** 命令仍可访问，浮层关闭返回焦点，背景尺寸稳定，长文件名不造成水平溢出，目录位置包含前置内容且语义明确。
