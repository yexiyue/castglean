# Spec Delta

## MODIFIED Requirements

### Requirement: 全页面可读与可操作
首页、导入、模型、音色、创建、引导、设置和工程各视图 SHALL 使用一致的页头、间距、焦点与主次操作，保持浏览器引导和真实宿主状态的区别，最小窗口中英文亮暗主题无横向溢出。路由级状态（页面未找到、路由加载中、路由加载失败）SHALL 保留应用外壳与应用级导航栏，形态与其他页面一致。集合页的空态、搜索无结果态与加载态 SHALL 锚定在所属工具栏或列表区顶部，不得脱离上下文漂在页面中部；同类状态在不同集合页之间 SHALL 使用一致形态（图标、标题与动作层级）。

#### Scenario: 浏览页面与详情
- **WHEN** 用户在 1024×680 窗口打开列表、详情或设置
- **THEN** 能通过滚动和键盘访问内容及关键操作，关闭弹层可回到原页面，资源准备/删除等既有确认仍生效

#### Scenario: 集合页等待与无结果
- **WHEN** 用户在模型中心或音色中心等待资源读取，或输入了没有匹配的名称
- **THEN** 状态出现在上方搜索与筛选控件的正下方，图标、标题与清除动作与同类页面一致，不漂在页面中部

#### Scenario: 路由级状态
- **WHEN** 用户打开未知地址，或路由加载失败
- **THEN** 页面仍显示应用级导航栏，状态整页居中，用户可从导航栏回到任一目的地
