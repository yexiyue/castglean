# Spec Delta

## MODIFIED Requirements

### Requirement: 多包选择与导入预览
系统 SHALL 通过宿主系统选择器一次选择多个包，展示可辨认文件名、音色名称、数量、大小、参考录音时长、来源和逐项状态，支持全选、取消选择及部分选择。选择取消保留当前页面；扩展名不代表校验通过。错误关联具体文件而非只报序号；前端不得解析包或提交任意文件路径。

#### Scenario: 选择两个包的部分音色
- **WHEN** 两个包共有二十个音色，用户只勾选五个
- **THEN** 提交只包含这五个；未勾选条目不进入库，选择与冲突决定保留至任务开始

#### Scenario: 发现损坏包
- **WHEN** 所选文件之一检查失败
- **THEN** 展示含文件名的文件级原因并阻止该批提交，允许移除问题文件重新检查，不清空其他界面草稿

#### Scenario: 排除损坏文件后继续
- **WHEN** 用户从多个文件中移除已标明文件名的损坏包
- **THEN** 可核对剩余文件与音色选择，重新检查后才提交，成功与失败结果仍按原文件和音色对应
