# Proposal

## Why

当前表单虽已有 shadcn/Base UI 基础，仍分散使用手写标签、不同布局和状态处理；静阅青主题与 Tailwind 约束尚未落地，审计记录了 6 项 P1、17 项 P2。用户要求从单表单试点扩展到全部表单，并将主题、组件、交互与这些已确认问题统一整改，避免只换颜色而继续累积行为差异。

## What Changes

- 所有用户可见编辑表单统一为共享 Field / InputGroup 等组件、React Hook Form 与 Zod 的接线体系，覆盖导入、结构/归属/角色、声音创建与资产编辑、连接与设置、停顿和助手输入；筛选、导航、播放等非表单交互统一原语而不伪装成持久化表单。
- 应用已选静阅青亮暗主题、语义颜色与几何 token，复用当前字体与品牌资产；内容排版接入命名 Typeset 预设，保留小说原文的独立渲染和坐标系统。
- 将 Tailwind 语义色、完整类名、共享组件外观边界和具体例外变为可执行的 Biome 门禁；保留 cn/CVA，不引入另一套格式化或表单引擎。
- 对照 `docs/ui-ux-audit/README.md` 修复全部 23 项已确认问题，并逐项提供验收证据：配置入口、播放连续性、恢复动作、导入返回路由、能力文案、示例分叉、保存/错误反馈、资源状态、名称、快捷键帮助及窄窗往返。
- 用户已确认：切换浏览章节继续播放原章节，唯一控制条标出播放章节并提供返回入口；不会按新浏览章改写冻结播放计划。
- 保留原文、稳定身份、人工保护、宿主权威、系统凭据、任务与幂等恢复语义；尚未确认的审计现象安排定向复验，不假定缺陷已成立。

## Capabilities

### New Capabilities

- `application-forms`: 全产品表单的统一组成、输入校验、编辑/保存状态、草稿与异步结果隔离及可访问语义。

### Modified Capabilities

- `desktop-interface-consistency`: 静阅青主题、组件与 Tailwind 使用边界、内容排版、资源状态、可区分名称、可发现帮助及真实窗口验收。
- `chapter-production-workspace`: 工程入口与真实能力表达、结构修改上下文、跨章播放连续性、操作恢复、窄窗面板记忆和示例工作台复用。
- `novel-chapter-import`: 首中尾样本定位、文件级状态与部分成功后进入稳定工程地址。
- `voice-library-transfer-ui`: 包检查错误关联实际文件、明确部分选择与恢复，继续由宿主解释包和发布结果。

## Impact

涉及 `src/index.css`、`src/components/ui/`、`src/routes/new.tsx`、工程/分析/音色/模型/设置与助手组件、前端播放会话的挂载位置、Lingui 文案、Biome 配置和现有组件/路由/原生测试。拟新增 `react-hook-form`、`@hookform/resolvers` 和 `zod`，按实际兼容版本安装；Typeset 为项目持有的 CSS，不引入另一套 UI 库或后端数据校验框架。

本变更承接 `redesign-production-experience` 中与主题、表单和已记录问题重合的范围，所涉行为以本变更的明确契约为准；旧草案其余布局探索不自动实施，不双算任务、不删除或归档旧变更。`introduce-hotkeys` 及章节音频/归属变更保留独立契约与原有验收缺口，本变更只记录实际覆盖证据。

不包括整书批处理、局部重做/候选采用、远程语音服务、品牌重做、通用 schema 驱动表单生成器或无依据替换虚拟阅读器。当前只创建规划产物，未修改应用代码或宣称问题已修复。
