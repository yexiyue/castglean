# Spec Delta

## Purpose

为桌面工程助手和专业子 Agent 提供统一的 AG-UI 请求、事件和人工中断契约，使前端能准确展示运行归因与真实状态，同时让宿主继续拥有业务授权、持久化和恢复权威，避免界面重连或协议切换导致重复模型调用与人工结果丢失。

## ADDED Requirements

### Requirement: 统一协议边界
系统 MUST 在新 agent 前后端边界使用固定版本的 AG-UI 请求与事件形状，文本、工具、运行、状态和子 Agent 使用相应标准事件。协议事件不得塞入旧 agent 更新包或先转换成另一套聊天协议；传输订阅身份与恢复游标须与事件载荷分离。

#### Scenario: 桌面启动对话
- **WHEN** 用户在工程助手发送新消息
- **THEN** 宿主校验请求后返回可查询执行身份，并通过桌面 IPC 交付 AG-UI 事件，不依赖额外 HTTP 服务

#### Scenario: 正常结束与挂起
- **WHEN** 一次运行完成、取消、挂起或失败
- **THEN** 事件顺序及终态符合所采用 AG-UI 版本，客户端分别显示真实状态，不将挂起或领域候选待采用显示为业务已完成

### Requirement: 协议数据与行为分别验证
系统 MUST 参照固定版本官方协议，以后端实际输出的序列化回归和行为测试检验生命周期、消息工具配对、共享状态和子 Agent 归因（当前生产端使用快照，不发送 JSON Patch）。不要求修正类型库命名差异或添加通用非法输入/schema 拦截；应用授权与领域校验继续由宿主负责。

#### Scenario: 合法消息往返
- **WHEN** 合法事件或请求经过 Rust 编解码再交给协议客户端
- **THEN** 必填字段、判别字段、归因及开放 JSON 数据保留语义，结果仍满足官方 schema

#### Scenario: 非法输入与流顺序
- **WHEN** 后端发射事件或结束运行
- **THEN** 后端保证所使用字段与生命周期合法，不依赖类型库拒绝所有非法输入，也不伪造完成状态

### Requirement: 专业子 Agent 归因
系统 SHALL 为每次专业子 Agent 调用分配稳定调用身份，发布子 Agent 生命周期和内容归因，支持关联发起工具与嵌套父子关系。同名任务的不同调用不得合并；共享运行状态按任务命名空间隔离，归因标签不创建独立 state 文档。

#### Scenario: 分析及独立预审
- **WHEN** 一次任务依次执行章节归属分析和独立只读预审
- **THEN** 两者具有不同子 Agent 身份，工具与输出归属可辨认，预审结束不等于人工确认分析结果

#### Scenario: 并发事件交错
- **WHEN** 多个允许并行的子 Agent 交错发出文本、工具或状态事件
- **THEN** 前端按调用身份分别展示，不串接消息，不因子 Agent 状态更新覆盖其他任务状态

### Requirement: 挂起与人工继续
系统 MUST 将真正需要继续执行的人工输入表示为持久中断，并校验继续请求的工程、会话、中断身份与未消费状态。挂起释放 Worker 名额；继续产生新的运行身份并关联原运行，能够关联的挂起子 Agent 保留调用身份。领域候选的生成、待采用和人工采用仍为不同事实。

#### Scenario: 子 Agent 等待人工决定
- **WHEN** 子 Agent 在未完成任务中请求人工输入
- **THEN** 持久化中断及挂起结果，关闭本轮事件流，界面显示等待，稍后继续时延续原子 Agent 分组

#### Scenario: 过期或重复继续
- **WHEN** 用户重复回答已消费中断，或回答属于另一工程的中断
- **THEN** 返回已有受理回执或明确拒绝，不重复调用模型或采用候选

#### Scenario: 只生成待采用候选
- **WHEN** 专业任务已经完成计算并发布待人工采用的候选，且没有后续模型工作
- **THEN** 显示任务计算完成和候选待采用，不为等待采用伪造未完成的子 Agent 或占用执行资源

### Requirement: 断开订阅与取消分离
系统 MUST 将订阅断开、重新同步、显式取消和用户重新执行区分为不同操作。前端取消本地事件读取、卸载组件或切换会话只解除订阅；仅用户明确取消可提交宿主取消意图。

#### Scenario: 切页后继续运行
- **WHEN** 用户在任务运行中离开助手页面再返回
- **THEN** 后台任务继续，前端从权威历史与游标恢复显示，不重发启动或取消命令

#### Scenario: 显式停止
- **WHEN** 用户点击停止任务
- **THEN** 宿主确认取消意图并阻止后续工作，等待本地已派发工作退出后发布终态，迟到结果不成为有效候选
