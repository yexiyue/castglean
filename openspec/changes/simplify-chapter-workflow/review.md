## Standards

依据 `AGENTS.md`、`docs/engineering.md`、`docs/data-format.md` 和技术边界文档。以下均已处理：

1. **P2：批量导入部分成功后隐藏后续失败。** 选择文件时明确保持导入视图，提交已完成文件不触发自动离开；失败项保留并可独立重试，不重复创建工程或导入成功来源。
2. **P2：停顿未知结果未保留操作身份。** 保留 run、期望修订、操作 ID 与原始编辑，未知结果只重放原操作；已收到回执就采用宿主编排，不因随后刷新失败而回到旧边界。已知冲突重读，旧快照不能覆盖较新编排修订。
3. **P2（测试）：数字边界选项定位歧义。** 浏览器 `selectOption('1')` 会同时匹配第一项显示名“1”和另一项 value；回归使用显式 `{ value: '1' }` 定位，避免没有真正移动却误判实现。
4. **P3：部分失败后“返回章节”无效。** 显式控制导入视图，可返回工作台后从“追加原文文件”恢复未释放的选择。

TaleChime 当前差异无额外规范问题。规范轴最高原始级别 P2，无遗留阻塞项。

## Spec

依据 `chapter-audio-workbench`、`simplify-chapter-workflow`、`recover-ai-queue-consumer` 和 TaleChime `support-kokoro-numeric-fullwidth-percent`。以下均已处理：

1. **P2：批量导入失败事实不可见。** 与规范轴同一问题，现通过实际路由两文件失败/恢复/往返检查。
2. **P2：切换片段清空失败草稿与重试命令。** 草稿和冻结重试闭包提升到工作台拥有的 `useSegmentEditDrafts`，按工程/章节/片段隔离；片段详情重挂载不清空草稿。
3. **P2：全角百分数被章节单元切开。** 切分器将 ％ 与 % 同等保护，覆盖 112–120 字前缀位置、全角数字、小数和负数，拼接仍精确等于来源。

规格轴最高原始级别 P2，无遗留阻塞项。定向复查确认三项修复，无额外范围扩张。
