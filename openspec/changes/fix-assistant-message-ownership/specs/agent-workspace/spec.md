## ADDED Requirements

### Requirement: 助手流式消息与快照共享展示身份

系统 SHALL 按持久消息与父工具关联将回复、思考和工具调用归入同一展示位置，保留专业任务和问题的真实归因。

#### Scenario: 快捷入口的任务收到多个快照

- **WHEN** 无父工具的专业任务收到流式更新、快照或历史重放
- **THEN** 每条已保存消息在主消息流只展示一次，工具和结果继续可用

#### Scenario: 从父工具委派专业任务

- **WHEN** 有父工具的专业任务完成或重连
- **THEN** 子任务在原父工具内展示一次，沿用持久任务与工具身份
