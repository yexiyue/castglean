# Proposal

## Why

选角建议目前能排序现有音色并给出设计草稿。用户需要在合成前核对试听计划，在审阅时听到实际候选，再决定是否入库和绑定。

## What Changes

- 选角子 Agent 提交批量试听计划。计划包含各目标的首选目录音色，目录无合适音色时可提交设计草稿。宿主校验并通过现有 AG-UI 中断等待批准。
- 宿主持久化批准、生成尝试与产物引用。选角子 Agent 收到真实试听结果后发布建议，结果审阅提供播放器和逐项确认。
- 设计试听保留实际生成的候选。用户显式确认采用时，宿主保存该候选并沿用领域绑定校验和幂等语义。
- 整章自动推进保留在 [助手驱动制作方案](../assistant-guided-production/proposal.md) 后置，本变更可独立实施。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `character-voice-binding`：增加选角试听审批、恢复、结果审阅与设计候选采用。

## Impact

涉及宿主选角工具和结果发布、AG-UI 中断与继续执行、Studio 合成和候选保存、角色绑定及媒体引用。前端复用助手工作区的中断入口、角色中心审阅与共享播放器。实施时同步数据格式和验证记录。
