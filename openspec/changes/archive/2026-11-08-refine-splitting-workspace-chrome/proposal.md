# Proposal

## Why

用户实机截图指出分章页没有沿用新的布局，顶部重复工程名、状态与文字按钮占据阅读空间；要求参考所附 zcode 截图的左右面板图标开关。

## What Changes

- 分章控制并入桌面顶栏，目录/助手开关固定在左右边缘，取消重复工程页头；独立挂载时提供紧凑退化栏。
- 操作改为具名图标与 tooltip，主要继续制作入口保留短文本；撤销、规则和追加入口仍可发现。
- 面板状态与实际响应式布局一致，支持快捷键、键盘焦点恢复，收起后不丢失助手和阅读状态。
- 统一三栏表面与紧凑分区头，原文没有候选时不显示孤立的原文切换行。

## Capabilities

### New Capabilities

- `splitting-workspace-chrome`：分章顶栏与可折叠面板的布局交互。

### Modified Capabilities

无。

## Impact

DesktopShell、分章工作区、助手标题、CSS 与浏览器夹具。仅临时 UI 状态，不改变来源、持久化、AI 任务或采用协议。附件只作视觉参考，不把截图中的小说或聊天文字写入代码。
