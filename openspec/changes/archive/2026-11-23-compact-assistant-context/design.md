# Design

## Context

AgentRun 保存原运行，SQLite 聊天用于审阅与后续投影。模型窗口和请求用量来自现有模型设置。

## Decisions

- 用 Rig 0.47 选择历史切点，收紧到普通用户轮次边界。保留最近的完整轮次和当前运行的原始历史。摘要通过 Rig 验证，模型请求投影再次校验工具配对。
- 会话保存摘要、覆盖前缀的长度及摘要校验值。完整消息和工具事实继续供历史 UI 读取。自动压缩先保存原 AgentRun 请求边界，再提交摘要，随后用摘要发送原请求。
- 手动压缩作为无聊天消息的同会话任务，复用模型绑定、执行租约和队列。成功提交和任务身份一起保存在摘要记录中，重领先核对身份。
- 数据库通过增量列升级到 v12，保留 v11 正文、聊天和运行。
