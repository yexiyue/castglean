# Proposal

## Why

整章消费契约已可用，但当前分析接受窗口仍是私有候选。多角色宿主需要在完整章节完成前取得稳定、证据闭合的前缀，同时准确处理部分交付后的失败与取消。

## What Changes

- 增加只读连续批次、运行身份、确认交付进度和宿主异步消费接口。
- 整章与增量入口共用窗口修复、身份分配、人工保护及最终校验。
- 证据涉及尚未接受的后文时延迟发布；已发布归属不再改写。
- 消费等待响应取消和章节截止，消费拒绝立即停止请求；完成只由最终返回成功表示。
- 补独立无模型示例、Schema、边界测试和文档；不接入 TTS 或持久化前缀恢复。

## Capabilities

### New Capabilities

- `incremental-analysis-delivery`: 有界分析的稳定前缀交付与失败边界。

### Modified Capabilities

无；整章消费契约继续保持。

## Impact

core 公开新增入口及只读类型，既有 API 保持整章行为。CLI/run 继续只提交完整章节；模型适配、提示词和接受条件不变。默认失败 Schema 保持，增量进度单独返回，交付批次提供独立 Schema。对应 CastGlean #1，实际语音联调仍由宿主承担。
