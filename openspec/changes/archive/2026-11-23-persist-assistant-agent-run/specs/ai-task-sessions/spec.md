# Spec Delta

## MODIFIED Requirements

### Requirement: 中断消息不伪装成功
系统 SHALL 保存部分输出。具有可用 AgentRun 检查点的工程助手主运行在宿主重启时重新领取原运行。中断发生在模型轮内时，恢复 MAY 重发该轮模型请求并保留累计计数。已提交的工具事实回复原结果。其他无法续跑的运行继续标记中断。继续执行只使用合法历史，缺失工具结果或截断回答不得表示为成功。取消保留已提交事实。

#### Scenario: 生成中宿主退出
- **WHEN** 宿主在一条助手消息尚未完成时退出
- **THEN** 可续跑的工程助手主运行回到最近的完成轮次，继续原请求；其余运行展示最后持久化内容和中断标记
