# Spec Delta

## ADDED Requirements

### Requirement: 工程助手进程级续跑
系统 SHALL 在重启时重新领取具有检查点的活动工程助手主运行，并保留原运行、消息和工具身份。每项领域写入 MUST 与工具回执同事务提交。宿主从已提交回执补交 Rig 应答，保留既有专业任务恢复范围。

#### Scenario: 工具写入后进程退出
- **WHEN** 工具事务已提交，进程在保存 AgentRun 应答前退出
- **THEN** 恢复读取原回执，使用同一结果推进原运行，副作用和工具记账仅发生一次

#### Scenario: 模型响应中途进程退出
- **WHEN** 持久检查点之后的模型轮仍未完成
- **THEN** 从原请求继续，丢弃该轮未确认的文字增量，保留已提交轮次和已发生的请求计数
