# Design

## Context

Rig AgentRunner 管理内存里的 AgentRun。工程助手需要在模型和工具步骤之间保存可序列化的状态。

## Decisions

- 工程助手主运行用显式 AgentRun 驱动。SQLite 运行行存检查点和正在生成文字的边界。启动恢复用原运行身份、队列和领取代次。
- 在执行任何工具之前先提交模型轮。工具事务保存领域结果与原工具回执。进程重新领取后按同一运行、轮次和调用查找回执，先恢复应答再推进。拒绝的调用先保存终止决定，再记录失败回执，恢复时复用同一个回执。
- 模型流的部分文字可先展示。恢复回到最近完成轮次的文字边界，使用原检查点继续模型请求。账本保留真实尝试。
- 已经交接的专业子任务继续走领域恢复。检查点随主运行终态清理。
