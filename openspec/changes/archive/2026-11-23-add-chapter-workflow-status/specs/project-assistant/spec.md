# Spec Delta

## ADDED Requirements

### Requirement: 单章制作状态与主要动作
系统 SHALL 在章节工作台展示来自当前章节、制作方式和真实生成预检的状态及单一主要动作。动作复用既有分析、归属修正、声音选择、模型资源和生成入口。预检未成功时不得将章节显示为可生成。

#### Scenario: 归属及音色变化
- **WHEN** 用户完成归属分析、修正归属或补齐声音
- **THEN** 状态栏根据重新读取的实际前置条件更新操作，准备完成后可直接发起当前章生成

#### Scenario: 切章后查看原任务
- **WHEN** 用户浏览另一章时已受理的章节任务仍有可查看状态
- **THEN** 状态栏可定位到固定章节并打开原任务所在面板，切章不改变任务目标或重新执行任务
