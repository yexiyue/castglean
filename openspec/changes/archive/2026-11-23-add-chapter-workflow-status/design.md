# Design

## Context

现有宿主提供已保存归属、有效声音绑定、只读生成预检、固定的助手运行目标和音频任务身份。单章状态栏组合现有事实。

## Decisions

- 章节下一步现位于已有播放栏，助手面板收起后仍可用。呈现位置由[局部反馈变更](../localize-workspace-feedback/proposal.md)更新。
- 用确定性规则选择当前阻塞。预检记录绑定章节、制作方式、归属和工程修订，旧请求结果不能发布为当前可生成状态。
- 助手运行以冻结章节为准。音频任务以其章节和制作方式为准。返回执行现有导航保护与面板操作。跨章看到运行后保留返回入口，即使运行先结束。任务状态继续从原会话或返回后的章节音频读回。
- 复用 AG-UI 会话快照与应用组件。建议提示组件继续适用于自然语言跟进，确定性动作直接调用已有用例。

组件选型与版本核对见 [assistant-ui 组件调研](../../../docs/research/assistant-ui-workflow-components.md)。
