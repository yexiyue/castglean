# Spec Delta

## MODIFIED Requirements

### Requirement: 全页面可读与可操作
首页、导入、模型、音色、创建、引导、设置和工程各视图 SHALL 使用一致的页头、间距、焦点与主次操作，保持浏览器引导和真实宿主状态的区别，最小窗口中英文亮暗主题无横向溢出。纯图标导航项 SHALL 同时提供无障碍名称与悬停提示，使读屏与键盘用户与鼠标用户获得同一目的地信息。

#### Scenario: 浏览页面与详情
- **WHEN** 用户在 1024×680 窗口打开列表、详情或设置
- **THEN** 能通过滚动和键盘访问内容及关键操作，关闭弹层可回到原页面，资源准备/删除等既有确认仍生效

#### Scenario: 图标导航项的可访问性
- **WHEN** 用户用读屏或键盘遍历图标导航栏
- **THEN** 每个图标都读出与悬停提示一致的目的地名称，选中项读出当前位置，不出现无名图标
