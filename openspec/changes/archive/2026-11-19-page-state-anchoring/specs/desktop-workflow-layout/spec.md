# Spec Delta

## MODIFIED Requirements

### Requirement: 创建任务优先
音色创建 SHALL 优先呈现核心字段、生成或选择录音入口与候选，保留草稿和返回入口；就绪引擎不重复整个资源目录，未就绪仍可准备。候选面板在没有候选时 SHALL 给出明确空态（图标、标题、说明与下一步），不得只留一行说明文字悬在空面板顶部。设置、上手和工程界面须沿用同一密度与分组规范。

#### Scenario: 创建与返回
- **WHEN** 用户切换方法或返回音色中心后再创建
- **THEN** 已填写草稿保持，未准备资源不伪装就绪，生成与保存仍按既有宿主确认

#### Scenario: 候选面板为空
- **WHEN** 用户进入创建音色页面但尚未生成任何候选
- **THEN** 候选面板给出图标、标题、说明与下一步指引，说明中保留「候选需确认保存后才进入音色库」的约束
