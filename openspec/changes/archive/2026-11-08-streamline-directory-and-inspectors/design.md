# Design

## Context

宿主快照已带完整目录、分卷与问题，无分页 IPC；旧 UI 每百章切片且诊断只取 20 项。全应用 8 处 details 使用会挤压内容。

## Goals / Non-Goals

Goals：目录连续滚动与按卷导航，诊断入口位置恒定；浮层不改变背景尺寸。
Non-Goals：不增加数据库分页或修改原文、AI 协议，不把本地检测等同模型结论。

## Decisions

- 固定行高虚拟树，仅渲染视口和 overscan；完整标题通过 tooltip 显示。基于已有快照，不宣称网络滚动加载。卷/来源使用真实标识分组并保留原始顺序；搜索暂时显示命中分支。
- 支持方向键、Home/End、Enter/Space、左右折叠、显式层级和位置；章号直达展开所在卷并滚动定位，不要求逐页翻阅。
- 目录/待检查固定标签共用侧栏高度，问题完整浏览并点击定位；本地检测与右侧 AI 会话清晰分开。
- 章节编辑、分卷设置改 Dialog，保存成功后关闭；附加信息复用小型辅助 Dialog，保持 Base UI 焦点/退出约定；导入备注、音色高级/管理/传输明细、冲突参考、候选规则、候选模型试听与诊断历史使用相同方式，不再展开挤压背景。输入保留在原所属受控状态，不自动持久化。
- 依据 WAI-ARIA Tree View Pattern 的树键盘/层级约定；NN/g Accordions on Desktop 提醒按需展开有适用范围，不能笼统认定所有 accordion 都违规范。此处选择浮层因为需要稳定阅读/操作位置。

## Risks / Trade-offs

- 虚拟树屏幕阅读器只见已渲染节点 → 标明层级/集合位置，保留活动节点，使用真实浏览器验证键盘与滚动。
- 固定行高截断标题 → 两行标题和完整 title，保留搜索。
- 嵌套 Dialog → 验证关闭最上层、焦点返回和输入保留。
- 原生 WebView → 本轮自动检查与原生验收分开记录。

## 目录与阅读栏减负（2026-11-08）

- 单一搜索支持标题与目录序号（包含前置内容，非小说章号）；纯数字优先精确序号，Enter 选择首个命中，方向下键进入树，不在输入时调用宿主读取。清除恢复完整目录。
- 目录标题紧邻数量，操作菜单明确“编辑章节”；目录/待检查使用线型标签，零问题弱化计数，入口位置不变。
- 章节标题与次级来源选择同组；右侧显示、转到行与分卷设置同高 32px。显示与行号使用 Popover，分卷保留 Dialog；正文只有一个固定工具栏，不因展开改变背景高度。
- 目录位置明确命名，空间不足在来源浮层显示；源文件长名称截断，窄视口收进来源浮层，不挤压标题。
- 跳行保留可见命令及 Ctrl+G，输入有标签、Enter 执行、非法值提示、Escape 退出返回触发入口。
- 取舍依据：Apple HIG Toolbars 的命令优先级/逻辑分组/减少边框；VS Code 的按需 Quick Open/Go to Line。采用项目主题与语义圆角，不复制原生材质。

## 单行目录头（2026-11-08，用户追加）

替代独立标题行、文字标签行和搜索行：目录/待检查使用 32px 图标 tab，具有 tooltip、可访问名称与选中态；目录 tooltip 显示章节数量，待检查仅在非零时显示真实计数。搜索、图标 tab 和操作菜单共用 56px 单行头，与正文栏对齐。待检查的说明放在图标提示中，保持列表起点稳定。目录默认 304px、拖动范围 280–400px，历史更窄会话值仅在显示时钳制到下限，不改变工程持久化数据。章末边界提示与前后章操作在同一行，保持显式切章与长标题截断。

同轮用户补充：目录编辑只有一个动作，移除单项菜单，改为带“编辑章节”提示的铅笔按钮，一次点击打开原有编辑浮层，保留禁用条件、焦点返回及保存校验。

顶部目录图标 tooltip 固定向下、起始边对齐并留 8px 间距；编辑提示同样向下，避免遮住窗口标题栏，沿用 Base UI 视口碰撞处理。

最终视觉以用户提供的 shadcn Tabs 截图为准：复用现有 Tabs 默认分段样式，共用浅色底板、选中项底色及轻阴影；内容为图标，保持 tab 语义、键盘行为及 56px 单行头部。不采用下划线变体或单独按钮高亮，也不新增 Toggle Group。

## 常驻搜索（2026-11-08）

按用户确认的调研建议，替代待检查标签下隐藏搜索框的行为：同一个输入常驻、几何与样式不变，仅更新范围标签/占位提示和值。目录保留原有标题/序号语义；待检查按本地问题类型、所属章节标题、来源文件和显示原文行号筛选（行号为 1 起始），数字只匹配原文行号；不修改总问题计数。两侧查询与滚动独立保留，改变当前查询仅将当前列表回顶。无问题与筛选无匹配使用不同空状态，零问题也保留输入。Enter 定位首个问题、方向下键进入列表，输入本身不读取宿主。所属章节通过按来源的标题行索引二分查找，不遍历问题×章节笛卡尔积。

依据：NN/g Tabs Used Right 建议相关面板保持一致布局；Carbon Searching 提供常驻和收起两种模式。为减少操作选择常驻，边框通过共享 SearchInput quiet 变体弱化，保留焦点强调。

## 图标工具栏与空状态（2026-11-08）

用户确认：正文显示直接 Toggle（pressed=compact），点击切换 compact/original，标签“紧凑校对”，向下 Tooltip 交代当前状态和下次动作；跳行/分卷为 32px 图标按钮且有可访问名称和向下提示，分隔阅读工具与结构操作。显示切换仍保留原窗口/选区/会话偏好，不增加宿主编辑。来源单文件显示文件图标+静态截断名称，多文件才提供明确“切换原文文件”入口；目录位置单独在章节标题旁显示，并解释含前置内容。待检查零问题使用紧凑 Empty：图标、标题“暂无本地检查项”、说明与返回目录，不能声称 AI 检查完成或分章正确；过滤无匹配仍可清除，零问题与无匹配区分。

## 阅读头部重新对齐（2026-11-08）

最终按用户澄清：标题与工具单行居中，当前文件和目录位置收进 Info 图标；悬停/键盘聚焦向下显示详情，点击同样可查看，只有多来源在浮层提供切换文件。长文件名换行，保持详情在视口内。显示使用 32px 图标切换按钮（shadcn Toggle）：pressed=compact 显示紧凑图标，original 显示原样图标；同一时刻只挂载一个，按钮尺寸/位置保持不变，保留稳定名称、向下提示和会话偏好。共享 Switch 保持原样。

## 柔和选中态与居中空状态（2026-11-08）

按用户反馈，目录与问题行横向内收 6px、使用项目 8px 列表圆角；虚拟槽位保持 48px，实际行高 44px 上下留 2px，选中使用浅底及正常前景/中等字重，键盘活动环保持独立。空状态最小高度填满列表视口，由共享 Empty 居中内容；不包括顶部工具栏，短窗口下内容超高可自然滚动，返回/清除仍可到达。

同轮用户指出选中底色左右留白不一致：滚动条占右侧空间，单纯 inset-x 相等不能使整个侧栏视觉居中。目录视口采用 scrollbar-gutter: stable both-edges，两侧等量预留，选中/悬停及空状态都在侧栏内水平居中；有无滚动条/切换标签不改变横向基准。
