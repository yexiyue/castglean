# Proposal

## Why

分章目录分页和诊断隐藏在长列表末尾，无法顺畅定位；分卷、章节与其他页面的附加表单内联展开挤压正文。

## What Changes

- 目录改为按卷/来源分组的虚拟树，连续滚动、标题搜索、章号直达和键盘导航取代每百章分页。
- 诊断作为固定标签入口，显示真实数量，完整浏览并定位所有问题，不再截取前 20 项。
- 章节编辑、分卷设置与全应用同类附加表单/明细使用独立浮层，保留背景位置、受控输入和显式保存。

## Capabilities

### New Capabilities

- `chapter-directory-navigation`: 长目录、分组树与诊断定位。
- `auxiliary-inspectors`: 不挤压工作区的附加编辑与信息查看。

### Modified Capabilities

无。未归档的既有工作台变更仍有效，本轮替代其中目录分页与内联展开交互。

## Impact

React 工作台、导入、音色设计/详情/传输和候选审阅与诊断历史；复用 Base UI Dialog，不修改 Rust、IPC、工程数据或引入虚拟列表依赖。

## 追加范围（2026-11-08）

按用户确认的界面方案，合并目录定位输入，扁平化标签；正文栏以章节标题为主，来源与低频命令弱化、浮层化，不改工程数据。

用户追加优化：将目录头部三行合为图标标签/搜索/操作菜单单行，侧栏加宽，章末导航压缩一行；保留诊断入口与显式切章边界。

常驻搜索追加：在目录和待检查中保持同一输入和固定工具栏布局，各自保留查询与滚动，增加本地问题类型/章节/行号筛选，以低对比度边框平衡视觉权重。

空状态与图标工具追加：补齐本地检查范围说明与返回目录，来源切换与目录位置分离，正文命令使用图标和向下提示，显示模式使用直接 Toggle，保留原文选区/窗口/偏好与显式结构编辑语义。

头部精简追加：文件/序号放入 Info 的悬停/聚焦详情与可固定浮层；显示采用同位置单图标切换，保留标题与工具单行对齐、可访问状态及原有阅读行为。

列表视觉追加：柔和的内收圆角选中态，视口两侧对称预留滚动空间，空状态在列表可用空间内居中，短窗口动作仍可达。
