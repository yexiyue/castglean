# Proposal

## Why

分章工作台已完成交互减负，但其他页面的搜索、创建、设置和反馈仍有重复操作、低频字段常驻及未接入控件占位。按钮、输入、原生下拉和弹层还混用不同圆角，需要一套可复用的规范和跨页面收敛。

## What Changes

- 建立控件 10px、列表项 8px、面板/菜单 12px、弹窗 16px 的语义圆角规范，集中到主题及共享组件，亮暗一致。
- 搜索统一提供清除、Esc 清空、可见标签和键盘焦点；模型、音色和工程筛选有可恢复空态。
- 优化首页与导入入口、模型/音色浏览、音色创建、快速上手、设置和工程阅读/角色/结果界面的一致性与操作层级。
- 音色创建优先展示核心输入，将低频生成选项按需展开；设置减少不能操作的占位表单。
- 保留真实宿主状态、资源准备确认、草稿、人工作业和现有数据格式，不增加虚假的完成或可用状态。

## Capabilities

### New Capabilities

- `desktop-interface-consistency`：全应用的圆角层级、控件、搜索和任务入口的统一体验。

### Modified Capabilities

无。模型与音色的宿主准备、搬运和文件协议沿用已有规格。

## Impact

主题、共享 ui 与页面控件；工程首页/导入/工作区、模型/音色中心、创建与详情、设置和引导。新增本地展示组件，不新增运行时依赖，不修改 Rust 或存储协议。同步品牌、交互说明、README 与知识库，并以真实组件浏览器夹具区分视觉验收和原生桌面验收。
