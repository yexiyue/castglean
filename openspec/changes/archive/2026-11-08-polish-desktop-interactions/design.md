# Design

## Context

共享 ui、页面原生 select 和尺寸变体混用 rounded-md/lg 与 min(radius,px)，导致同类控件不同角度。PageShell 已统一外壳，但搜索无统一清除、设置含不可用开关/输入、音色创建低频参数常驻。动机见 proposal。

## Goals / Non-Goals

Goals：沿用 Base UI、Lingui、Tauri 与现有主题，建立几何规范并逐页简化交互。
Non-Goals：不改配色品牌、宿主协议、下载/推理逻辑、工程格式和真实资产；不把未完成的角色分析/音频制作实现为假功能。

## Decisions

1. 主题增加 control/item/surface/overlay 语义圆角，值为 10/8/12/16px。基础 rounded-sm/md/lg/xl/2xl 映射到 6/8/10/12/16px；共享组件使用语义名，移除尺寸变体的独立 clamp。容器嵌套用明确内角和 overflow-hidden 保证弹窗页脚贴合。不使用全局 !important 覆盖所有边界，贴边工作区仍方正。
2. SearchInput 复用 Input/Button，具名 label、搜索图标、清除、Escape 和焦点恢复；页面仍持有筛选状态。NativeSelect 统一原生下拉的形状/焦点，不改变 option/value/onChange 和原生键盘行为。
3. 首页有工程时提供直接导入入口，空态保留单一主行动并修正旧格式文案；模型/音色搜索保持列表与详情分离。音色预置也可按名称搜索，我的音色批量导出操作在有资产时出现并减少空选择噪声。
4. 音色创建方法改为直接可见的双选项，计算设备和随机种子放高级选项；保留原草稿和同一 start/run。设置移除没有实际动作的占位字段，以简短能力说明替代；设置分类搜索使用同一清除行为。
5. 页面优化覆盖首页/导入、模型中心/设计引擎、音色库/创建/详情、设置所有分区、快速上手及工程正文/角色/结果。共享控件先落地，再针对页面操作与文案调整，不另建设计系统展示产品页。

## Risks / Trade-offs

- [共享样式影响所有页面] → 真实组件/browser 路由矩阵及计算样式断言，不只检查 CSS 文本。
- [原生与 Base UI 下拉形状不同] → 统一外观令牌，保留两者交互语义，不增加兼容封装业务层。
- [隐藏参数使功能难找] → 明确“高级选项”，引擎与模型资源入口持续可见；未实现能力只说明，不伪造可用操作。
- [浏览器无法证明宿主] → 真正产品路由在 browser 模式检查引导/示例；隔离合成 IPC 检查真实组件与任务前置，明确原生未验收边界。
