# Design

## Context

现有 `validate_book` 已检查全文覆盖、UTF-8 边界、正文摘要、角色修订及闭合证据集合。`ValidatedChapter::segments()` 返回只读标注和同一快照切片，`BookState::correct` 返回新修订，不修改旧状态。动机见 proposal.md。

## Goals / Non-Goals

目标是验证和示例化现有完整结果的交接边界。宿主独立保存书籍作用域的 CharacterId 到音色绑定与固定声音配置；核心只提供角色、表达类型和归属。增量发布、TTS 装配、画像推断、自动选角及新持久化版本不在范围内。

## Decisions

- 复用 `ValidatedBook` 和 `ValidatedChapter`，不增加包装 DTO 或第二套覆盖校验。角色引用从同一本书的只读注册表解析。
- 示例用公开人工标注展示 A/B/A、多人同名、第一人称旁白、unknown/ambiguous 和纯空白。宿主示例中用本地枚举表示显式选角策略，保留原标注，不输出厂商音色 ID。
- 交接身份由 book_id、chapter_id、规范化 source.sha256 和共同 character_revision 组成，另有宿主自己的声音配置/执行版本。修正、重分析或共同修订变化时宿主保守重新构造执行；已取得的旧不可变对象不会自动检测新修订，宿主负责比较当前身份。
- `SourceSnapshot::import` 可在分析前调用；仅交付成功返回或已持久化完整结果。失败诊断的 accepted_windows 不能当成朗读范围。
- 公开夹具复用现有 JSON Schema，测试重新验证从保存正文构造的快照。无 DTO 变化，不改 Schema、提示词或运行指纹。

## Risks / Trade-offs

- 结构正确不代表角色归属正确 → 人工夹具只验证消费契约，不报告模型语义准确率。
- 将旁白直接映射为固定声音可能丢失第一人称身份 → 示例先检查归属，再处理无归属表达类型。
- 旧快照仍有效但已过期 → 明确宿主启动/替换执行前比较当前修订；修正示例证明旧对象和正文不变。
- 未来嵌套语义范围可能重复正文 → 当前只遍历完整分区一次；未来语义层不能直接当成第二套朗读范围。
