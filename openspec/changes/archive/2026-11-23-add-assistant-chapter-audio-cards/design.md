## Context

宿主的章节音频表记录稳定任务 ID、阶段、完成单元和正式发布的媒体。章节音频生成入口和全局播放器已交付。

## Decisions

- 助手在消息流末尾显示工程级近期生成任务，最多五项，当前运行优先。用持久任务记录恢复显示，切换会话与章节只改变查看位置。
- 使用 assistant-ui 的独立 Task Card，按原 run ID 读取可播放单元和宿主冻结播放计划。返回动作选择原章节及制作方式，并经过工作台停顿编辑的导航守卫。
- 查询、渲染、重开和试听均不写入任务或生成产物。试听复用全局播放器，可为已保存的停顿准备临时静音媒体。生成继续由现有工作台入口受理。
