# Spec Delta

## Purpose

在 CastGlean 音色中心提供由 Rust 宿主驱动的真实音色库搬运体验，让用户一次选择多个包、检查内容与冲突、导入所选音色或批量导出，并在后台处理期间持续看到可核实的进度与结果。

## ADDED Requirements

### Requirement: 真实音色库与资产边界

“我的音色” SHALL 从宿主权威库读取，导入完成及重启后重新查询；真实列表不混入示例资产。自定义资产不强制绑定一个模型；预置音色不得参与资产包导出。模型未下载 SHALL 不阻止包检查和传输；本变更未接入的修改、删除、生成和试听操作必须明确不可用。

#### Scenario: 没有模型也能导入
- **WHEN** 首次启动、没有任何模型或自定义音色
- **THEN** 我的音色展示真实空态并允许导入，导入后出现真实条目，重启后仍存在

#### Scenario: 示例和预置音色
- **WHEN** 用户切换预置与我的音色，或进入浏览器设计预览
- **THEN** 预置条目没有资产导出选项；浏览器不伪装本机成功入库，示例无法混入真实导出选择

### Requirement: 多包选择与导入预览

系统 SHALL 通过宿主系统选择器一次选择多个包，展示音色名称、数量、大小、参考录音时长、来源和逐项状态，支持全选、取消选择及部分选择。选择取消保留当前页面；文件扩展名不代表校验通过。前端不得解析包或提交任意文件路径。

#### Scenario: 选择两个包的部分音色
- **WHEN** 两个包共有二十个音色，用户只勾选五个
- **THEN** 提交只包含这五个；未勾选条目不进入库，选择与冲突决定保留至任务开始

#### Scenario: 发现损坏包
- **WHEN** 所选文件之一检查失败
- **THEN** 展示文件级原因并阻止该批提交；允许移除问题文件重新检查，不清空其他界面草稿

### Requirement: 可理解的冲突交互

系统 SHALL 分别展示已存在、同 ID 差异、可能重复及同名提示，允许跳过或作为新音色导入，展示本地和输入信息。不得默认覆盖声音或改写元数据，不要求用户输入内部 ID；宿主为“新音色”分配稳定 ID 并返回实际映射。

#### Scenario: 同名不同音色
- **WHEN** 包内音色与本地同名但 ID、内容不同
- **THEN** 提示同名且允许作为独立音色导入，不误报为必须覆盖的冲突

#### Scenario: 同 ID 声音不同
- **WHEN** 用户选择把冲突项作为新音色导入
- **THEN** 预览显示新增结果，宿主分配新 ID，已有资产和工程绑定保持不变

### Requirement: 多选单包导出

“我的音色” SHALL 支持勾选多个条目及全选后导出一个包，明确全选范围；详情单音色导出复用同一流程。宿主选择保存位置并确认已有目标替换；取消选择不得启动任务，只有完整文件发布后才展示成功。

#### Scenario: 筛选结果全选
- **WHEN** 筛选结果有十二条而库内有五十条，用户全选并导出
- **THEN** 界面明确选中十二条并只导出这十二条，不暗中包含其余音色

### Requirement: 后台任务和可查询结果

系统 SHALL 以宿主任务 ID 和递增序号呈现阶段、条目及字节进度，允许取消，并提供任务快照和最终逐项结果。切页、重新进入或漏收事件不得丢失活动任务结果；旧任务事件不得污染新任务。应用重启只恢复音色事实，不宣称恢复未持久化任务。

#### Scenario: 切页与部分成功
- **WHEN** 导入二十条期间离开页面，回来时十八条已导入、两条未完成
- **THEN** 从宿主快照恢复准确状态，最终展示成功、失败或取消明细，并重新查询真实库

#### Scenario: 大包处理期间操作界面
- **WHEN** 后台校验或写入接近上限的合法音色包
- **THEN** 窗口缩放、列表滚动、语言切换和取消入口仍可操作，WAV 和压缩包字节不通过 JSON IPC 来回传输
