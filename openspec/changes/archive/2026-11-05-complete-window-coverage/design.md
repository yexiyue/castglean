## Context

## Goals / Non-Goals
明确窗口目标集合并保留校验历史；不接收补丁、不静默填补非空白，不增加修复或请求预算。
## Decisions
输入提供 target_ids / target_count；提示词要求输出集合恰等于清单，并禁止把上下文当目标。References 将所有应用生成的 missing_segment_ids 转为本窗短引用，继续拒绝不受信任值。诊断 window.validation_issues 按收到响应顺序记录拒绝问题，仅保存安全应用问题，终态类别仍由最终错误决定。
若第二轮报告确认纯空白遗漏，使用现有完整窗口几何范围，只把完整纯空白目标从模型任务中移除；窗口保留可见正文与证据短引用。程序生成 narration/无归属，模型对这些程序目标返回标注仍拒绝；非空白必须完整覆盖。纯空白窗口不调用模型、不消耗远程预算，恢复仍按完整章节。
提示词默认/引文从 7/8 更新为 9/10，CLI run-2；条件性纯空白实现改变后使用 11/12、run-3。分区版本保持 1，正文、片段 ID 与 UTF-8 范围不变。
## Risks / Trade-offs
清单不能保证模型遵循，完整校验仍是接受门槛。纯空白策略以报告证据为触发，未出现则保持全部目标交模型。三轮预算耗尽后保留未完成状态。
## Migration Plan
公开计划同步实际版本；历史报告和旧运行不改动。每轮新目录冻结相同三章正文与预算、实际配置及二进制。最多两轮新增调用。
