# 实现任务

任务按验证证据逐项勾选，未勾选项目可能已有部分实现。按依赖顺序推进，先交付 LLM 设置；测试使用公开合成正文和可控端点，真实服务及平台证据单独记录，不把模拟通过记成真实验收。

## 1. 依赖与通信契约验证

- [x] 1.1 锁定 graph-flow 与 Rig 的兼容版本，关闭 graph-flow 默认 PostgreSQL 和非必需消息桥；通过 `cargo check`、`cargo tree -e features` 确认无意外 SQLx/PostgreSQL、重复 Rig 主版本及额外 runtime，并记录依赖选择于工程约定。
- [x] 1.2 用可控端点验证 Rig 的 OpenAI 兼容、Anthropic、Gemini 文本/流式/工具往返/结构化调用及自定义端点路径；覆盖鉴权、截断、超时和跨源重定向，并记录实际支持矩阵。
- [x] 1.3 用最小任务验证 graph-flow 单步执行、条件分支、等待输入与自定义本地存储接口；加入节点执行后保存失败和重载冲突用例，记录实际 checkpoint 边界及框架约束。
- [x] 1.4 锁定 AI SDK UI 版本并验证 Tauri 自定义 transport 的文本、工具输入/输出、错误与结束消息生命周期；通过可控流契约测试及前端构建，确认不需要 Node/HTTP 服务。
