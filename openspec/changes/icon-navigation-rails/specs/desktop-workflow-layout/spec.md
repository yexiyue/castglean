# Spec Delta

## ADDED Requirements

### Requirement: 图标导航栏
应用级导航栏与工程内导航栏 SHALL 统一为纯图标栏，栏宽约 56px，目的地名称通过悬停提示与无障碍名称提供，选中项保留强调底与 `aria-current`。应用 SHALL 只保留一处设置入口（顶栏），导航栏内的品牌标记 SHALL NOT 承担导航职责，回应用级首页由顶栏入口承担。

#### Scenario: 应用级导航栏
- **WHEN** 用户在工程、音色中心与模型中心之间切换
- **THEN** 侧栏只显示图标，悬停或聚焦显示目的地名称，选中项有明确强调；内容列宽度不因侧栏被压缩到不可用

#### Scenario: 设置入口唯一
- **WHEN** 用户在任何页面寻找设置
- **THEN** 只有顶栏齿轮一个设置入口，界面中不存在第二个同名设置按钮

#### Scenario: 工程内导航栏
- **WHEN** 用户在章节制作、工程角色与制作结果之间切换
- **THEN** 左栏与应用级栏形态一致（纯图标 + 悬停提示），键盘可依次聚焦并读出名称

#### Scenario: 品牌标记不跳转
- **WHEN** 用户点击侧栏顶部的品牌标记
- **THEN** 不发生导航；回工程首页仍由顶栏入口完成
