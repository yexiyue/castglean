# Proposal

## Why

2026-11-10 优先级修订：本变更排在整章生成和单章基础闭环之后，复用其已实现的领域用例；不再以短试听工具卡切片作为下一项产品交付。见[方向决定](../../../docs/knowledge/decisions/chapter-generation-first.md)。

当前用户必须在分章、归属、角色与音色页面之间手工串联流程，助手主要受理单项任务，工具结果仍以过程轨迹和跳转为主。需要让用户用制作目标驱动工作，在对话中处理分歧、查看真实生成进度、试听产物并查看生成信息，同时保留正文和资源的直接操作。

## What Changes

- 工程助手读取真实制作状态，为明确目标维护可恢复的步骤及阻塞；按需调用领域工具和专业子 Agent，避免用户学习内部任务划分。
- 增加宿主持久化的交互请求：说话人分歧、音色选择、候选采用等用类型化工具卡呈现，用户决定可校验、幂等提交并恢复；不以自然语言“好的”代替准确目标和操作。
- 增加异步任务工具卡：受理、排队、执行、取消、失败及产物分开表示；对话内直接试听音色设计/短文本试声结果，展开真实模型、音色、输入、设备、用量与耗时信息。
- 能力按只读查询、领域命令、用户交互、异步任务和专业子 Agent 分工，复用现有 Rig、SeaORM、任务系统和播放器；同一能力供聊天和直接操作调用。
- 默认工作台突出正文、当前步骤和待决定事项，助手可收起为状态入口；保留章节制作、工程角色、制作结果三个稳定入口和独立资源入口，减少必须跨页处理的动作。
- 前置产品阶段先按独立章节音频规格交付整章生成/播放及单章基础闭环；本变更随后把已实现的章节任务投影为交互卡，短文本试声和设计作为补充验证。章节合成、局部重做、采用及导出语义由音频域拥有，不在此另写执行器或把短试听标为整章完成。
- **BREAKING**：为目标、交互请求和任务引用增加版本化宿主协议；删除被新卡片替代的重复前端编排，不新增旧界面兼容层。保留用户工程、历史和人工修改。

## Capabilities

### New Capabilities

- `assistant-interactions`：对话内的持久化用户决定、异步任务卡、媒体产物操作及真实生成信息。

### Modified Capabilities

- `project-assistant`：目标驱动的跨步骤推进、工具与子 Agent 的职责、工作台渐进展示；保留固定上下文和人工采用边界。

## Impact

- 宿主：`src-tauri/src/ai/{tasks,service,messages,dispatch}.rs`、`ai/assistant/tools/`、数据库实体/迁移，以及 `voices/studio/` 的持久化任务适配。领域命令继续由各域拥有，不由模型或前端写数据库。
- 前端：`session-messages.tsx`、`imported-workspace.tsx`、`project-workspace.tsx`、`use-ai-session.ts`、`lib/ai/transport.ts`，复用声音候选卡和播放器。
- 补充 SQLite/协议并发与恢复、浏览器中英亮暗小窗口、macOS 原生和真实模型验收。依赖现有角色中心撤回/忽略待办，不能通过本方案将其勾成完成。
- 本变更为待实施方案，不改变当前已交付状态，不承诺整书批量、自动质量裁决、完整章节音频或所有模型质量。
