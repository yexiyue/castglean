## ADDED Requirements

### Requirement: 手动重置不兼容数据库

系统 SHALL 在宿主确定数据库版本不受支持且持有数据目录所有权时，提供归档旧库并重新启动的显式操作。

#### Scenario: 归档并重启

- **WHEN** 用户选择备份并重置
- **THEN** 系统完成 SQLite 日志归并并关闭连接，把原数据库移到当前数据目录的独立备份位置，重新启动后创建当前版本空库
- **AND** 保留正文、音色、音频、模型和应用设置文件

#### Scenario: 放弃或无法安全归档

- **WHEN** 用户退出提示，归档失败，或当前错误属于读取、权限或迁移失败
- **THEN** 系统保留数据库并停止启动
