# Spec Delta

## MODIFIED Requirements

### Requirement: 完整且不可变的正文标注

系统 MUST 将有效结果表示为按源顺序覆盖整章且不重叠、不遗漏的非空片段，分别标记旁白、台词、内心独白。未完成的人工版本 SHALL 以明确的「未标注」区间补足结构覆盖，未标注可朗读内容不构成有效的多角色生成计划。所有坐标绑定同一来源摘要及半开 UTF-8 字节范围，字符、换行、空白与章节范围保持原样；一个段落允许有多个不同类型或说话人的片段。

#### Scenario: 同段多个说话人
- **WHEN** 一段正文含两个人物对话、插入叙述和内心独白
- **THEN** 结果可分为多个精确片段，不强制整段只属于同一个人，也不把叙述插入语计入人物台词

#### Scenario: 空白及多字节文本
- **WHEN** 正文含中文、emoji、组合字符、BOM、混合换行与连续空白
- **THEN** 标注按范围拼接与整章原文字节完全相同，空白归入相邻片段，不产生越界、字符中间边界或正文规范化

#### Scenario: 只标注了一部分原文
- **WHEN** 本章只完成部分人工标注
- **THEN** 未选中的可朗读文字保留为未标注，不标作旁白、未知说话人或人工确认。用户可通过生成前检查定位该范围，多角色生成拒绝启动

#### Scenario: 手工完成整章
- **WHEN** 所有可朗读原文已有有效类型与归属
- **THEN** 本章可按同一套角色绑定、模型能力和资源条件进行多角色预检，无需先运行 AI；单音色旁白仍直接使用原文

### Requirement: 明确的身份与归属语义

系统 SHALL 分别表达片段类型、归属的已解析/未知/歧义状态和未审阅/人工确认状态。尚未标注的人工范围 SHALL 有可区分的状态，尚未对这些范围判断类型或说话人。旁白身份独立于人物身份；台词或独白的未知归属不得伪装成旁白，模型使用已有角色身份也不得自动标记人工确认。

#### Scenario: 无法确定发言者
- **WHEN** 当前证据不能区分两个候选人物或未出现可识别人物
- **THEN** 分别保存歧义候选或未知状态与理由，界面不自动选择第一个候选，不以旁白音色回退改写语义身份

#### Scenario: 模型给出明确角色
- **WHEN** 模型输出一个存在于当前工程的角色身份
- **THEN** 宿主验证引用合法，但该片段仍保持未审阅，结构有效不被解释为语义正确
