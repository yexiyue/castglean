# Tasks

本轮已跑通无 AI 的原文归属和 AI 发布顺序。下方各项保留完整验收条件，已通过的用例见[验证记录](validation.md)。

## 1. 宿主归属与角色事务

- [ ] 1.1 扩展归属版本、校验与分页投影，实现在原文中切分、精确替换和保留选区外保护。单测覆盖旧版本读取、未标注与未知分离、同段多角色、混合换行、中文、emoji、组合字符、空白覆盖和越界拒绝。确认模型协议继续只接受既有三种语义类型。
- [ ] 1.2 接入按范围手动写入与可选的原子建角，复用工程锁、期望修订和持久回执。宿主测试覆盖首个写入、同名显式选择、跨工程角色拒绝、回执丢失后的重试、同章并发、章节范围变化和事务失败无部分提交。
- [ ] 1.3 接入首次与后续人工撤回、历史及重开恢复，更新数据格式说明和 Specta 类型。宿主测试验证首次撤回恢复无人工标注、保留角色与音频、历史可查、修订单调、旧数据可读及不支持新格式的版本明确拒绝。

## 2. 分析发布与音频制作

- [ ] 2.1 让 AI 发布按冻结修订更新归属并提示覆盖。宿主测试覆盖无人工状态时首次发布、人工先于 AI 发布、AI 先于旧人工命令、旧任务不覆盖较新边界、后发 AI 更新并提示、同源非冲突补全和拆合后晚到结果。
- [ ] 2.2 接入本章剩余范围的显式旁白提交及未标注阻塞。验证批量只修改未标注的可朗读区间、更新修订且可撤回，多角色预检和启动一致拒绝未完成范围，手工完成并绑定后可生成，单音色旁白及旧产物继续可用。更新章节制作状态说明。

## 3. 正文入口与工作站验收

- [ ] 3.1 基于原文端点加入归属图标、键盘入口与归属对话框，提供范围预览、类型、角色选择和显式创建。浏览器测试覆盖无模型的第一次标注、跨页和反向选择、同一行的局部重标注、离开/取消、选区/复制/引用及焦点回到正文。核对中英文、亮暗和窄窗。
- [ ] 3.2 在现有检查弹窗和正文联动呈现部分标注、定位和批量旁白确认，接入保存失败重试与撤回反馈。浏览器验证归属与音色操作独立、状态回读后才更新、处理后保留阅读位置，并同步 README 与工作台说明。
- [ ] 3.3 用隔离 macOS 工程验收未配置模型的手工标注、补全、重开、试听与整章多角色生成，并用独立已配置样本验证 AI 乱序发布与后发覆盖提示。分别记录浏览器夹具、原生窗口和实际模型结果，运行相关 Rust 测试、Clippy、前端构建、浏览器回归及 OpenSpec 严格校验。
