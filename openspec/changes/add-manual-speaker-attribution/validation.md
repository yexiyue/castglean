# 本轮验证

日期 2026-11-22。目标是跑通未配置 AI 时的正文归属，并验证同源分析按冻结修订发布。

- 无 AI 路径从工作台正文开始。选区浮条打开居中的归属对话框，支持角色搜索、复用和同次提交新建。可用正文选区或 Alt+Enter 打开。章节标题菜单可撤回上次归属修改。
- 版本、角色和回执经同一 SQLite 事务保存。部分归属使用明确的未标注区间。生成前检查可定位原文，也可显式把本章剩余未标注区间设为旁白。
- 归属顺序由冻结修订判定。较旧分析仅可补全独立未标注范围。基于当前修订的结果可以更新人工归属，结果卡显示提示，撤回恢复上一版。
- Playwright 的 5 项相关用例通过。覆盖反向选区、取消后重选、保存既有角色、键盘入口、新建角色、撤回、剪贴板兼容，以及分析任务卡显示持久覆盖提示。浏览器使用隔离的 IPC 夹具。
- Rust 章节归属 68 项和章节音频 47 项测试通过。覆盖首次原子建角、回执重放、撤回、复用已有角色、补旁白、旧任务保留较新修订，以及后发 AI 更新和持久提示。发布测试连接本地 SQLite，使用受控分析结果。
- TypeScript/Vite 构建、87 项前端单测、Lingui 严格编译、Clippy、Specta 导出和本变更的 OpenSpec 严格校验通过。
- 隔离 macOS 窗口、外部模型实际输出、真实试听和整章多角色合成仍待单独验收。

## 提交前审查

- 正文切片保留 U+FEFF，避免选择和写入使用不同的字节坐标。回归覆盖已标注正文中 BOM 后第一个汉字的真实选区。
- 手动提交在桌面会话中保留原请求、命令 ID 和确认修订。丢失回执后重试原命令，回读必须达到确认修订才关闭弹窗。
- 工程助手聊天受理时保存当前章归属修订，稍后为该章派发分析时复核。无可安全合并的迟到初次分析以候选留存。助手结果卡使用宿主保存的覆盖标记显示对应语言的提示。
- 章节菜单可撤回当前归属修改。通过历史选择任意旧版本恢复仍待实现。
