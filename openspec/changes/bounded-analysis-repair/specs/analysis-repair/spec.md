# Spec Delta

## Purpose

单章分析利用确定性校验反馈在硬预算内修复模型候选，保护原文和已有数据，提升可恢复性；该能力同时提供可关闭的对照路径与运行统计，便于评估结构恢复与实际语义效果。

## ADDED Requirements

### Requirement: 有限校验反馈修复

系统 SHALL 默认允许每窗口一次修复，可显式设置为零；仅语法、结构、覆盖、证据和身份引用错误允许修复，通过校验后必须立即结束窗口。未知及歧义归属是合法结果。

#### Scenario: 候选修复成功
- **WHEN** 首次返回无效引用，修复返回完整有效候选
- **THEN** 系统接受修复结果并进入下一窗口，不额外请求完成确认

#### Scenario: 修复耗尽或关闭
- **WHEN** 允许的修复全部无效或修复设为零
- **THEN** 系统返回安全错误，不发布完整产物

### Requirement: 原子接受窗口

系统 MUST 在候选全部校验成功前保持角色及片段上下文不变，整章通过最终校验后才返回完整结果；已有人工数据不得被候选覆盖。

#### Scenario: 新角色候选含坏片段
- **WHEN** 候选声明新角色但片段覆盖校验失败
- **THEN** 修复请求与后续窗口的正式角色上下文不包含该失败角色

### Requirement: 安全且有界的反馈

系统 SHALL 反馈固定错误码、程序生成位置及必要的受信任 ID，不回传原始解析或服务错误。修复请求包含原窗口输入及最近失败候选，候选作为数据；超限先省略旧候选，仍超限则停止。

#### Scenario: 私有字段及超限候选
- **WHEN** 解析错误含任意模型字符串且附候选的修复输入超限
- **THEN** 外部错误不含该字符串，修复仅包含原输入及安全反馈并遵守输入预算

### Requirement: 共享预算与取消

系统 MUST 将首次及修复请求计入同一章节请求上限，修复前预留剩余窗口各一次请求；默认章节时限为 600 秒。取消、超时、服务失败、输出截断及大小超限必须停止，不自动网络重试。

#### Scenario: 请求不足与章节超时
- **WHEN** 修复会占用后续首次请求预算或章节时限到达
- **THEN** 系统停止且不发送预算外请求、不发布结果

### Requirement: 统计与 CLI 配置

系统 SHALL 提供修复次数及章节时限的 library 和 CLI 配置；成功结果统计所有取得响应的调用，包括拒绝候选，并记录修复调用和成功窗口数，新增统计字段缺省兼容旧文件。

#### Scenario: 两次生成一次修复
- **WHEN** 首次错误后修复成功
- **THEN** 统计包含两份 usage、两份响应大小、一次修复调用及一个修复成功窗口
