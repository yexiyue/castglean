# 提案：归属规则与独立评测基线

## Why

现有六个样例存在歧义金标与同名身份对齐的局限，评分无法充分暴露角色合并、重复和虚构。需要先固定通用标注规则和独立评测集，再决定后续模型改进方向。

## What Changes

- 定义匿名身份、确定归属、有限候选及未知来源的中文标注规则。
- 建立四十个原创场景，开发与留出各二十个，冻结正文、金标及评测元数据。
- 增加有界章内一对一身份匹配、评分上下界、角色表指标及失败分母；保留历史入口行为。
- 运行本地与国内 MiniMax 各八十次章节分析，不更改生产提示词、协议、公共 API 或接受条件。

## Capabilities

### New Capabilities

- `attribution-evaluation`：版本化公开语料、角色及表达评分、可复核基线运行和失败统计。

### Modified Capabilities

无；主规范尚未同步，既有生产合同保持不变。

## Impact

变更只涉及文档、公开评测数据、Python 标准库工具、离线测试和 CI。密钥与完整模型产物继续忽略；不新增 crate、Agent、跨章状态或外部集成。
