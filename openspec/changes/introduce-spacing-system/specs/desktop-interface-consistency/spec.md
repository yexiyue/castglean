# Spec Delta

## ADDED Requirements

### Requirement: 间距尺寸体系

业务界面 SHALL 使用统一的间距档位体系：允许档位为 4px、8px、12px、16px、24px、32px 及更大的页面级档位，按相邻档相对差距不低于约 25% 选取，不要求线性倍数；业务代码不得使用 6px、10px 等半档（Tailwind `.5` 刻度）表达布局间距。档位按角色使用：控件内部与相关元素组内间隙用 8px 档，面板与条带水平内边距统一 12px 档，组间 16px 档，区块间 24px 档，页面级留白 32px 档及以上。结构栏高 SHALL 对齐：桌面顶栏与侧栏品牌区同为 44px，无桌面顶栏的工作台回退 header 同为 44px，章节工作台 header 为 56px。`src/components/ui/` 组件库保持上游内边距与控件密度刻度，作为显式例外不参与归档。

#### Scenario: 跨页面节奏一致

- **WHEN** 用户在工程首页、导入、模型、音色、设置与工程工作台之间切换并对比同类面板与条带
- **THEN** 面板水平内边距、状态条带内距与组间间距保持同一档位取值，不出现 6px、10px 级的含糊间隙

#### Scenario: 顶栏与品牌区同高

- **WHEN** 用户打开任一工程工作台
- **THEN** 侧栏品牌区与桌面顶栏高度一致（同为 44px），头部两段带不出现 44px/48px 混档

#### Scenario: 归档不引起布局回归

- **WHEN** 在 1024×680 最小窗口以中英文、亮暗主题浏览各页面
- **THEN** 间距归位不引起换行、溢出或控件挤压，既有键盘路径与焦点顺序不变
