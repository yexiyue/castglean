# Design

## 体系定义

间距轴与控件密度轴分离。布局间距遵守一套档位；按钮 `h-6/7/8/9`（24/28/32/36px）等控件密度刻度属于 `src/components/ui/` 组件库，保持 shadcn 上游原样，不参与归档。两者数值有重叠但语义不同：前者表达元素之间的关系，后者表达单个控件的状态密度。

### 允许档位（相对差距 ≥25%，不要求线性）

| 档位 | 值 | 角色 | Tailwind 刻度 |
|---|---|---|---|
| 1 | 4px | 图标↔文字、极紧组内 | `1` |
| 2 | 8px | 控件内距、相关元素组内间隙 | `2` |
| 3 | 12px | 面板/条带水平内边距（现已是事实标准 `px-3`，确认之） | `3` |
| 4 | 16px | 组间 | `4` |
| 6 | 24px | 区块间 | `6` |
| 8 | 32px | 页面级留白 | `8` |
| 12+ | 48px+ | 页面级大留白（首页、空状态） | `12`、`16` |

淘汰半档 `1.5`（6px）、`2.5`（10px）、`3.5`：它们与相邻整档的相对差距不足 25% 或卡在两档正中间，无法表达"更紧"或"更松"的关系，是节奏随机的直接来源。

### 结构栏高

| 位置 | 现值 | 归一 | 依据 |
|---|---|---|---|
| 桌面顶栏 | 44px（`h-11`） | 44px 不变 | 与章节 header 56px 相差 27%，符合阶梯；44→48 升档反而与 56px 只差 17% |
| 侧栏品牌区 | 48px（`--app-header-height: 3rem`） | **44px（2.75rem）** | 与顶栏底边平齐，左上角横线合一 |
| 工作台 fallback header | 40px（`h-10`） | **44px（`h-11`）** | 无桌面 chrome 时与顶栏同高；40 与 44 相差仅 10%，淘汰 |
| 章节 header | 56px（`min-h-14`） | 56px 不变 | 按钮换行容器，`min-h` 已按内容伸缩 |

顶栏维持 44 而非升 48，是"阶梯按相对差距选取，不要求 16 的倍数"的直接应用（用户确认的取舍）。

## 半档归位清单（业务代码，非 `src/components/ui/`）

按类名统计（2026-11-17 普查，共 30 处、19 个文件）：

| 现值 | 处数 | 归位规则 |
|---|---|---|
| `mt-0.5` | 8 | 微调偏移，逐处判断：光学对齐可删则删，否则 `mt-1`；以渲染结果为准 |
| `gap-1.5` | 8 | 图标↔文字行归 `gap-2`；紧凑 chip 组归 `gap-1` |
| `gap-2.5` | 6 | 松散行归 `gap-3`，紧凑行归 `gap-2`，按所在分组角色定 |
| `py-0.5` / `p-0.5` / `px-0.5` / `gap-0.5` | 6 | 2px 不在阶梯内：能删则删，需要保留时归 `1`（4px） |
| `py-1.5` / `px-1.5` / `mt-1.5` | 3 | 归相邻整档（`2` 或 `1`），按条带密度 |

**保留例外**：`models/model-logo.tsx` 定义层的两处 `p-0.5`（CpuIcon 回退与 sm 徽章内衬）不归位——它是 `biome.json` 显式登记的定义层密度例外，改 `p-1` 会使 sm 图标字形比 default 档小一档（视觉回归）；该内衬表达图标盒内部密度，不是元素间布局间距，在本体系的密度轴豁免范围内。`voices/voice-studio-page.tsx` 的 Link 登记值 `gap-1.5` 随归位同步更新为 `gap-1`。

文件分布（行数）：`voices/voice-library-rows.tsx` 5、`settings/about-settings.tsx` 3、`settings/llm-settings.tsx` 2、`projects/casting-suggestion-panel.tsx` 2、`models/model-logo.tsx` 2、`models/model-center.tsx` 2、`components/detail-properties.tsx` 2，其余 12 个文件各 1。逐处替换前先看渲染结果；替换后跑 `pnpm check` 与受影响页面目验。

## 定点修复

1. **顶栏按钮边距**：`desktop-shell.tsx` 中 Home 链接 `mx-3` 与新建链接 `mx-2` 统一为 `mx-2`（同一栏同类控件同值；Home 左侧已有 macOS 通行区 `pl-[78px]`，不需要额外让位）。
2. **检查面板底部双重内边距**：`imported-workspace.tsx` 底部容器 `p-3 border-t` 内嵌的模型确认告警条自带 `border-b px-3 py-2`，水平内边距叠成 24px 且边线悬在 padding 盒内。修复为去掉内层 `px-3` 与 `border-b`，仅保留纵向节奏（`py-1` 量级按渲染定）。
3. **`--app-header-height`**：`src/index.css` 值改 `2.75rem`；该 token 仅 `app-sidebar.tsx` 一处引用，无连带。
4. **fallback header**：`imported-workspace.tsx` `h-10` → `h-11`（仅浏览器开发预览可见，与顶栏对齐）。

## 文档落点

- **DESIGN.md** Layout 段：补档位表与角色映射，与 Shapes 段语义圆角同构；声明 `src/components/ui/` 密度刻度例外。
- **docs/engineering.md**：一条约束——业务界面间距只用允许档位，半档类不得新增；指向 DESIGN.md。
- **docs/knowledge/decisions/**：新增决策记录——"间距阶梯按相对差距选取"（记录用户否决线性 16 倍数方案及 44 vs 48 的推导）、"组件库密度轴与布局间距轴分离"（记录 shadcn 兼容取舍）；更新知识库索引。
- **README**：不在能力清单中新增条目（无功能变化），仅当验证边界变化时更新。

## 风险与验证

- 归位引起的换行/挤压风险集中在 `voice-library-rows.tsx`（5 处）与设置页；逐处渲染核对，1024×680 最小窗口回归。
- e2e 断言基于角色与文案，不依赖间距类名；跑 `e2e/` 相关 spec 确认。
- `gap-0.5`/`mt-0.5` 类微调涉及光学对齐，删除与保留以渲染对比为准，不做纯机械替换。
