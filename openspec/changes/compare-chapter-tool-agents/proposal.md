# Proposal

## Why

前一轮两路线同时改变提示、协议和并发，无法隔离运行时影响；单次整章 JSON 还出现覆盖缺失及格式错误。用户已选择方案 C：用真实 Agent＋草稿工具＋校验反馈和有界局部修正，直接对照现有 Rig Agent 与 ECS。

## What Changes

- 在隔离实验包增加共用的不可变片段、草稿工具、反馈、完成条件与预算。
- 两运行时使用相同模型、初始输入、提示、工具定义、最终校验与独立预审，不更改正式应用入口。
- 固定数据与程序身份，记录逐模型请求和工具调用、修正效果、失败与未知用量。
- 使用旧公开十例作回归，并新增冻结的未用于调参样本；真实小说仅独立授权烟测，不混入公开质量分母。

## Capabilities

### New Capabilities
- `chapter-tool-agent-evaluation`: 真实工具循环的共有草稿协议、有界反馈与跨运行时公平评测。

### Modified Capabilities

无。正式应用的分析、人工采用和存储契约保持原状。

## Impact

仅实验包、共享评测接入、显式测试用原生凭据桥及验证文档。使用已安装 Rig 0.46，两路线不引入产品迁移或发布权限。
