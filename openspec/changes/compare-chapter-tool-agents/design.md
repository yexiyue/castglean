# Design

## Context

旧原型使用一请求零工具角色，主线使用固定 JSON 流水线；旧两路线输入/协议不同，不能归因运行时。当前原型已具备原生凭据桥、取消子进程和共享固定集。

## Goals / Non-Goals

目标为两种真实 Agent 运行时共用工具、输入、反馈、预算与模型传输，观测修正后的合法交付和语义质量。非目标为迁移产品、自动采用、放宽覆盖、工具回填金标或复活旧库。

## Decisions

- 首轮已知规范人物身份；角色候选工具保留能力但独立评分不冒充身份发现质量。
- source 片段由宿主按确定性 Unicode 边界生成；模型引用 ID，宿主还原 UTF-8；整章初始可读，上下文补查可用工具。
- 五工具共用同一状态机：read_source、propose_characters、patch_annotations、check_draft、finish_analysis。patch 以修订、operationId 幂等，验证整个批次后替换连续 ID 范围，不覆盖非目标结果；失败不部分写入。语义未知不擅自旁白填空。
- analysis 与植错 review 独立实例；review 使用只读候选和 finish_analysis 中审阅建议，不能改写候选。分析草稿完成不等于人工确认。
- 两边同一模型包装器、low、4096 输出上限、16 次模型请求、每个分析/预审 agent 32 次工具调用（任务内共享 16 次模型请求）、最多三次失败完成/校验修正反馈和 300 秒总期限；已知 token 达 64k 后停止新请求，未知成本保持未知。工具串行，不隐式网络重试。
- trace 不含正文/工具参数/理由；记录调用名、修订变化、错误码、问题数、预算、配置/提示/工具Schema/代码/数据摘要，模型用量仅请求 span 记一次。
- 先受控脚本验证错误反馈后修复与取消，再冻结代码/提示并跑相同公开集。旧十例仅称回归集；新增冻结集首次在线前锁定，不看结果后调参重跑冒充盲测。

## Risks / Trade-offs

工具循环可能更慢、成本更高；工具调用格式仍可能失败。报告计入所有失败和未完成结果，比较有效交付与质量后才解释速度。两个 runtime 的工具历史与调度差异单列，不把 JSON 单次历史基线当纯运行时对照。

## Migration Plan

隔离实验 package 新入口，旧 CLI 和默认应用保持原状。原生桥扩展仅 cfg(test) 的显式请求路径，完整保留工具请求/响应，凭据只在原生 Rust 读取。私人正文和运行产物均在忽略目录。

## Open Questions

服务实际 tool calling 能力需要真实请求先验验证，失败如实计入；不借其他模型目录假定支持。

## 2026-11-09 用户授权的无 token 上限复验

保留默认有界 profile，新增显式 `unlimitedTokens:true` 实验配置：不设置请求 max_tokens、不设置 ModelSpec 输出预算、不执行 64k 累计 token 停止；不冒充取消服务商本身容量限制。两条 Agent 的提示、工具、16 次请求、32 次工具准入、3 次失败校验和 300 秒任务期限保持。原生 helper 必须收到显式 opt-in 且 max_tokens 为空，禁止额外参数旁路。

使用同一已授权小说快照与同一模型，对照旧预切片紧凑 JSON、classic Agent 和 ECS；不据结果调提示。两轮反向执行顺序，逐次保存初稿与完整流水线的交付、用量及耗时；JSON 仅分析，Agent 含独立生成预审，指标必须分阶段，不把额外预审成本归因于协议本身。所有私人产物留在 target，26 处历史检查集只在结果后离线评分；输入、程序、模型配置、提示及 token profile 在请求前冻结，校验失败保留。


## 2026-11-09 中途修复授权

用户进一步要求已知问题及时修复，避免下一轮重复失败。原无上限运行保留原始身份；新工具版本单独冻结和复测，不能拼接成同一版本的成对结果。

- 人物声明改为批量、有 operationId 幂等和模型局部 ref 到宿主规范 ID 的映射；不按名字合并，整批验证后提交。
- 片段补丁允许稀疏批量提交：宿主推导实际修改范围，仍逐段严格验证且原子写入。缺口不自动填补，最终完成继续要求整章完整覆盖。
- 仅允许可证明不相交的陈旧补丁安全重放：目标范围在 expectedRevision 之后已有修改则拒绝；未来修订、已有段跨边界修改及同 ref 不同身份继续拒绝。追加人物不因无关批次而使所有不相交补丁失效。
- 错误反馈提供当前修订、有效片段首尾和数量、有限未知 ID、缺口或候选格式要求；不泄露 gold、不推断语义、不返回虚构完成状态。
- 新提示只解释新工具合同和身份发现权限，不根据 gold 调语义答案；新协议号与提示/工具摘要分别记录。先受控回归，再进行真实章节快速复验，未通过前不启动大批重复付费评测。


## 用户追加无时间上限与思考模式

显式 unlimitedTime:true 关闭整条工具工作300秒、共享模型调用600秒、helper请求/HTTP总期限和外部进程期限；清理回收仍独立有界，仍保留模型16次、工具32次、失败校验3次，不声明远端服务网关永不超时。预算与实际提示同步为无执行期限，所有层透传该配置并回归验证，不只延长最外层等待。

同一修复后工具版本先以low快速对照，再增加当前Agent的无时间上限low组；思考对照使用同一模型的provider-default与low（官方说明GLM-5.3-Flash强制思考，不能disabled）。仅记录HTTP白名单参数与响应reasoning_content是否返回/长度和usage，不保存或展示思考文本。参数已发送不等于服务已执行，网关未回传的推理用量保持未知；必要的参数探测不含私人小说。
