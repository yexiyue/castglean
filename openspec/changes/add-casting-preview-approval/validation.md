# 选角试听审批验收

2026-11-18，macOS Apple Silicon，独立应用标识与公开两章工程。使用 GLM Flash 生成计划和建议，使用本机已就绪的 VoxCPM CPU 与 MOSS Nano CPU 生成试听。

| 场景 | 结果 |
| --- | --- |
| 批量审批与重启 | 旁白预置、阿岚设计同批出现。关闭并重开应用后恢复原审批，只批准阿岚。宿主记录旁白未批准、阿岚可播放。 |
| 设计试听与采用 | 角色中心播放约 3 秒的实际设计音频，经明确确认后入库并绑定。SQLite 绑定引用该库资产，试听和库内 WAV 的 SHA-256 完全一致。 |
| 目录首选试听 | 单独批准旁白的 Weiguo 预置试听。宿主发布一次建议，角色中心通过共享播放器加载约 2 秒的真实音频。 |
| 宿主和协议 | 442 项通过、10 项按原配置忽略。恢复回归覆盖同一审批复现、多窗口竞争和原请求重放。候选保存测试核对重开库后重复保存仍只有一个资产。 |
| 前端 | TypeScript、Lingui 构建、8 项浏览器会话回归通过。覆盖中英亮暗窄窗口、键盘选择、刷新恢复、拒绝、不可试听状态和编辑后部分批准。 |

原生复测修复了两个问题。模型省略设计引擎时由宿主预选，实际引擎和设备在批准前展示。已持久化的审批由宿主确定挂起，避免 SDK 停止回合被当成用户取消。

原生验证覆盖 macOS Apple Silicon 以及上述已准备的模型。平台及其他模型组合待独立验收。

补充故障验证：

- 在 Qwen CPU 试听进入运行状态后终止隔离进程。重启记录原运行中断，显式重试后列出未完成条目。初版恢复卡缺少助手消息，按钮不可操作。修复为先保存可恢复消息，再创建无旧工具归属的重试卡。对既有隔离记录补齐这一消息后，实测新尝试成功，原尝试仍为中断，建议只发布一次。
- 替代建议发布后重启。旧预览已回收，已入库 WAV 保留。最新预置试听仍可读取，跨工程和跨建议的音频读取均返回未找到。
- 在隔离库向绑定写入注入 SQLite 错误。已保存资产仍可读取，原绑定修订保持；移除注入后重新确认并重放相同请求，只推进一次绑定修订，音色库仍是一份资产。
