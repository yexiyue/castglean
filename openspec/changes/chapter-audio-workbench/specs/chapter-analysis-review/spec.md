# Spec Delta

## ADDED Requirements

### Requirement: 分析后按角色分段呈现
系统 SHALL 在有效分析发布后按归属片段顺序分块，固定左侧角色列显示旁白、角色名或未知/歧义，正文自然换行且不插入行内角色标签；同原文行的不同归属分块，同一片段跨行保持一个逻辑块。未分析时紧凑阅读，分析中保持现有布局和位置，失效分析不得作为当前有效角色布局。

#### Scenario: 旁白与台词相间
- **WHEN** 一段原文含旁白、角色台词和后续旁白
- **THEN** 展示三个顺序块，角色列对齐、正文用间距分隔，不改字、不增删实际段落；长角色名可查完整名称，未知或歧义明确标示

#### Scenario: 发布及失效
- **WHEN** 首次有效分析发布或当前分析因章界改变而失效
- **THEN** 发布后保留阅读锚点并切为角色布局；失效后显示紧凑正文与原因，旧标注仅能在明确历史视图查看

### Requirement: 制作对象检查器
系统 SHALL 随选中对象显示对应信息：正文或音频块显示归属、声音、真实状态及定位/试听入口，停顿显示时长与删除操作；无选中时可收起或展示章节概况。切换不清空助手草稿、检查草稿或改变任务，只有宿主提交成功才显示修改已保存。

#### Scenario: 从失败音频到停顿
- **WHEN** 用户选中失败块后再选中停顿
- **THEN** 先显示失败原因与对应正文，再显示停顿时长编辑；返回助手时会话和输入保持，不隐式调用模型
