# Design

## Context

动机和范围见 proposal.md。当前 `chapter_audio` 已逐单元持久化原文范围、角色、音色、状态、媒体身份和真实时长，执行事件主要返回 run，`use-chapter-audio` 再查快照。单元只有 pending/done/failed/empty，不能仅凭 completedUnits 推导执行位置。`unitTimeline` 当前过滤未完成单元，可能跨过缺口；新轨道必须显式阻止这种试听跳跃。

`AnnotatedLine` 按原文行切片并把归属标签插入行内；正文读取和复制已有 UTF-8 范围、空白显示与虚拟窗口约束。分析 segment 是语义块，生成 unit 是模型约束下的执行块，二者不能混为同一身份。

活动变更 `attribution-review-and-playback` 的段首标签和无队列管理限制与本次展示有冲突。实施时将其标记由本变更接续，保留其异常驱动待检查规则；先协调后归档，不能让归档顺序复活旧规则。现行主规格 `continuous-source-reading` 的逐行展示要求由本变更 delta 更新。

## Goals / Non-Goals

**Goals:** 保持来源及既有生成事实不可变，用同源宿主编排驱动轨道、试听和导出；让当前进度、片段声音和失败范围可见；所有编辑可恢复、可检测冲突。

**Non-Goals:** 不引入通用 DAW、原文重排、自动重试或云端计费策略；不依靠新模型推理决定展示；不把历史无停顿的 chapter.wav 当作编辑后最终结果。

## Decisions

### D1：按分析有效性选择正文投影

没有有效分析使用现有紧凑/原样投影；分析中保留当前投影，有旧有效分析时继续显示它，首次分析完整发布后自动切角色投影。角色块采用固定角色列和正文列，未知/歧义明确标示，旁白统一列出；无卡片外壳、无行内标签。角色列建议 88–112px，小窗口可收窄，长名截断可访问。选择和播放分别加轻背景，异常沿用 warning token。

拒绝以原文行号组织分析后主布局：一行可含多角色，一个片段也可跨行。以 segment.id + source hash + ByteRange 建立逻辑块，可将超长块分成有界显示窗口，只在逻辑块起点标角色，续读明确为同一块。渲染块必须保存到原字节范围的映射。虚拟化保留选择节点；读取不一次拉取整章。行号跳转、错误定位和章末切章继续使用来源坐标。

布局变化前记下来源字节锚点及视口偏移，变化后恢复，不回到章首。分析失效回到紧凑当前正文，历史分析单独只读，不把旧范围套到新章。紧凑/原样是未分析阅读偏好，不作为逃避角色布局的兼容层。

### D2：底部制作区与相互独立的状态

保留现有外壳和目录，底部轨道横跨正文及右侧检查区域，目录保持独立。默认高度约 200px，可键盘或拖动调整，可收为控制条；小窗口钳制高度，正文仍能阅读。生成启动立即展开，恢复历史不强制改变用户收放偏好。轨道内横向滚动，虚拟化只保留可见单元和活动选择。

控制条包含阶段、已处理/总数、实际音频产物数、播放/暂停、前后片段、取消/继续、添加停顿和导出。只将当前可行动作突出。初次未开始生成时不伪造轨道产物；计划在宿主提交后展示全章占位。模型加载、合成、写盘、拼接分别呈现实际可得阶段，未知子阶段不补造。

增加宿主明确的当前执行单元身份和单调状态修订；不把第一个 pending 或 completedUnits 当成执行单元。pending/done/failed/empty 可保持存储枚举，当前执行是单独 run 投影。事件携带 run 身份及修订，前端重订阅/终态回查权威快照，丢弃跨章和过时响应。检查生成进度事件是否被旧前端状态覆盖，作为本次具体修复入口。

selectedUnit、playingUnit、generatingUnit 独立。用户手动滚动暂停相应跟随，提供“回到播放/生成位置”。生成跟随只移动轨道，不持续滚动正文；正文只在显式定位或用户开启播放跟随时滚动。切章不影响后台目标，也不把另一章音频放在当前章轨道中。

### D3：占位顺序轨道与真实时间轴

有未知时长时用统一最小宽度的顺序音频块，显示状态、角色/声音、文本摘要和已知时长，不显示全章秒刻度或估算波形。全部必要单元时长确定后启用时间比例和缩放；默认切换保留选中块视口锚点，不打断播放。极短停顿的可点击手柄可以宽于其时间标记，但不得改变刻度值。空白 unit 保留覆盖事实，不作为等待音频块或任意静音。

波形不是首版交付条件，有真实摘要才展示；占位状态不画随机波形。文本摘要按来源范围有界读取且只在 UI 使用，不进入日志。

### D4：正文、轨道与播放器同源映射

单击块选中并定位正文，块内播放按钮从该 unit 起播；正文选中 segment 时定位其首个单元，具体已生成范围可单独起播。播放时高亮精确 unit 范围，不把 segment 拆成多段阅读块。定位不触发播放。

按 unit.index 检查连续覆盖，遇 pending/failed/媒体缺失即停止，empty 透明通过；拒绝现有“过滤缺失后继续”的队列逻辑。播放启动固定可播连续区间和编排 revision，新完成单元不自动追加，编辑停顿不改变在播会话，提示重新播放生效。前后片段动作也不静默绕过缺口。保持音色试听和章节音频互斥；切章释放当前播放，后台生成继续。

### D5：独立编排持久化与安全边界

宿主新增 chapter_audio_arrangements 与编辑记录（工程、章节、run、来源哈希、分析版本、计划指纹、revision、版本化 content）。content 的 pause 列表包含稳定 id、左右 unit 身份与相邻范围边界、duration_ms；不保存小说正文。无编辑的既有任务解释为空编排，不改动历史音频。

首版允许两个相邻可发声单元之间的边界，中间纯空白可跨过；不支持章首/章末或音频内部任意坐标。停顿按左右范围锚定，不按时间偏移锚定；相同来源/分析/计划重开可恢复，不兼容计划保留旧编排并阻止自动继承。

默认停顿 500ms，允许 0–10000ms、步长 10ms，0 等价删除；这是额外静音，不替代模型自身已有句读停顿。拖入工具、边界“添加停顿”、拖动现有停顿到其他合法边界、边缘拖动调整、数值输入和删除提供等价键盘路径。同一边界只存一个停顿，移到已占边界时拒绝并提示，不隐式累加。

命令使用 expectedRevision、operationId 和宿主回执，事务校验范围、身份、时长与所属工程；冲突返回刷新，失败保留草稿。编辑日志支持最近一次有效编辑撤销，作为新修订提交，跨重启有效；不能越过其他编辑撤销旧状态。前端拖动预览可即时变化，宿主成功前不显示已保存；拖动结束一次提交，Escape 取消预览。

允许生成中编辑安全边界停顿，因编排不参与 TTS 输入身份，不取消生成或让合成缓存失效。分析/绑定变化后的兼容性由宿主判断，不在前端猜测。此变更不提供音色修改后的局部重生成。

### D6：播放和导出共用编排时间轴

宿主解析当前编排为有序 audio/silence entries，携带 unit 范围、真实时长和 revision；前端只执行，不自行决定缺口或静音采样数。停顿期间选中停顿、正文显示同边界标记，暂停、继续和 seek 都必须作用于包括静音的时间轴；后台页面挂起后按媒体时钟/会话位置恢复，不能仅以未校正的 setTimeout 叠加。

原 chapter.wav 只代表无编辑拼接结果，非空编排使用单元串播及精确静音；只有无停顿且身份完全匹配时可复用单文件。已完成音频块不覆盖，编排改变不会触发引擎调用。

导出先在宿主冻结 run/plan/arrangement revision 和全套媒体身份，验证来源有效、无缺口、PCM 格式兼容、文件完整及覆盖顺序。阻塞线程流式复制 PCM 和写入静音，静音采样帧统一使用 round(duration_ms * sample_rate / 1000)，播放计划使用同一有效时长。默认输出 16-bit PCM WAV，继承一致的采样率/声道；不兼容则明确拒绝，本轮不隐式重采样。

导出状态可查询，取消在有限写块间检查；目标同目录临时文件完成同步后原子发布，禁止目标位于来源/内部产物目录。覆盖须确认且发布前核对目标变化，失败不破坏既有目标；磁盘满、目标不可写、源文件损坏和取消分别验证。导出期间编辑不改变冻结结果，完成回执包含 revision 和时长，后续编辑使旧导出显示为旧版本。

### D7：规格接续和验收边界

新 capability `chapter-audio-editing` 统一管理轨道、停顿和导出，避免把章节制作的全部职责放进分析规格。两个 modified delta 保留主规格完整旧场景并扩充投影和选区规则。实施时同步更新活动变更的取代说明与相关现行文档，不提前将本规划写成已完成状态。

## Risks / Trade-offs

- [角色块增加高度并改变虚拟尺寸] → 用来源锚点恢复，覆盖超长片段、页边界、选区固定与字体变化。
- [全章时间未知] → 先用明确顺序占位；完整后再提供秒刻度，不用模型语速估计替代事实。
- [生成与编辑并行] → 合成身份与编排修订分离，播放/导出冻结版本，事件只更新所属对象。
- [静音播放与 WAV 差异] → 共用采样帧取整与编排时间轴，验收 seek 到静音内部、暂停恢复和最终时长。
- [旧规格归档覆盖新交互] → 实施及归档前核对活动变更接续，未完成原生验收各自保留。

## Migration Plan

1. 在当前数据库版本上新增编排和编辑记录，事务迁移；旧任务默认无停顿，旧文件和用户数据原样保留。未知 schema 拒绝写入，迁移失败不清库。
2. 增加宿主投影、命令和 bindings 后接入角色布局及轨道；采用现有主题和组件，不保留旧行内标记的另一套行为。
3. 接入停顿播放、编辑和导出，再执行故障与真实窗口验收；验证完成前 README 标记已实现/未验证的实际边界。
4. 回退只回退展示/服务路径，不删除新增记录；不支持降级读取的新 schema 应明确停止，禁止用旧程序改写新格式。
