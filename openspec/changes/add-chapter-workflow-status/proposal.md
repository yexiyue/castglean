# Proposal

## Why

章节工作台已经具备归属、绑定和生成预检。需要把实际阻塞和一个可点击的下一步放在同一处，并在切章后保留任务入口。

## What Changes

- 为章节工作台增加可见的 Agent 状态栏，展示单章制作状态与主要动作。
- 根据归属、音色绑定、预检和产物状态选择动作，复用既有工作台用例。
- 使用运行的固定目标回到原章和任务所在面板。

## Capabilities

### New Capabilities

### Modified Capabilities

- `project-assistant`：单章制作状态、下一步和跨章返回。

## Impact

章节工作台及现有助手、分析和音频状态的读投影。
