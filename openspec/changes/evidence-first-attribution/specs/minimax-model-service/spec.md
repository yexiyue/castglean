## Purpose

让独立 Rust 库及 CLI 使用用户显式配置的国内 MiniMax 模型分析小说窗口，保持凭据与业务数据分离，同时沿用不可变正文、应用校验、取消与有限预算的行为约束。

## ADDED Requirements

### Requirement: 显式国内服务配置
系统 SHALL 提供 minimax 后端及独立模型、端点、密钥配置，保持参数大于进程环境大于配置文件的后端优先级，不自动切换服务，不在诊断或产物中包含密钥。

#### Scenario: 切换 MiniMax
- **WHEN** 用户显式选择 minimax 且提供有效配置
- **THEN** 请求使用对应端点及凭据，GLM 和本地设置不影响该请求

### Requirement: 安全有界生成
系统 SHALL 将模型正文与思考分离，验证响应、限制接收大小、不重定向或自动重试，拒绝认证错误、截断和服务错误，失败不发布章节。

#### Scenario: 响应带思考
- **WHEN** 服务返回独立思考内容与最终正文
- **THEN** 仅将最终正文交给核心 JSON 校验，保留可取得的用量统计

#### Scenario: 服务拒绝请求
- **WHEN** HTTP 或业务状态表示认证失败或限流
- **THEN** 返回安全类型化错误，不回显服务响应
