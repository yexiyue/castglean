# Spec Delta

## Purpose

为已经安装的 CastGlean 提供可信且可控的版本升级，让用户查阅更新、决定安装时机，并在升级后继续使用已有工程与本地资源。

## ADDED Requirements

### Requirement: 检查并显示适用的更新

支持的正式桌面包 MUST 允许后台与手动检查更新，检查不得阻塞启动。应用 MUST 仅提供同渠道、适用于当前平台且版本更高的更新，并显示当前版本、可用版本、摘要及发布页。

#### Scenario: 已经是最新版本

- **WHEN** 更新源返回同版或更低版本
- **THEN** 应用不提供安装，手动检查给出无新版本的结果

#### Scenario: 发现可用新版本

- **WHEN** 更新源给出更高的本渠道版本且平台信息完整
- **THEN** 应用展示更新详情和用户可以选择的动作，当前工作继续进行

#### Scenario: Windows 更新复用 CUDA 运行库

- **WHEN** Windows 应用更新，且已安装的 CUDA 运行库满足新版本引擎要求
- **THEN** 下载的 Windows 应用更新包不包含 CUDA 运行库，安装后继续复用现有运行库

#### Scenario: 更新后需要另一个运行库版本

- **WHEN** 新版 Windows 应用需要不同的 CUDA 运行库版本
- **THEN** 应用可启动，模型中心在用户选择 CUDA 时提示单独准备所需版本，旧运行库及工程数据保持可用

#### Scenario: 更新源无法使用

- **WHEN** 检查超时、离线或清单无法读取
- **THEN** 正式安装的应用可正常使用，设置页提供清楚的检查结果和重试入口

### Requirement: 用户控制可信安装

升级 MUST 校验下载归档的签名。应用 MUST 在明确用户操作后才下载更新，在用户确认且应用能安全退出时才安装和重启，并提供真实的下载或安装状态。

#### Scenario: 归档签名不匹配

- **WHEN** 下载归档损坏或签名不受信任
- **THEN** 应用不安装或重启，旧版本保持可用，并提供明确的失败状态

#### Scenario: 更新下载失败

- **WHEN** 下载中断
- **THEN** 当前应用和工程仍可使用，用户可以重试或稍后安装

### Requirement: 安装保护进行中的工作

安装前 MUST 重新核对活动任务及未保存编辑。应用 MUST 保护章节生成与导出等活动任务，完成保存或者让用户明确处置未保存改动，并防止新任务与安装并发进入。

#### Scenario: 完成下载后出现新任务

- **WHEN** 用户确认安装时有章节生成、WAV 导出或其他冲突任务活跃
- **THEN** 应用延后安装并说明原因，原任务继续按原语义执行

#### Scenario: 用户取消退出

- **WHEN** 用户在未保存编辑提示中取消
- **THEN** 应用保留编辑与当下工作，不执行安装或重启

#### Scenario: 安装失败后继续工作

- **WHEN** 宿主无法安装已验证的更新
- **THEN** 应用释放为安装持有的任务保护，报告失败并允许继续工作或重试

### Requirement: 跨版本升级保持本地数据

应用更新 MUST 延续本渠道的应用身份和本地数据路径。升级 MUST 保留工程、已采用音频及停顿、音色库、设置与模型缓存，不自动重置不兼容的数据库。

#### Scenario: 以已安装候选版验证升级

- **WHEN** 用户通过应用更新器从已安装的候选 A 升级到更高的已签名候选 B
- **THEN** 应用重新启动并显示 B，原工程和采用音频可重新打开、播放和导出，音色、设置和缓存仍可使用

#### Scenario: 本地数据无法由新版本打开

- **WHEN** 应用重启时发现数据库版本不受支持
- **THEN** 应用遵循现有保留原库与显式备份流程，不把空工程列表当成成功升级
