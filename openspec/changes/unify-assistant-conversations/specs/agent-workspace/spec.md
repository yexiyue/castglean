## ADDED Requirements

### Requirement: 主助手与专业子任务的可见回复

系统 SHALL 在同一工程会话展示主助手和专业子任务的可见文字，并保留 AG-UI 消息归属和稳定身份。领域结果和用户决定 SHALL 由宿主结果及权限校验驱动。

#### Scenario: 阅读分析任务的答复

- **WHEN** 从快捷入口或主助手启动章节分析
- **THEN** 会话显示分析角色、其可见回复和归属结果入口，工具过程默认折叠

#### Scenario: 思考与状态

- **WHEN** 主助手或子 Agent 提供可见思考摘要
- **THEN** 在该回复内用行内状态显示运行情况，并允许展开摘要
- **AND** 摘要缺失时只呈现已观测的活动状态

#### Scenario: 恢复会话

- **WHEN** 通过 AG-UI 快照重开或恢复会话
- **THEN** 消息保留原调用归属，结果和答复不重复显示
