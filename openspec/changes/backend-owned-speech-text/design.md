## Context

不同模型的规范化与特殊标记不同，文本规则由所选后端负责。

## Goals / Non-Goals

宿主传递精确单元原文，各后端按自身模型规范处理。通用控制标记不从用户原文自动解释为人工读音意图。旧任务兼容性需单独识别，不清除任何产物。

## Decisions

各后端接收精确原文并按自身规则处理或报错；真实引擎、单元测试和文本矩阵分别验证。

宿主为每个任务冻结 `ResolvedModel::revision()` 与 `text_semantics_revision()`，续跑时比较当前解析结果。缺失身份、模型资源版本或文本算法变化时创建新任务，不删除已有音频。

## Risks / Trade-offs

不同后端依赖不同预处理，需分别对照；音频成功不能证明文本被完整朗读。
