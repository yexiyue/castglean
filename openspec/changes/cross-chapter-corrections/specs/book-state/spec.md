# 书级状态

## Purpose

通过来源绑定、修订检查与完整书级校验，让调用方可靠地继续分析和修正同一本书，在保留正文和稳定人物身份的同时明确章节知识边界，保护人工确认并保证失败不发布。

## ADDED Requirements

### Requirement: 完整有序快照
系统 SHALL 校验并保存同一书身份的有序正文、章节标注、角色表及共同修订，不解释章节 ID 为排序或文件路径。

#### Scenario: 继续同一本书
- **WHEN** 新章追加通过完整校验
- **THEN** 旧章正文与人物 ID 保留，共同修订递增一次，返回完整新状态

### Requirement: 多候选与获知边界
系统 SHALL 保持同名人物独立，别名查询返回多个已获知候选，拒绝章节表达引用未来首次获知的身份。

#### Scenario: 同称呼
- **WHEN** 两个不同身份共有一个名字
- **THEN** 查询同时返回双方，不自动合并

### Requirement: 有限重分析
系统 SHALL 仅重分析最后一章，验证相同正文与原切片，失败或取消不改变已提交状态。

#### Scenario: 重跑较早章节
- **WHEN** 请求重分析的章节不是末章
- **THEN** 在模型请求前拒绝

### Requirement: 一致发布
系统 SHALL 核对预期修订，并仅将全量有效候选发布到新的快照目录，禁止覆盖已有目录。

#### Scenario: 过期修订
- **WHEN** 操作预期修订与状态不符
- **THEN** 拒绝操作，不调用模型也不发布新产物
