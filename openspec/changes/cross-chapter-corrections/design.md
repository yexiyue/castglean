# 设计

## 背景

参见 proposal。现有 analyze_chapter 已顺序接受只读 ValidatedBook，但禁止重跑已有章节；注册表与标注有共同修订，validate_book 校验完整证据闭集。CLI 目前仅输出单章新目录。

## 目标与边界

书级状态使用一个聚合 JSON 文档，顺序就是章节边界；继续三个 crate，核心不做文件 IO。任意旧章重跑、合并/撤销、恢复及跨进程并发冲突检测后置。本轮不再调整模型协议、预算或冻结金标。

## 决策

- 新增私有 book 与 corrections 模块，公开具体 BookDocument、BookState、CorrectionBatch 等类型。BookState 持有校验后的整书与变更记录，不提供可变引用；成功操作返回新状态。
- 聚合文档嵌入已有角色表及正文/标注，registry.revision 为共同提交修订，所有章节同步引用。每个操作递增一次并记录动作，预期修订错误在调用模型之前返回。单文件聚合避免字符表和章节文件的半次更新，CLI 暂用不可变新目录发布，不做活动指针和原地覆盖。
- 身份获知章节从最早有效角色证据派生，别名查找返回章内有序多个角色；不自动根据名字合并。书级校验拒绝表达引用尚未获知的角色。
- 追加使用完整当前前缀。重分析只接受最后一章、原正文和同一完整切片，保留所有已有角色身份，保护已确认归属及人工确认的非对白类型。复用窗口执行、修复和整体校验；未确认结果可更新，人物不会自动删除。
- 修正批次携带书身份与预期修订。归属修正必须包含章节、正文摘要、片段正式 ID、类型及归属，程序设置确认状态；别名替换须在所供原文证据中实际出现，同名合法，保留姓名与身份。批次全通过才构造下一状态，旧状态保持不变；记录完整修正与修订供复核。
- 归属人工修正清除该片段旧的模型引文扩展，避免把原建议引文当作新人工判断证据；其他扩展保留。已确认非对白用保留字段 castglean.human_confirmed 标记，重分析保护整个片段。

## 风险与迁移

整个正文聚合会随书增长，后续 D 可改为清单和分文件事务，本轮不建立存储抽象。预期修订只约束调用者提交的快照，不能保证跨进程活动分支唯一。历史单章 JSON 不改变，可用 BookDocument 构造并校验导入；已有 validate 保持原行为。新旧章的修订引用统一是提交绑定，不代表重写正文或角色身份。结构校验不保证模型跨章语义匹配正确。

## 验证

离线验证追加复用身份、同名独立、边界、修订溢出及冲突、非法证据、来源变更、批次回滚、已确认 unknown/非对白、别名保护、末章重分析失败/取消不修改旧状态、往返及 CLI 完整发布。提供两章原创例子和离线库示例，GLM 小范围验证同一复用流程，不追求新的准确率基线。完成 workspace/Python/fmt/Clippy/rustdoc/OpenSpec 检查。
