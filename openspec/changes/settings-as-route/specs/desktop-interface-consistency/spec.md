# Spec Delta

## ADDED Requirements

### Requirement: 设置页面与返回入口

设置 SHALL 以独立路由页面呈现（`/settings`，`?section=` 携带分区，支持深链直达服务连接、存储位置等分区），入口唯一为最左侧栏底部的设置按钮（模型资源状态同处底部栏）；设置页面内部分类导航与分区内容同为面板底色双栏呈现，地址随分区变化以替换方式更新，后退一次即离开设置。顶栏 SHALL 在设置页面提供返回按钮：存在历史时后退到进入设置前的页面，否则回工程首页，且焦点归还到打开设置前的元素。未识别的分区 SHALL 回落到默认分区，不留空白面板。

#### Scenario: 底栏进入与返回

- **WHEN** 用户在任一页面点击最左侧栏底部的设置按钮，再点击顶栏返回按钮
- **THEN** 进入设置页面的对应分区，返回后回到进入前的页面与状态，焦点回到打开设置前的元素

#### Scenario: 失败路径直达分区

- **WHEN** 章节工作台提示服务连接不可用，用户点击「服务连接」
- **THEN** 打开设置页面的服务连接分区，地址栏为 `/settings?section=models`

#### Scenario: 未识别分区回落

- **WHEN** 用户手输 `/settings?section=unknown`
- **THEN** 显示默认分区内容，不出现空白面板

## MODIFIED Requirements

### Requirement: 可清除搜索

集合搜索 SHALL 提供可见清除动作和 Escape 清空，保持输入焦点；无结果可恢复到原集合。设置页面搜索非空时 Escape 只清除搜索，不产生页面导航。

#### Scenario: 搜索无结果

- **WHEN** 用户输入没有匹配的工程、模型或音色名称
- **THEN** 显示无匹配状态，点击清除或按 Escape 恢复原列表

#### Scenario: 设置搜索 Escape

- **WHEN** 用户在设置页面分类搜索中按 Escape
- **THEN** 搜索词被清空且分类列表恢复，页面不发生导航
