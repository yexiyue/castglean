# Spec Delta

## MODIFIED Requirements

### Requirement: 角色中心页面

系统 SHALL 在工程外壳内提供角色中心页面（非浮层弹窗），采用目标列表与目标详情的主从结构：列表呈现旁白（置顶）、已确认角色（含绑定状态摘要与待审建议标记）与候选角色分组，支持搜索；详情集中承载所选目标的身份操作、声音画像、绑定状态、选角建议对照与音色设计发起。目标级表单与统计 MUST 在所选目标详情内就近渲染，不出现脱离触发上下文的页面级游离表单；设计候选 MUST 呈现在发起设计的目标详情中并预选该目标为绑定对象（可改选其他目标）。页面保留工程上下文与未提交输入，离开页面不取消进行中的建议或设计任务。

#### Scenario: 从工程入口进入角色中心

- **WHEN** 用户点击工程角色入口
- **THEN** 进入角色中心页面，工程导航与标签保持，列表读取实际角色身份与候选/已确认状态及各目标绑定摘要，不显示示例人物

#### Scenario: 建议按目标对照审阅

- **WHEN** 存在选角建议且用户在列表中选择某目标
- **THEN** 详情并排呈现该目标当前绑定与建议条目（画像建议、候选音色理由、试听与逐项采用），列表以标记提示有待审建议的目标；已人工绑定的目标默认保持不动并显示差异说明

#### Scenario: 表单就近渲染

- **WHEN** 用户在详情内触发重命名、添加别名或查看使用统计
- **THEN** 相应表单与统计呈现在该目标详情内的对应分区，不改变列表滚动位置，不在页面其他位置出现游离表单

#### Scenario: 设计候选绑定预选

- **WHEN** 用户从某目标详情发起设计并生成候选
- **THEN** 候选呈现在该目标详情中，绑定操作预选该目标且可改选其他目标，不渲染面向全部已确认目标的按钮列表

#### Scenario: 从会话结果进入审阅

- **WHEN** 用户在工程会话中点击选角建议结果卡的审阅动作
- **THEN** 进入角色中心并定位到首个有待审建议的目标详情

#### Scenario: 页面状态与后台任务保持

- **WHEN** 用户在角色中心留有未提交的画像或设计输入，切换到章节制作后再返回
- **THEN** 输入与位置保留，进行中的选角建议或设计任务不受影响，返回可继续审阅

### Requirement: 选角建议任务执行

系统 SHALL 将 AI 选角建议作为固定工程目标的专业任务执行：复用共享子 Agent 设施与隔离上下文，冻结输入（已确认角色及其原文证据、旁白目标、音色目录元数据、当前绑定状态，以及触发消息中用户对本次选角的具体要求），模型经有界工具回合以原子提交工具产出完整建议，宿主校验失败提供有界修复反馈；重复派发不重复发布建议，取消与失败如实保留已完成事实。

#### Scenario: 冻结输入后目录变化

- **WHEN** 建议运行期间本地库音色被删除
- **THEN** 任务按冻结输入完成或失败；宿主在结果审阅时按当前目录重新校验建议条目并标注失效，不静默沿用

#### Scenario: 重复派发

- **WHEN** 同一建议任务被重复投递或响应丢失后重放
- **THEN** 最多发布一次建议记录，迟到执行者不能覆盖新结果

#### Scenario: 用户要求随输入冻结

- **WHEN** 用户携带自定义要求（如"只配主角，配角先不管"）发起选角
- **THEN** 要求原文随输入一并冻结并进入子 Agent 上下文；恢复或重试使用冻结的要求原文，不读取会话后续消息；未携带要求时按默认意图执行，不虚构要求
