# Spec Delta

## ADDED Requirements

### Requirement: 会话内选角建议审阅

系统 SHALL 在助手会话的选角建议结果处提供与角色中心等价的逐目标审阅：候选音色列表与理由、试听播放（复用已批准试听与预置音色的既有播放通道）、采用绑定与采用画像。卡内采用 MUST 走与角色中心相同的显式命令，携带期望工程修订与绑定修订，不引入旁路写路径。生成期间，会话在选角建议结果处显示本批已处理条目数与总数，并区分生成、收尾与失败；结果区 MUST NOT 只能通过展开工具调用访问。设计草稿编辑与音色设计发起仍在角色中心完成，会话内提供到达该流程的入口。

#### Scenario: 卡片内试听并采用绑定
- **WHEN** 用户在会话的选角建议结果处试听某候选并选择采用绑定
- **THEN** 采用经同一显式命令与期望修订校验完成，成功后该处显示当前绑定，重复点击呈现为当前绑定而非再次换绑

#### Scenario: 卡内采用与角色中心一致
- **WHEN** 用户在会话内完成采用后打开角色中心
- **THEN** 两处显示一致的绑定状态、画像来源与建议失效标注，无半套变更

#### Scenario: 生成进度锚定在结果处
- **WHEN** 批准的试听进入生成且会话可见
- **THEN** 选角建议结果处随生成推进更新已处理数与失败计数，生成结束后过渡到逐目标审阅，不再显示重复的独立进度条

#### Scenario: 设计路径跳转角色中心
- **WHEN** 用户在会话内选择某目标的设计草稿
- **THEN** 会话跳转到角色中心该目标的设计流程并带入草稿，设计入库确认不发生在会话结果区

#### Scenario: 读取失败如实呈现
- **WHEN** 会话内审阅所需的建议、绑定或模型数据读取失败
- **THEN** 结果处如实显示读取失败与重试操作，不显示空候选或伪装可用
