# Spec Delta

## ADDED Requirements

### Requirement: 会话内候选结果操作

系统 SHALL 在助手会话的归属分析结果处提供候选级就地操作：采用候选（全部有效片段）为待确认初稿、放弃候选与重分析入口，走与检查器相同的宿主命令与校验；卡内显示候选的当前业务状态（待采用、已采用、过期、来源变化），独立查询不从运行成败推断。逐片段的选择、修正与确认保护仍在检查器完成，会话内提供定位到该候选检查视图的入口；聊天文本本身不获得确认、采用或修改正文的权限。

#### Scenario: 卡内采用候选
- **WHEN** 用户在会话结果卡内采用一个仍有效的分析候选
- **THEN** 候选按全部有效片段经同一命令成为待确认初稿，卡内与检查器读取到同一当前版本

#### Scenario: 过期与来源变化标注
- **WHEN** 候选依赖的来源或归属已变化
- **THEN** 卡内如实标注过期或来源变化并禁止采用，提供重新分析入口

#### Scenario: 段级修正仍走检查器
- **WHEN** 用户需要逐片段修正或确认保护
- **THEN** 会话内入口定位到该候选的检查视图，修正经检查器完成并受人工保护约束
