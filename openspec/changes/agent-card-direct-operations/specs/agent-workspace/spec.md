# Spec Delta

## ADDED Requirements

### Requirement: 结果卡就地领域操作

专业任务的结果卡 SHALL 按展示行、进度、结果面三段式呈现：结果面由结果引用的类型驱动，提供所属域的就地操作，操作走该域的显式命令并按命令自身的期望修订与幂等语义校验。结果卡显示的业务状态 SHALL 独立查询权威数据，不得从运行成败推断；进度 SHALL 锚定在产生它的工具调用旁并随生成推进更新；结果区 MUST NOT 只能通过展开工具调用访问。就地操作完成后，结果卡与对应专职界面读取到一致状态；命令冲突、读取失败与目录失效在卡内如实呈现，不伪装可用。

#### Scenario: 卡内采用后状态一致
- **WHEN** 用户在结果卡内完成一项领域采用后打开对应专职界面
- **THEN** 两处显示一致的当前状态与来源，无半套变更

#### Scenario: 修订冲突如实拒绝
- **WHEN** 卡内操作提交时工程修订已被其他操作推进
- **THEN** 命令被拒绝，卡内显示冲突与重新读取入口，不重试覆盖或伪装成功

#### Scenario: 折叠态可见与进度锚定
- **WHEN** 专业任务进入生成或收尾阶段，或其结果已发布
- **THEN** 进度与结果区在工具卡片折叠态外可见，随帧推进更新，完成后过渡到结果面

#### Scenario: 读取失败如实呈现
- **WHEN** 结果面所需的建议、绑定或候选数据读取失败
- **THEN** 卡内显示读取失败与重试操作，不显示空候选或过期数据伪装
