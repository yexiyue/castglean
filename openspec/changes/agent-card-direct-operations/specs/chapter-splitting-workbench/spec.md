# Spec Delta

## ADDED Requirements

### Requirement: 会话内候选方案采用

系统 SHALL 在助手会话的分章候选结果处提供整套采用与放弃：差异摘要（章数、新增、移除）卡内可读，采用走与审阅弹窗相同的宿主命令，按命令的期望修订与幂等语义校验；方案过期、已采用或已放弃时卡内如实标注并禁止重复采用。章节边界的细调与原文定位仍在既有审阅弹窗完成，会话内提供到达该弹窗的入口。

#### Scenario: 卡内整套采用
- **WHEN** 用户在会话结果卡内采用一个未过期的候选方案
- **THEN** 采用经同一宿主命令完成，成功后卡内显示已采用，目录与审阅弹窗读取到同一状态

#### Scenario: 过期方案卡内标注
- **WHEN** 用户修改目录后回到会话中的旧方案卡
- **THEN** 卡内显示过期并禁止采用，历史消息仍保留

#### Scenario: 采用失败如实呈现
- **WHEN** 卡内采用提交或最新工程读取失败
- **THEN** 卡内显示受控错误与重新读取入口，不伪造保存成功或替换当前目录
