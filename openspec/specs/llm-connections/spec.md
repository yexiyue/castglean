# llm-connections Specification

## Purpose

让用户在桌面应用中管理多个文本模型服务及其模型，以可验证的连接、能力状态和明确的任务选择支持分章诊断及后续分析，并确保密钥与小说工程、对话和日志分离。

## Requirements


### Requirement: 多连接与协议选择

系统 SHALL 支持多个命名连接，每个连接配置多个模型，支持 OpenAI Chat Completions 兼容、Anthropic 原生与 Gemini 原生协议。连接与模型具有稳定身份，实际模型由连接和模型共同确定。

#### Scenario: 同名模型属于不同服务
- **WHEN** 用户在两个连接中添加相同的模型 ID
- **THEN** 系统独立保存、展示连接名称，并按所选连接调用对应地址

#### Scenario: 配置保存失败
- **WHEN** 修改连接时持久化失败
- **THEN** 系统保留之前生效配置，展示可重试错误且不报告保存成功

### Requirement: 手动模型与显式列表获取

系统 SHALL 允许手动输入模型 ID 和显示名称，并支持用户主动获取远程模型列表后选择加入。列表不支持、获取失败或分页未完成 SHALL 不删除已有模型，也不阻止手动添加；列出模型不代表能力验证通过。

#### Scenario: 服务不提供列表接口
- **WHEN** 获取模型列表返回不支持
- **THEN** 系统说明无法获取并保留手动添加入口和全部现有模型

#### Scenario: 用户选择列表中的模型
- **WHEN** 列表中出现尚未配置的模型且用户选择加入
- **THEN** 系统保存该模型，不自动将未选择的模型加入配置或设为默认

### Requirement: 密钥使用系统凭据库

系统 MUST 仅在系统凭据库持久化密钥，普通配置仅保存不透明引用；允许显式无密钥连接。设置读取不回显原值，支持替换和删除；凭据不可用时不得回退到明文文件或假设无密钥。小说工程、恢复文档、前端持久化及日志不得包含密钥。

#### Scenario: 凭据库被锁定
- **WHEN** 用户保存、测试或使用一个需要密钥的连接但凭据库不可读写
- **THEN** 系统报告凭据不可用且不发起未鉴权替代请求，不将密钥写入配置

#### Scenario: 替换密钥时配置写入失败
- **WHEN** 新密钥已写入但新连接配置无法保存
- **THEN** 旧配置和旧密钥引用仍然生效，新增孤立引用不会被当作当前连接

#### Scenario: 本机服务不要求密钥
- **WHEN** 用户显式配置无密钥连接并启动测试
- **THEN** 系统允许请求且不伪造已配置密钥状态

### Requirement: 连接与能力分别测试

系统 SHALL 提供用户主动触发的文本连接测试、工具往返测试与结构化输出测试，分别记录未测试、通过、失败、过期以及时间和配置身份。测试不得发送小说正文；配置变化使旧证据过期。普通文字声称支持工具或返回 JSON 字符串不等于相关能力验证通过。

#### Scenario: 文本可用但工具不可用
- **WHEN** 模型文本请求成功但工具测试没有完成实际工具往返
- **THEN** 系统分别展示连接通过和工具失败，不标记分章诊断可用

#### Scenario: 修改模型请求配置
- **WHEN** 协议、端点、密钥或实际模型 ID 发生变化
- **THEN** 旧测试结果标记过期，晚到的旧配置测试不能更新新配置状态

#### Scenario: 结构化输出非法
- **WHEN** 模型返回的数据无法解析或不符合测试 Schema
- **THEN** 系统标记结构化测试失败，保留文本与工具测试各自的真实结果

### Requirement: 默认模型与任务覆盖

系统 SHALL 提供全局默认模型，允许启动任务前覆盖选择，并在运行时固定连接、模型和有效配置。修改全局默认不影响已有运行。相关活动运行期间，请求配置修改与删除 SHALL 返回忙状态；失败不得自动切换提供商或模型。

#### Scenario: 默认设置在任务运行时改变
- **WHEN** 用户切换全局默认模型
- **THEN** 运行中的诊断继续使用原配置，新任务使用新默认

#### Scenario: 活动连接请求被修改
- **WHEN** 用户修改运行中任务所用连接的端点或密钥
- **THEN** 系统拒绝冲突修改并提示先结束相关任务，不让运行中请求混用配置

#### Scenario: 请求失败后选择另一个模型
- **WHEN** 用户明确选择新模型继续诊断
- **THEN** 系统创建新的执行身份并展示模型变更，保留已有候选、调用记录和会话累计预算

### Requirement: 可操作错误与真实宿主状态

系统 SHALL 区分浏览器预览、凭据缺失、鉴权失败、模型不存在、不支持能力、网络失败和超时，提供相应操作。返回前端的错误不得包含密钥、带凭据 URL 或原始服务响应；浏览器预览不得伪造测试、保存和调用成功。

#### Scenario: 浏览器打开设置
- **WHEN** 当前页面没有桌面宿主
- **THEN** 页面明确说明真实连接管理需要桌面应用，不启用会产生成功假象的测试按钮

#### Scenario: 服务返回敏感错误正文
- **WHEN** 请求失败且服务错误包含鉴权字段
- **THEN** 系统仅展示安全错误类别和可操作提示，不泄露原始响应

### Requirement: 按供应商能力配置思考强度
系统 SHALL 根据模型已知支持的思考选项默认最低可用档位，允许用户在前端选择已支持选项。未知能力或不支持思考时使用供应商默认行为，不盲发low或关闭参数。

#### Scenario: 配置后启动分析
- **WHEN** 用户修改思考强度后启动新任务
- **THEN** 新任务冻结该设置并按供应商协议发送，在途任务不被改写

#### Scenario: 不支持关闭思考
- **WHEN** 模型能力仅包含强制思考的档位
- **THEN** 前端不提供关闭选项，宿主拒绝不支持值
