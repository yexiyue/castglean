# assistant-interactions Specification

## Purpose
承载工程助手对话内的持久化用户决定、异步任务卡、媒体产物操作及真实生成信息：助手以宿主事实呈现任务与产物，用户决定可校验、幂等提交并恢复，不以自然语言或受理状态代替准确目标和完成事实。
本能力随 assistant-guided-production 逐步建立，当前仅包含已交付的章节生成任务卡。

## Requirements

### Requirement: 对话内章节生成任务卡
系统 SHALL 在工程助手内从宿主音频任务记录显示近期运行，按原运行 ID 报告阶段和已完成单元。

#### Scenario: 切章或重新打开助手
- **WHEN** 章节任务已被宿主受理且用户切章或重新打开助手
- **THEN** 对话任务卡继续显示原任务，阶段和进度来自宿主，返回操作定位原章节及制作方式

#### Scenario: 直接试听已有产物
- **WHEN** 用户点击存在可读音频的任务卡试听
- **THEN** 全局播放器只读取该运行的已有媒体和播放计划，查看、恢复、返回及试听均不得再次启动生成
