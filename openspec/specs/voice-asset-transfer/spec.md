# voice-asset-transfer Specification

## Purpose

为宿主和命令行提供模型无关的音色资产批量搬运能力，使一个或多个包中的音色可以经过受限校验、冲突确认和明确提交后进入本地库，并保证失败、取消和重复操作不会静默改变已有声音。

## Requirements

### Requirement: 统一多音色容器

系统 SHALL 使用一个版本化 `.voice` 容器保存一个或多个自包含音色，包含稳定身份、名称、来源、原始创建时间、描述、参考文本及原始 WAV；不得包含模型权重、模型专用缓存、凭据或工程角色绑定。系统 MUST 拒绝旧格式及未知版本，不转换、覆盖或删除输入文件。

#### Scenario: 多音色跨库往返
- **WHEN** 用户将三个音色导出一个包并在空库导入
- **THEN** 三个音色的身份、声音内容、来源和原始创建时间保持一致，本机导入时间单独记录

#### Scenario: 拒绝旧包
- **WHEN** 输入旧单音色格式或未知版本
- **THEN** 返回类型化版本错误，音色库和输入文件不变

### Requirement: 无模型依赖的公开传输契约

库 SHALL 提供检查多个包、选择条目、提交冲突决定、批量导入及选中音色单包导出的公开 API，返回结构化进度、错误和逐项结果。单音色 MUST 复用相同传输语义；调用方不需要构造模型注册表、下载或加载模型，也不需要了解包内部布局。

#### Scenario: 离线空模型环境搬运
- **WHEN** 宿主在无模型资源、无网络环境调用公开 API 检查、导入和导出两个音色
- **THEN** 操作正常完成，不触发模型准备、网络请求或合成；结果可按稳定错误码和条目身份消费

### Requirement: 有界校验与只读预览

系统 MUST 在写入正式库前校验所有输入包的结构、条目身份、元数据、内容摘要和完整 WAV，并限制文件数、条目数、清单大小、单音频大小与累计解压字节。预览 SHALL 返回每条音色信息及冲突，不写正式音色记录；校验任一输入失败时不得开始本批提交。

#### Scenario: 畸形和超限文件
- **WHEN** 输入缺失录音、重复清单条目、重复 ZIP 路径、非法身份、摘要不符、截断 WAV 或超限内容
- **THEN** 返回可定位到包或条目的结构化错误，没有任何本批音色进入正式库，资源使用不超过声明预算

#### Scenario: 用户取消预览
- **WHEN** 检查期间取消或关闭尚未提交的预览
- **THEN** 已有库不变，受控暂存资源被回收

### Requirement: 身份与冲突决定

系统 SHALL 区分同名、同 ID、相同声音内容和元数据差异；默认跳过完全相同的同 ID 资产，保留本地元数据。同 ID 不同声音 MUST 要求跳过或以新 ID 导入，不提供覆盖声音。不同 ID 相同内容 SHALL 提示重复并允许跳过或保留；所有结果返回来源条目到本地 ID 的映射。

#### Scenario: 冲突矩阵
- **WHEN** 同一批含完全重复、同 ID 元数据不同、同 ID 声音不同、仅同名和不同 ID 相同内容的条目
- **THEN** 分别展示已存在、元数据差异、身份冲突、可新增同名、可能重复；未解决的身份冲突阻止提交，任何默认决定均不覆盖本地信息

#### Scenario: 多包内 ID 冲突
- **WHEN** 两个输入包包含同 ID 不同声音
- **THEN** 即使本地库为空也报告批内冲突，以明确决定及唯一目标 ID 才能提交

### Requirement: 预览与提交的一致性

系统 MUST 将提交绑定到经过验证的输入内容和用户选择，并在库提交时重新检查目标身份、重复状态及目标 ID 分配。过期预览不得静默采用新内容或其他冲突策略；重试同一导入不得重复生成已经完成的新 ID 副本。

#### Scenario: 预览后输入发生变化
- **WHEN** 用户确认前原始包被另一进程替换
- **THEN** 系统只提交预览时冻结且已验证的内容，或者拒绝并要求重新预览，不读取替换内容直接提交

#### Scenario: 预览后本地发生冲突
- **WHEN** 另一个写入者占用了预览分配的目标 ID
- **THEN** 对应项返回冲突且不覆盖；已完成项不撤销，重试能识别其原提交结果

### Requirement: 逐项提交与如实报告

系统 SHALL 逐条原子发布音色；失败不暴露半条资产、不改变已存在记录。报告 MUST 覆盖所有选择项的成功、已存在、跳过、失败、取消或未执行状态及 ID 映射；取消阻止后续发布，已开始的单条原子提交允许完成但必须反映在最终报告。进程异常退出后可重新盘点有效资产并安全重试，不承诺自动恢复旧任务。

#### Scenario: 批次中途磁盘写入失败
- **WHEN** 第三个音色写入失败，前两个已完成
- **THEN** 前两个保留、第三个没有正式半成品；磁盘等批次级故障停止后续写入，报告区分失败项与未执行项

#### Scenario: 提交边界取消和异常重启
- **WHEN** 在单项提交边界取消或进程意外终止
- **THEN** 库内只存在完整资产，取消报告不将已发布项记为取消；重启重新导入时已完成声音不重复创建

### Requirement: 原子导出与稳定内容

系统 SHALL 将选定音色的已验证快照写入一个完整包；导出中资产变化不得产生混合记录。导出为空、重复 ID、缺失或损坏资产 MUST 显式失败；取消或写入失败不得发布新目标文件或破坏已有目标。覆盖已有目标必须是调用方明确选择的行为。

#### Scenario: 多选导出失败
- **WHEN** 五个选中音色中存在损坏记录，或写盘中途失败、取消
- **THEN** 不发布部分音色包，已有目标保持不变，返回具体失败项或写入错误

#### Scenario: 已有同名目标
- **WHEN** 调用方未明确授权替换而目标文件已存在
- **THEN** 导出返回目标冲突，原文件保持不变
